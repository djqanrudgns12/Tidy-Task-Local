# 토너먼트 구현 및 검수

2026-09-21 · 학급 툴킷의 독립 도구 `tournament`

## 구현 범위

- 4·8·16·32·64강 생성, 대회 목록과 이어서 열기.
- 각 칸 직접 입력, 여러 줄 명단 붙여넣기, 학급 학생/모둠 불러오기.
- 참가자 ID를 유지하는 대진 섞기와 번호 선택으로 두 자리 교환.
- 빈자리의 자동 부전승 및 양쪽 대진에 고르게 분산하는 초기 배치.
- 같은 경기의 승자를 재클릭하면 취소. 상대를 클릭하면 승자 변경.
- 변경 경기의 조상 경기 결과만 해제하고 반대편 대진 결과 유지.
- 최근 50회 되돌리기, 대진 편집으로 복귀, 결과만 초기화.
- 확대/축소, 화면 맞춤, 배경 드래그, 왼쪽/오른쪽/결승 집중 보기.
- 독자 제작 SVG 트로피, 결승 무대, 우승자 화면, 일회성 색종이 연출.
- 기본 켜짐의 합성 팡파레, 소리 미리듣기, 명시적 간단한 연출 선택.
- 툴바/노출 설정/네이티브 창 생성/작업창 수명/개발 미리보기 연결.

## 저장 계약

`tidy-task-tournament.json`의 독립 문서 저장소를 사용한다. 네이티브 창은 하나를 재사용한다. 저장 요청은 revision을 검사하고 저장 실패 시 메모리 상태와 디스크 캐시를 이전 상태로 복구한다. 손상된 파일이나 미래 형식은 덮어쓰지 않는다. 브라우저 미리보기는 별도 localStorage 키 `tidy-tournament-v1`을 사용한다.

대회별 제목, 크기, 준비/진행 상태, 참가자와 배치, 수동 경기 결과를 보관한다. 부전승은 참가자 배치로부터 계산한다. 학급 자료는 불러온 시점의 복사본이므로 진행 중 학급 편집으로 대진이 바뀌지 않는다. 되돌리기 기록은 창 세션 범위다. 효과음/간단한 연출 선택은 각각 전용 localStorage 키에 보관한다. 우승 결과를 다시 열어도 축하 연출이 자동 재생되지 않는다.

툴킷 설정은 v5로 확장했다. v1~v4에서 토너먼트를 추가하며, v5 이후 사용자가 숨긴 도구는 다시 표시하지 않는다.

## 브라우저 직접 검수

- 8강 생성 → 8팀 일괄 입력 → 확정 → 8강/준결승 선택 → 우승 화면 → 대진표 복귀.
- 우승 이후 8강 승자를 재클릭해 해당 준결승/결승/우승만 해제되고 반대편 결과 유지 확인.
- 되돌리기와 저장한 대회 재개 확인.
- 64강 생성, 60팀 입력, 섞기, 빈 4자리 부전승 안내 및 확정 확인.
- 1280×720 기본 화면과 640×520 작은 창의 대진 확대 및 하단 조작 영역 확인.
- 검수 중 참가자 글씨를 확대하고 기본 대진표 배율을 개선.

## 검증의 한계

네이티브 코드 컴파일과 단위 테스트까지 수행했다. 실제 설치 앱에서 명단 불러오기, 창 항상 위/전체 화면, 재실행 후 디스크 복원, 다중 모니터/DPI를 직접 조작하는 검수와 설치 패키지 생성은 이번 작업에서 수행하지 않았다. 브라우저 검수는 네이티브 검수로 간주하지 않는다.

작업 중 다른 도구 관련 변경도 같은 작업 폴더에 존재했다. 관련 없는 뽑기/외부 메뉴/음원 변경은 이 문서의 구현 범위에 포함하지 않는다.


## 가독성·우승 연출 개선 (사용자 피드백 반영)

- 본문을 시스템 한글 글꼴로 통일하고 안내문 대비를 강화. 입력/팀명은 기본 24px, 경기 버튼은 높이 56px로 확대했다. 기본 8강 편집 화면에서는 실제 표시 크기 약 18px를 유지하면서 전체 대진을 표시한다.
- 희미한 파스텔 대진판을 청회색 배경, 짙은 글씨, 선명한 연결선과 진출 색상으로 변경했다. 비활성 조작도 글씨를 알아볼 수 있게 유지한다.
- 영어 장식 문구를 한국어로 변경. 참가자 입력 → 경기 시작 → 승자 선택 안내를 상단에 배치했다. 입력 패널 접기, 큰 글씨, 좌우 경기/결승 보기 버튼을 제공한다.
- 640×520에서는 결승 보기를 가로형 카드로 표시해 두 팀과 트로피가 잘리지 않게 했다.
- 기존 소리 OFF 기본값을 ON으로 변경. 클릭 이벤트에서 오디오를 먼저 활성화한 후 결과를 저장하므로 자동 재생 제한으로 소리가 누락되는 문제를 방지한다.
- 약 1.9초 드럼롤/기대감 → 트로피 등장/색종이 100개 발사 → 이름 공개/브라스 팡파레 → 결과 유지의 약 6.5초 연출을 분리된 컴포넌트로 구현했다.
- 브라스 화음, 드럼롤, 킥, 심벌, 짧은 잔향을 Web Audio로 합성한다. 외부 음악 파일은 사용하지 않는다. 소리 미리듣기/음소거/다시 축하하기/발표 건너뛰기 제공. 닫기와 반복 실행에서 예약된 소리와 타이머를 정리한다.
- 미리보기 환경에서는 시스템 동작 줄이기가 켜져 있었으며, 기존 코드가 UI 체크 상태와 무관하게 모든 연출을 생략했다. 또한 공통 toolkit.css가 하위 애니메이션을 강제로 차단했다. 사용자 요청에 따라 토너먼트는 풍성한 연출을 기본으로 하며, 토너먼트의 간단한 연출을 선택할 때만 생략한다. 명시적 전체 연출 클래스에 한해 공통 CSS 차단을 제외한다. 다른 도구의 시스템 접근성 동작은 유지한다. 간단한 연출에서도 소리는 별도 설정을 따른다.

추가 검증:

- 전체 Node 테스트 224개 통과. 신규 오디오 테스트 3개: 활성화 전 재생 방지, 드럼롤/팡파레 일정, 재실행 시 기존 음 정리, 간단한 연출의 소리 유지, 종료 후 재생 방지, 오디오 사용 불가 처리.
- 최종 웹 빌드 통과. 전체 타입 검사는 기존 873 errors / 14 warnings이며 토너먼트 파일 진단 없음.
- 브라우저에서 소리 미리듣기 활성화/재생 성공 상태 확인. 실제 교실 스피커의 음량/음색 청감 검수는 별도다.
- 발표 대기 화면과 우승 결과가 분리되는 것, 색종이 100개 및 트로피의 계산된 animation-name이 실제 활성화된 것과 움직이는 화면 확인.
- 1180×800에서 입력 패널과 대진판 모두 불필요한 스크롤 없이 표시됨 확인. 640×520에서 하단 버튼이 화면 안에 있고 결승 두 팀이 한 카드에 보이는 것 확인.
- 간단한 연출, 재생 중 닫기, 다시 축하하기 확인. 검수 종료 시 풍성한 연출/소리 켜짐으로 복원.

## 참가자 선택음·휠 배율 개선

- 모든 유효한 참가자 클릭에 짧고 밝은 합성 말렛음을 추가했다. 진출 선택과 승자 변경은 위로 올라가는 두 음, 같은 참가자를 다시 눌러 취소할 때는 아래로 내려가는 두 음이 난다.
- 마지막 우승자 클릭의 선택음은 약 1.9초 드럼롤과 팡파르가 시작되어도 끊기지 않는다. 빠르게 연속 선택하면 이전 선택음만 정리해 소리가 겹치지 않게 했다.
- 대진표 패널 위에서 마우스 휠을 올리거나 내리면 포인터 위치를 중심으로 정확히 5%씩 확대·축소한다. 확대/축소 버튼도 같은 5% 단위를 사용한다.
- 모든 표시 배율을 5% 경계로 정규화했다. 화면 맞춤은 패널 밖으로 넘치지 않도록 가까운 5% 값으로 내림하며, 새로 만들거나 다시 연 대진표의 기본 배율은 100%다.
- 선택음·취소음·팡파르 연결 및 5% 배율 정규화 단위 테스트를 추가했다. 전체 Node 테스트 227개와 웹 빌드가 통과했다.
- 브라우저에서 100% → 확대 버튼 105% → 축소 버튼 100%, 패널 휠 위로 105% → 휠 아래로 100%를 확인했다. 결승 선택 취소와 재선택 뒤 발표 대기 연출 진입도 확인했다.
