# 토너먼트 학급 명단 선택 · 자리 배정

2026-09-27

## 변경 내용

- 학급 명단 불러오기에서 학생/모둠 선택과 경기별 자리 배정을 하나의 모달 창으로 제공한다.
- 정원을 초과하는 학급은 선택하지 않은 상태로 열고, 정원 이내 명단은 번호/명단 순서대로 채운다.
- 명단 클릭으로 첫 빈자리에 배정하고, 재클릭이나 자리의 삭제 버튼으로 개별 선택을 취소한다.
- 자리를 먼저 선택한 뒤 명단을 클릭하면 지정 자리에 넣거나 기존 참가자를 교체한다.
- 배정된 자리와 다른 자리를 차례로 클릭하면 교환한다. 빈자리로 이동도 가능하다.
- 번호순/명단순 배정, 전체 명단에서 정원만큼 랜덤 선택, 선택한 참가자의 대진만 섞기, 선택 모두 취소를 지원한다.
- 검색, 선택 인원/정원, 남은 자리, 좌우 경기 구분, 빈자리 부전승 안내를 제공한다.
- 모달의 배정 배열을 그대로 저장한다. 적용 전 취소/닫기/Esc는 기존 대진에 영향을 주지 않는다.
- 저장 실패 시 모달과 선택을 유지해 재시도할 수 있다. 저장 성공은 기존 되돌리기 기록에 포함된다.
- 원본 학급 명단은 수정하지 않는다. 참가자 식별자는 학급 항목 ID를 사용하며 저장 자료는 기존 토너먼트 형식을 유지한다.
- 작은 창은 명단과 경기 목록을 개별 스크롤하고 하단 취소/적용을 유지한다. 높이가 낮으면 제목/선택 영역과 안내를 압축한다.

## 자동 검증

- 신규 선택 로직 검사 5개: 학생 번호 정렬/ID 보존, 정원 제한/지정 자리 교체, 이동/중복 방지, 순차 배정/초과 거부, 4~64강 랜덤 선택/선택 집합 보존.
- 전체 Node 테스트 608개 통과.
- Svelte 검사: 오류 0개, 경고 0개.
- Vite production build 통과. 별도 산출 디렉터리 `output/tournament-roster-build` 사용.
- 관련 변경의 `git diff --check` 통과.

## 브라우저 직접 검수

체험용 28명 학급으로 확인했다.

- 8강에서 선택 0명으로 시작, 첫 빈자리 순차 배정, 6번 자리 지정 배정.
- 1/2번 자리 교환, 개별 선택 취소, 번호순 재배정.
- 8명 선택 시 9번째 선택 비활성. 자리 지정 후 다른 참가자로 교체하면 인원은 8명 유지.
- 랜덤으로 8명 선택. 대진 섞기 후 미리보기의 8개 자리 이름과 실제 대진표 입력값 일치.
- 적용 후 재불러오기/랜덤 선택/취소에서 기존 8개 자리 보존. 되돌리기로 적용 전 빈 대진 복구.
- 학생 → 모둠 전환에서 이전 학생 선택을 제거하고 모둠 없음 안내. 학생으로 전환하면 초과 명단을 다시 미선택 상태로 초기화.
- 4강과 16강 랜덤 선택/적용에서 각각 4명/16명, 중복 없음.
- 32강은 28명 자동 배정 및 빈 4자리 표시. Esc 닫기와 불러오기 버튼으로 포커스 복귀.
- 기본 1280×720, iframe의 실제 viewport 640×520에서 모달, 명단/자리 스크롤, 적용/취소 버튼 확인. 작은 화면에서 랜덤 선택/취소 가능.
- 브라우저 console 오류/경고 없음.

## 검증 범위

이번 검수는 브라우저 개발 미리보기에서 수행했다. 설치된 Tauri 앱의 실제 학급 파일 읽기/쓰기와 Windows DPI 검수는 수행하지 않았다. 같은 작업 폴더의 다른 도구 변경은 수정하거나 되돌리지 않았다.
