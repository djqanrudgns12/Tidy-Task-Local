# 할 일 세로 재정렬 검수 — 2026-09-30 / 5.6.5

오른쪽 손잡이를 유지하면서 가로 이동을 고정했습니다. 잡은 행은 포인터를 바로 따라가고, 주변 행과 놓는 효과는 180ms로 움직입니다. 목록 끝에서는 자동으로 스크롤하며, Escape로 이동을 취소할 수 있습니다.

## 구현

- `src/lib/todos/verticalSort.js`: dnd kit DOM 0.5.0의 세로축 제한, 포인터·키보드 센서, 충돌 판정, 자동 스크롤, Sortable 애니메이션을 사용합니다. Svelte가 keyed DOM을 관리하도록 엔진의 직접 DOM 재정렬은 사용하지 않습니다.
- 드래그 시작 때의 행 너비와 왼쪽 위치를 고정합니다. 기본 드롭 효과가 폭까지 보간하는 경우를 막고, 현재 세로 위치에서 대상 칸의 최종 좌표로만 착지합니다. 이동 중인 주변 행의 애니메이션 좌표는 착지 목표로 사용하지 않습니다.
- `TodoList.svelte`의 임시 순서는 저장 상태와 분리합니다. `order.js`가 전체 ID 순열과 시작 순서를 검증한 뒤 최신 일정 객체로 최종 순서를 만듭니다. 바뀐 순서만 `appState.reorderTodos()`로 한 번 저장합니다.
- 추가·삭제·외부 재정렬·검색·업데이트 잠금은 이동을 취소합니다. Escape, 창 초점 상실, 숨김, 크기 변경, 포인터 캡처 상실, 컴포넌트 제거 시 센서 리스너와 스크롤 잠금도 정리합니다.
- 손잡이 18px, 오른쪽 버튼 묶음 약 37.66px을 유지합니다. 표시 여부는 투명도로만 바꾸며 별도의 이동 칸은 추가하지 않습니다.
- 키보드: Space/Enter 시작, ↑↓ 이동, Space/Enter 확정, Escape 취소. ‘동작 줄이기’ 설정도 따릅니다.

공식 근거: [dnd kit Sortable](https://dndkit.com/concepts/sortable/), [Modifiers](https://dndkit.com/extend/modifiers/), [PointerSensor](https://dndkit.com/extend/sensors/pointer-sensor/).
