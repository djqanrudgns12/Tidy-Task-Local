# 학급 투표 개표·결과·PNG 개선 검수 (2026-09-26)

## 변경 기준

기호·그림·이름·득표·상태가 서로 겹치지 않도록 각 영역을 분리했습니다. 결과 화면과 공유용 PNG는 `resultImage.js`의 동일한 그리기 함수를 사용합니다. 원본 캐릭터 18종을 유지했으며, 의견 스티커의 무늬도 PNG에 그립니다.

| 개표 방식 | 개선 내용 |
| --- | --- |
| 바로 결과 | 다른 방식과 동일한 결과판 및 완료 연출로 연결합니다. |
| 한 장씩 펼치기 | 현재 투표용지, 선택 내역, 기호 순 집계표를 분리했습니다. 새 표의 행을 강조하고 숫자에 단위를 붙였습니다. 후보 9명일 때 행 높이와 그림 크기를 줄입니다. |
| 실시간 레이스 | 기호와 이름을 왼쪽에, 득표수를 오른쪽에 고정합니다. 캐릭터는 레인 높이에 맞춰 움직입니다. |
| 줄다리기 | 찬성과 반대를 독립 카드로 표시합니다. 판정 도장이 득표 카드 위를 가리지 않습니다. |
| 개표 방송 | 순위, 후보, 막대, 득표, 확정 표시의 칸을 분리했습니다. 0표의 막대는 길이 0이며 개표율은 실제 공개한 용지 수로 계산합니다. |
| 반전 공개 / 골라 공개 | 기호와 상태를 카드 상단에 확보했습니다. 납작한 카드는 그림과 이름을 가로로 놓아 최대 9명까지 한 화면에 표시합니다. |

## 결과와 저장

- 제목·날짜·참여 인원, 결과 카드, 전체 결과표, 집계 기준을 구분했습니다.
- 동점 후보 전원을 그림과 함께 표시합니다. 일부 당선 + 나머지 동점, 최대 9명 동점도 포함합니다.
- 찬반 결과는 안건별 번호·제목·득표·판정을 같은 행에 표시합니다.
- 공개 범위가 순위/당선자/찬반 결과만인 경우 숨긴 득표수와 비율을 출력하지 않습니다.
- 결선을 권하는 문구와 조작 버튼, 축하 입자는 PNG에 포함하지 않습니다.
- PNG는 3200×1800이며 화면과 같은 글꼴을 기다린 뒤 생성합니다. 복사도 같은 PNG를 사용합니다.
- 캔버스 결과판에 대응하는 제목·목록·표를 보조 기술에 제공합니다.
- 결과 카드와 목록을 짧은 시차로 등장시키고, 그림 준비 후 축하 소리와 입자를 시작합니다. 재생 후 입자를 제거하며 움직임 줄이기에서는 정적인 표시를 사용합니다.

## 검증 결과

- `node --test src/lib/vote/vote.test.js src/lib/vote/resultImage.test.js`: 57/57 통과했습니다.

- 전체 테스트는 실행 당시 545개 중 541개 통과했습니다. 실패 4개는 자리 배치 도구가 추가된 레지스트리와 기존 마이그레이션 테스트의 기대 목록 차이입니다. 이번 작업에서 해당 영역은 수정하지 않았습니다.
- 9가지 결과 사례의 실제 저장 버튼으로 PNG를 내려받았습니다. 모두 3200×1800이며 화면과 비교한 채널당 평균 차이는 0.84/255 미만입니다. 차이는 배율별 글꼴·도형 래스터화에서 발생하며 구도와 내용은 같습니다.
- 1440×900, 1366×768, 1024×720에서 33개 반응형 사례와 의견·찬반 추가 5개 사례를 검사했습니다. 최종 38개 사례 모두 영역 넘침·기호/그림/이름 겹침·런타임 오류가 없었습니다.
- 실제 이미지 복사 후 클립보드에서 `image/png`를 확인했습니다.
- 다시 개표 후 결과가 동일한지, 골라 공개 9장 완료, 찬반 3개 안건의 순차 완료를 확인했습니다.
- 완료 시 입자 80개가 나타나고 이후 0개로 정리됩니다. 움직임 줄이기에서는 입자 0개와 정적 표시 1개를 확인했습니다.
