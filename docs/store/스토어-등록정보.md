## 9. 영어 등록정보를 만들지 않는 이유

영어 등록정보를 추가하면 영어권 PC에서는 영어 설명이 보이지만, 앱 화면은 한국어뿐이라 **"설명과 실제 앱이 다르다"는 신고·낮은 평점**으로 이어지기 쉽습니다.
한국어 하나로 등록하면 모든 지역에서 한국어 설명이 보여 오해가 없습니다. 나중에 영어 화면을 지원할 때 추가하세요.

## 10. 연령 등급(IARC) 질문지 답변 가이드

질문 문구는 바뀔 수 있으니 **실제 앱 동작 기준으로 정직하게** 답합니다. 예상 결과는 전체 이용가(3+) 또는 7+입니다.

| 질문 주제 | 답 | 근거 |
| --- | --- | --- |
| 앱 종류 | 게임 아님 → 교육·참고·생산성/유틸리티 계열 | 업무·수업 도구 |
| 폭력·공포 묘사 | 아니요 | 집중벨의 '폭탄'은 효과음일 뿐 폭력 장면 없음 |
| 성적 내용·노출 | 아니요 | |
| 욕설·비속어 | 아니요 | |
| 저속한 유머(Crude humor) | **질문이 신체 소리 유머를 포함하면 "예(경미)"** | 집중벨에 '방구' 효과음이 있음. 숨기지 말 것. 등급이 7+가 되어도 게시엔 문제없음 |
| 약물·음주·흡연 | 아니요 | |
| 도박·모의 도박 | 아니요 | 주사위·인형 뽑기는 무작위 선택 연출, 돈·포인트 베팅 없음 |
| 사용자 간 소통·콘텐츠 공유 | 아니요 | 온라인 대화·게시 기능 없음. 투표도 같은 PC에서만 |
| 위치 정보 공유 | 아니요 | GeoIP 비활성화, 위치 수집 없음 |
| 디지털 상품 구매 | 아니요 | 앱 내 결제 없음 |
| 제한 없는 인터넷 접근(내장 브라우저) | 아니요 | 외부 사이트(롤린썬더·클래너 등)는 기본 브라우저로 열 뿐, 앱 안 브라우저 없음 |
| 개인정보 제3자 공유 | 아니요 | 사용 통계는 무작위 설치 ID 기반, 이름·연락처 등 미수집. 처리방침에 공개 |

## 11. 홍보 문구 세트 (블로그·쇼츠·커뮤니티용)

스토어 밖에서 클릭을 부르는 문장입니다. 스토어 설명에는 링크를 못 넣지만, 여기 문구에는 스토어 링크를 붙여 쓰세요.

**제목·썸네일 훅**
- 선생님, 아직도 타이머 사이트 검색하세요?
- 타이머·뽑기·자리 배치가 한곳에? 선생님을 위한 무료 도구
- 회장 선거, 이제 숫자키 하나로 비밀 투표 끝
- 자리 바꾸는 날 교실이 들썩이는 이유
- 모니터 테두리의 포스트잇, 오늘 다 떼세요
- 마이크로소프트 스토어에 올라간 선생님 전용 프로그램

**한 줄 소개(쇼츠 설명란·카톡 공유)**
```text
수업은 즐겁게, 준비는 가볍게! 메모·할 일 + 교실 도구 12가지를 프로그램 하나로. Microsoft Store에서 'Tidy Task'를 검색하세요. 무료·가입 없음.
```

**커뮤니티 글 첫 문단(인디스쿨 등)**
```text
교실에서 매일 쓰던 타이머·뽑기·투표·자리 배치를 하나로 모은 무료 프로그램 Tidy Task가 Microsoft Store에 올라갔습니다. 스토어에서 설치하면 다운로드 경고 없이 바로 설치되고, 메모와 학급 자료는 선생님 PC에만 저장됩니다. 써 보시고 별점과 의견 남겨 주시면 다음 업데이트에 반영하겠습니다!
```
