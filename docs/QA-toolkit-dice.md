# 주사위 던지기 구현 및 검증 — 2026-09-23

기준 문서: 주사위 던지기 PRD(Claude Docs, 2026-09-23). 사용자 확정 사항: 처음 1개로 시작, 간단 뽑기와 별개 도구(뽑기 아이콘·코드 그대로), 더블·트리플 배지 이번 배포에 포함.

## 구현 결과

- 툴킷 `dice` 역할: 독립 작업 창(960×720, 최소 520×480, 집중벨과 같은 화면 비율 규칙), 툴바 버튼(집중벨 다음), 도구 표시 설정, 도움말 장·단축키.
- 주사위 1~3개. 개수는 조작줄 `1개 · 2개 · 3개` 라디오 묶음(좌우 화살표, `1`~`3` 키). 처음 1개, 이후 마지막 개수 기억(`localStorage` `tidy-dice-settings-v1`).
- 결과는 연출 전에 확정(crypto, 거부 표본 추출로 1~6 균등). 1개는 숫자 하나, 2·3개는 `a + b = c`. 칩 색 = 주사위 자리 색.
- 더블(2개 같음)·트리플(3개 모두 같음) 배지. 3개 중 2개만 같으면 배지 없음.
- 3D 정육면체(CSS `preserve-3d`) + 층 분리: 그림자 / 위치 / 모양(찌그러짐) / 기울임 / 회전. Web Animations API로 던질 때마다 키프레임 생성, 지난 각도에서 이어 굴림.
- 대기 중 웃는 얼굴, 던지는 순간 `> <` 얼굴. 1은 빨간 하트.
- 동작 줄이기: OS 설정을 따르되 창 안 스위치로 바꿀 수 있고 선택을 기억. 켜면 0.2초 흐려졌다 바뀜, 효과음은 "딩" 한 번.
- 효과음 합성(녹음 파일 없음): 착지 "톡"은 AudioContext 시계로 착지 순간에 예약, 합계 "딩", 트리플은 세 음.

## 2차 개선 — 2026-09-24

사용자 제보: 던질 때 윗부분에 띠가 생기고 주사위가 어그러짐, 연출이 순식간, 던지는 순간 소리 없음, 결과 영역 구분 없음.

| 항목 | 이전 | 이후 | 이유 |
| --- | --- | --- | --- |
| 주사위 몸통 | CSS 3D 둥근 면 6장 + 안쪽 심 | **WebGL 둥근 정육면체 한 덩어리**(`geometry.js`·`renderer.js`) | 둥근 면끼리 맞닿지 않아 꼭짓점에 구멍, 심이 삐져나와 이중 테두리, 기울임 때문에 윗면 띠. CSS 값 조정으로는 원리상 해결 불가 |
| 멈춘 모습 | CSS 그러데이션·흰 광택·테두리 | 셰이더로 같은 값 재현(그러데이션·광택은 화면 위치+법선, 테두리는 실루엣) | 멈추면 예전과 같은 모양, 굴러갈 때는 빛이 고정된 실제 물체처럼 명암이 따라옴 |
| 연출 | 1.05초, 한 번 튐 | 약 1.35~1.55초(3개 최대 1.9초): 움츠림 → 두 바퀴 비행 → 두 번 더 튐 → 바닥에서 모서리 넘어 1~2번 구름(미끄러지며 돎) → 흔들리다 멈춤 | 공중 회전 속도 일정, 부딪힐 때만 축·속도 변화. 매 순간 "가장 낮은 점이 바닥 위" 규칙으로 모서리 착지·모서리 딛고 넘기가 저절로 나옴 |
| 자세 계산 | 오일러 각 키프레임(WAAPI) | 쿼터니언 대본 + `requestAnimationFrame`(`rotation.js`, `motion.js`의 `buildRoll`·`poseAt`) | 여러 구간을 이어도 자세가 튀지 않고, 끝 자세부터 거꾸로 짜서 착지 면이 항상 결과와 같음 |
| 효과음 | 착지 "톡" 1번 | 던지는 순간 "달그락·휙"(`throw`) + 부딪힐 때마다 세기별 "톡"(첫 착지 크게, 구를 때 작고 높게) | 요청 사항. 줄임 모드는 PRD대로 "딩"만 |
| 결과 | 줄만 있음 | **결과 패널**. 칩·기호·합계 칸 폭을 합계 글자 크기 배수로 고정하고 `fitResultSize`가 창 폭에서 글자 크기를 계산 | 1~3개 어떤 창 폭에서도 한 줄·잘림 없음(440~2600px 전 구간 테스트). 대기→결과로 바뀌어도 패널 폭 고정 |
| 배지 | 합계 오른쪽 위에 겹침 | 패널 오른쪽 위 모서리 스티커 | 합계를 가리지 않고 창 밖으로 나가지 않음 |
| Space | 스위치에 초점이 있으면 스위치가 도로 꺼짐 | 창 단계(capture)에서 먼저 가로채 던지기만 | 검수 중 발견한 기존 버그 |
| 효과음 예약 | — | 과거 시각 예약 방지 | 검수 중 발견: 던지기 소리의 무작위 어긋남이 0초 이전을 예약해 예외 → 뒤따르는 착지음이 모두 빠짐 |

WebGL을 못 쓰는 PC는 2D 캔버스로 정면만 그립니다(결과는 똑같이 읽힘). 그래픽 문맥을 잃으면 복구 뒤 다시 그리고, 주사위가 사라질 때 문맥을 바로 반납합니다.
