# Tidy Task 상단 디자인 고도화

## 목표와 범위

작은 데스크톱 메모 창에서 제목과 기능을 즉시 구별한다. 밝은 종이 같은 기존 분위기와 테마를 유지하고, 작은 회색 아이콘에 의존하던 기능에 읽을 수 있는 이름을 붙인다. 완벽함을 선언하는 대신 아래 사용 시나리오와 시각 기준으로 검수한다.

- 기존 사용자 변경사항, 저장 형식, 창 생성/닫기/고정/전체화면 로직을 보존한다.
- 급식은 현재 MealIcon과 창 연결을 그대로 사용하고 항상 노출한다.
- 초기화 삭제는 보류한다. 메뉴 하단으로 옮기되 별도의 확인 후에만 실행한다.
- 본문, 마감된 일, 중요 메모, Tiny Note 헤더는 이번 개편 범위 밖이다.

## 정보 구조와 정렬

1. 브랜드 줄: 왼쪽 Tidy Task, 오른쪽 실행 취소/다시 실행 한 쌍과 고정/최소화/닫기. 빈 영역의 기존 드래그와 더블클릭 동작 유지.
2. 제목 줄: 왼쪽 편집 가능한 노트 제목, 오른쪽 아이콘+이름의 ‘새 노트’. 메뉴에는 Tidy Task 노트와 Tiny Note를 구별하는 설명을 넣는다.
3. 도구 줄: 서식 / 알림 / 급식 / 메뉴. 같은 높이, 짧은 한글, 일정한 간격. 활성 기능에는 색뿐 아니라 체크/눌린 외형을 제공한다.
4. 서식 도구는 펼침/접힘 선택을 기억한다. 기존 사용자의 빠른 서식 접근을 위해 처음에는 펼친 상태로 시작하고, 접으면 3단 구성이 된다. 펼쳐놓은 상태는 메뉴 밖을 클릭해도 유지한다. 실행 취소는 서식 패널에 숨기지 않는다.
5. 메뉴: 보관함, 여러 항목 선택, 창 투명도, 설정, 기능 설명, 버전/제작자 정보, 구분된 초기화. 관련 항목은 작은 제목과 여백으로 묶는다.

## 시각 사양

- 좌우 시작선 통일. 제목과 본문 쪽 여백은 기존 앱의 12px 체계에 맞춘다.
- 브랜드 13~14px, 제목 16~18px, 주요 도구 12~13px, 메뉴 본문 13px를 기준으로 실측 조정한다.
- 제어 버튼은 기존 20px 안팎에서 28~32px 클릭 영역으로 확장한다. 매우 좁은 폭에서도 기능명을 축소/생략하지 않는다.
- 기본 글자와 아이콘은 충분히 진한 중성색. 테마색은 선택 상태와 새 노트에 제한적으로 사용한다. 다크 테마 대응.
- 반복된 카드 테두리와 그림자를 피한다. 메뉴에만 얕은 그림자, 상단과 본문 사이에 가는 구분선.
- 주요 버튼은 Lucide의 일관된 선 굵기, 급식 그림은 그대로 유지한다.
- 호버/포커스/활성/비활성 상태를 구별한다. 짧은 120~160ms 반응, reduced-motion 존중. 지속적인 장식 애니메이션은 사용하지 않는다.

## 사용성 계약

- 새 노트, 보관함, 설정 등 기존 콜백을 재사용한다. 리마인더는 기존 대상 창 이벤트를 유지한다.
- 메뉴는 하나만 열리고, 바깥 클릭/Escape로 닫힌다. 키보드로 열고 이동할 수 있으며 Escape 후 트리거로 포커스가 돌아온다.
- 메뉴는 뷰포트에 맞춰 배치하고 낮은 창에서는 내부 스크롤한다. 숨겨진 항목에도 키보드로 도달할 수 있다.
- 글꼴/색/크기 변경 시 본문 선택 범위를 잃지 않는다. 새 서식 트리거는 선택 범위를 보존한다.
- 제목은 한국어 IME 입력을 방해하지 않고 기존 저장 시점을 유지한다.
- 초기화는 취소가 기본 포커스인 확인창을 거친다. 오류를 숨기거나 성공한 것으로 표시하지 않는다.
- 좁은 창에서는 여백과 부가 버전 표기를 먼저 줄인다. 급식이나 기능 이름을 자동으로 숨기지 않는다.

## 구현 순서

1. 작업 전 diff 및 검사 결과 기록. 기존 작업을 덮어쓰지 않도록 변경 범위를 한정.
2. 공통 헤더 스타일과 키보드/뷰포트 대응 팝오버 구현.
3. Titlebar를 브랜드/창 제어로 정리. 설정과 초기화는 별도 헤더 메뉴로 이동.
4. MainToolbar에 제목/이름 있는 도구/서식 접기 추가. 기존 서식 로직과 급식 연결 보존.
5. 개발 전용 미리보기에서 실제 컴포넌트를 렌더링하여 폭/테마/긴 제목/메뉴/선택 편집 검수.
6. 자동 테스트·빌드·변경 파일 진단 확인 후 결과와 네이티브 미검증 항목 기록.

## 완료 판정

- 250, 280, 320, 350, 480, 640px에서 상단 가로 넘침과 버튼 겹침 없음. 200px에서도 기능 접근 가능.
- 250×300의 낮은 창에서 메뉴 끝과 취소 버튼 접근 가능.
- 밝은/어두운 테마와 긴 제목, 활성/비활성 상태 확인.
- 서식 선택 범위, 메뉴 닫기/포커스 복원, 초기화 취소, 생성 메뉴 구별 확인.
- 기존 테스트와 프로덕션 빌드 실행. 저장된 실제 노트는 QA로 초기화하지 않는다.
- 브라우저로 확인한 UI와 실제 Tauri 창/모니터/DPI에서 확인한 항목을 구별해 보고한다.

## 작업 전 기준

- 기존 작업 트리에 급식/설정/공지 등 다수의 미커밋 변경이 있음. 원래 변경을 보존한다.
- `npm run check`: 작업 전 36개 파일에서 오류 889개, 경고 15개. 전체 검사 성공으로 보고하지 않고 변경 파일에 새 진단이 생겼는지 비교한다.

## 구현 및 검수 결과

- Titlebar는 브랜드/실행 취소/다시 실행/창 제어만 남겼다. 기존 네이티브 창 동작 함수를 유지했다.
- 노트 제목을 왼쪽에 정렬하고 ‘새 노트’ 메뉴에 두 종류의 창과 설명을 넣었다.
- 서식/알림/급식/메뉴는 같은 줄에 이름과 아이콘으로 표시한다. 200px에서는 이름을 숨기지 않고 두 줄로 배치한다.
- 서식은 처음에 펼쳐져 있으며 접기/펼치기를 기억한다. 기본 350px에서는 한 줄, 더 좁은 창에서는 글꼴·크기 / 편집 버튼 묶음 단위로 정렬한다.
- 급식의 기존 MealIcon과 toggleMeal 연결을 유지했다. 초기화는 확인창을 거치는 메뉴 항목으로 보존했다.
- 메뉴를 뷰포트 안에 배치하고 낮은 창에서 내부 스크롤, Escape, 화살표 이동, 바깥 클릭, 포커스 복원을 지원한다. 서식 팝업도 창 가장자리에서 잘리지 않도록 조정했다.
- 글자 크기 목록에 키보드 열기/선택/닫기를 추가했다. 선택된 텍스트의 스타일 대신 바깥 편집기 스타일을 읽어 크기 표시가 되돌아가던 문제를 수정했다.
- 기존 사용자 UI 글꼴을 따른다. 개발 미리보기는 앱의 기본 메이플스토리 L을 사용한다.

## 사용자 시각 피드백 반영 — 작고 아기자기한 비례

앞선 시안은 실제 320px 창에서 버튼과 제목의 비중이 크고 서식이 두 줄이 되어 상단이 무거웠다. 사용자 피드백에 따라 기능 구조는 보존하고 크기·간격·강조를 재조정했다.

- 브랜드 줄 29px, 제목 14px, 도구 이름 11px, 주요 도구 클릭 영역 26px를 기준으로 조정.
- 큰 활성 테두리를 제거하고 옅은 테마색 배경으로 상태를 표시. 새 노트는 작은 강조 버튼으로 축소.
- 글꼴 선택 영역이 줄 전체를 차지하지 않도록 제한. 320px에서 글꼴·크기·편집 도구를 한 줄로 배치.
- 상단의 무거운 회색 면적과 여백을 줄이고, 기본 글꼴·급식 아이콘·기능 이름을 보존.
- 320px 실제 컴포넌트 미리보기: 브랜드/제목/도구/서식 합계 약 128px. `output/qa/header/refined-320.png` 참조.
- 기존 브라우저 UI 검사 23개 재통과. 기본·어두운 테마와 200~640px 확인. 프로덕션 빌드 통과.
- 이전에 명시한 실제 Windows 네이티브 동작 미검증 범위는 동일하다.

## 클래식 기본값과 작은 메뉴

- 기본 상단은 클래식이다. 급식 추가 당시의 아이콘 도구, 가운데 제목, 불투명도, 급식, 펼쳐진 서식 구성을 복원했다. 제목 왼쪽 고정과 오른쪽 디자인 전환은 이번 요청에 따른 변경이다.
- 상단 이름 오른쪽의 작은 배지로 클래식/새 디자인을 바로 전환한다. 설정 최상단에도 같은 선택이 있으며 ‘반영’으로 해당 노트 창에 적용한다.
- `headerDesign`은 노트 창별로 저장하되 Undo 스냅샷에 포함하지 않는다. 누락/잘못된 값은 클래식으로 복원한다. 기본 클래식은 저장 시 필드를 생략해 이전 파일의 기존 데이터 왕복을 유지한다.
- 새 노트 메뉴 설명: `To do list 창 추가하기` / `스티커 메모 추가하기`.
- 두 메뉴의 폭은 최대 216px. 버튼 오른쪽에 맞춰 4px 아래에서 열고, 낮은 창에서는 메뉴 내부를 스크롤한다. 제목 줄 오른쪽에 X 닫기 버튼을 추가했다.
- 메뉴 아이콘에 작은 바탕을 두고 글자/아이콘 간격, 항목 높이, 구분선과 보조 정보 크기를 조정했다.
- 클래식은 상단에 초기화 아이콘을 복원했다. 새 디자인은 메뉴 하단, 설정은 기존 데이터 초기화 버튼을 유지한다. 모두 확인 절차를 유지한다.
- 검증: 기존 테스트 및 새 저장 계약 테스트 142개 통과, UI 검사 25개 통과, 빌드 통과. 클래식 6개 너비 전환, 설명 문구, 두 X 닫기, 설정에서의 선택/반영을 추가 검증했다.
- 전체 타입 검사는 기존 오류 873개/경고 14개로 실패하며 새 진단은 없다. 실제 Windows 네이티브 창/저장 장치 검증은 수행하지 않았다.
- 최신 화면: `output/qa/header/choice-classic.png`, `choice-modern.png`, `choice-create.png`, `choice-menu.png`, `choice-settings.png`.

## 설정 전용 디자인 선택 보완
- 메인 노트의 클래식/새 디자인 전환 버튼을 두 모드 모두 제거했다. 선택은 시스템 설정에서만 한다.
- 클래식 고정 버튼은 Tiny Note 앞, 상단 맨 왼쪽으로 복원했다. 새 디자인은 브랜드 왼쪽 위치를 유지한다.
- 설정 제목은 `Tidy task 상단 디자인`으로 바꾸고, 실제 도구 배치를 요약한 두 종류의 전용 SVG 아이콘을 배치했다.
- 카드 선택 시 대상 노트에만 디자인을 즉시 적용하고 저장한다. 안내 문구에 즉시 저장을 명시하며, 취소해도 이미 선택한 디자인은 유지된다. 나머지 설정은 기존 반영 동작을 유지한다.
- 라디오 키보드 탐색과 포커스 표시를 유지하고, 다른 노트나 잘못된 디자인 값은 무시한다. 디자인 변경은 실행 취소 이력에 넣지 않는다.
- 검증: 단위 테스트 144개, 브라우저 UI 검증 25개 통과. 브라우저는 Tauri 이벤트 모의 환경이며 실제 네이티브 창 검증과 구분한다.
- 명칭은 사용자 선택 전까지 새 디자인을 유지한다.

## 모던 명칭 및 서식 한 줄 보완
- 사용자 선택에 따라 새 디자인의 이름을 모던으로 확정했다. 설정과 공지의 전환 안내를 현재 경로에 맞췄다.
- 서식의 고정 폭과 줄바꿈 규칙을 제거했다. 글꼴/크기 필드와 서식 버튼이 함께 축소되며, 200~640px의 11가지 폭에서 두 디자인 모두 한 줄 정렬과 잘림 없는 표시를 검증했다.
