# 타이머별 사운드 적용 및 추가 후보 · 2026-09-20

## 적용한 사용자 선택

| 타이머 | 시계음 | 종료 경고음 | 종료음 |
| --- | --- | --- | --- |
| 전광판 | T01 | W05 이중 비프, 1.000초 | E08 |
| 아날로그 | 기존 `tick.wav` 그대로 | W09 | E09 |
| 스톱워치 | ST04, 정확히 1초 반복 | 해당 없음 | 해당 없음 |
| 모래시계 | HT04 | HW09 | HE09 |

`createTimerAudio`에 타이머 종류를 전달해 각 창이 해당 음원만 로드한다. 새 음원의 반복은 전체 클립 길이를 사용하고, 원래 소리의 1초 반복에는 필요한 무음만 보충한다. W09나 종료음을 1초로 자르지 않는다. 종료 경고는 설정된 구간이나 타이머 종료 시점에 멈추며 종료음은 한 번 재생한다.

W05는 실제 비프가 약 0.4초까지 있고 그 뒤가 무음이다. 끝 무음만 줄여 48 kHz의 48,000프레임으로 만들었으며, 비프의 속도·음높이는 바꾸지 않았다. `tick.wav`의 SHA-256은 기존 값 `1084dbe5f434aa8b3c1a3188f740377f3887cbf893938272b5cd63aa2246e0b7`과 동일하다.

생성 스크립트: `scripts/prepare-selected-timer-audio.mjs`. 선택된 WAV는 `public/audio/toolkit/digital/`, `public/audio/toolkit/analog/`에 저장한다. 가공·출처·해시는 `artwork/toolkit/audio/manifest.json`, 이용 조건은 `public/audio/toolkit/LICENSE.txt`에 기록했다. Mixkit 자료는 CC0가 아니며 이번 작업은 로컬 적용만 수행했다.

## 선택을 기다리는 추가 후보

`output/timer-sound-samples/additional.html`에서 비교한다. 기존 30개 페이지에도 연결했다.

- 모래시계: HT01–HT10 시계음, HW01–HW10 종료 경고음, HE01–HE10 종료음.
- 스톱워치: ST01–ST10 시계음. 현재 제품에 없는 경고·종료 기능을 추가하지 않았다.
- 총 40개는 기존 후보들과 다른 소스 ID를 사용한다.
- 시계음 미리 듣기는 8초, 경고음은 10초 반복, 종료음은 한 번 재생한다. 원본과 편집한 반복 한 주기도 별도로 보관한다.
- 모래시계는 실제 모래시계 녹음이 아니라 모래·유리·차임 등 적합한 질감의 후보들이다.
- 공급처 다운로드 모달의 요청 제한으로 ST02–ST10은 이미 열람한 카탈로그에 공개된 공식 MP3 미리 듣기 파일을 사용했다. 이것을 원본 WAV라고 표시하지 않으며 MP3 원본을 보존했다. 나머지 31개는 제공처 WAV 원본이다.
- `additional-manifest.json`에 출처, 원본 형식, 편집 과정, 반복 길이, 피크, 원본/미리 듣기 SHA-256을 기록했다.

추가 후보 중 ST04, HT04, HW09, HE09는 사용자 확정에 따라 앱에 적용했다. 비교용 긴 미리 듣기가 아닌 검토한 한 주기 WAV를 바이트 단위로 그대로 복사했다. 로컬 HTML은 폴더 전체와 함께 열면 서버 없이도 사용할 수 있다.

## 모래시계 두 번째 후보

`output/timer-sound-samples/hourglass-v2.html`: HS01–10 시계음, HA01–10 경고음.

- HS01–04: Benboncan의 실제 모래시계 녹음(122863, CC BY 4.0), HS05–08: SteveMeli의 모래 붓기 녹음(215006, CC BY 3.0). 각각 고음 필터와 음량을 달리한 4개 편집본이다.
- HS09–10: 기존 HT01 원음을 무음 페이드 없이 교차 연결한 두 편집본. 실제 모래 녹음 2종과 기존 HT01의 총 3개 원음을 사용한다.
- 0.9초 equal-power overlap과 완만한 레벨 보정으로 반복 구간을 연결했다. 30초 미리 듣기와 실제 반복 WAV를 구분해 저장했다.
- HA01–10: plasterbrain Bell Chime Alert, Ethraiel Soft Alert, Sadiquecat C6 Chime, jerry.berumen gentle ping의 새 원음 4종을 1–3회 신호로 구성한 10개 편집본. 12초 비교본이다. 서로 다른 원음 10개로 표시하지 않는다.
- Freesound 6개 소스는 공개 HQ MP3 미리 듣기를 보존했다. 원본 WAV 마스터가 아니다. `hourglass-v2/originals/`에 MP3, `cycles/`에 반복 WAV, `previews/`에 비교 WAV, `manifest.json`과 `CREDITS.md`에 출처/저작자/라이선스/편집 과정이 있다.
- 두 번째 후보 20개는 참고용으로 남겼고 제품에는 연결하지 않았다. 사용자는 기존 후보 중 HT04와 HW09를 최종 선택했다.

이번 추가 변경 검증: 전체 테스트 170/170 및 빌드 통과, 확정 음원 두 개는 선택 당시 WAV 해시와 일치. 후보 관련 47개 로컬 미디어 경로 모두 HTTP 200, 후보 WAV 해시 20개 서로 다름, 연속음 100ms 구간 RMS는 모두 -41 dBFS보다 높아 무음 구간 없음. Chrome에서 새 20개 후보 표시와 HS02/HA02 재생 동작을 확인했다. 실제 스피커 청감 평가는 사용자가 선택한다. 전체 타입 검사는 이번에 재실행하지 않았으며 아래 결과는 이전 적용 단계의 기록이다.

## 확인 결과

- `npm test`: 170/170 통과.
- `npm run build`: 통과. 기존 Svelte 접근성 경고가 출력된다.
- `npm run check`: 전체 저장소의 기존 오류 873개, 경고 14개로 실패. 이번 수정 파일 `audio.js`, `audio-profiles.test.js`, `TimerApp.svelte`에 대한 진단은 0개였다.
- 새 테스트: 타이머별 로딩 경로, 기존 아날로그 230ms 파형+770ms 무음, W05 1초 반복, W09 전체 8초 반복, 전체 종료음 단발 재생, 중단/해제, 스톱워치의 불필요한 음원 미로딩, WAV 길이·해시.
- 추가 샘플 40개: 전부 디코딩 성공, 소스 ID/미리 듣기 해시 중복 없음, 무음 및 0 dBFS 피크 없음.
- Chrome 개발 화면: 전광판·아날로그 경고음 미리 듣기, 3초 시작→완료, 오류 알림 없음 확인.
- 추가 후보 페이지: 40개 표시, 네 종류 대표 샘플 재생, 선택 요약과 초기화, 확정된 여섯 음원 표시 확인.

실제 Tauri 배포 실행 파일 재패키징, 교실 스피커 청감, 장시간 실제 기기 검사는 이번 범위에서 수행하지 않았다. 다른 작업에서 변경 중인 툴킷 레이아웃·아이콘은 수정하지 않았다.
