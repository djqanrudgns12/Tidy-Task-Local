# 알림장 구현 및 검증 기록

2026-09-21. PRD와 상세 계획을 기준으로 구현했다. 아래 자동 검증과 실제 기기 검증을 구분한다.

## 구현 범위

- 툴킷에 알림장 독립 창과 표시 설정 추가. 기존 도구 숨김 설정을 보존하는 설정 버전 3 이행.
- 로컬 날짜별 한 장, 자동 임시 보관과 명시적 저장 분리, 날짜별 편집 상태와 실행 취소 이력 유지.
- 기존 Tidy 글꼴, 선택 영역 크기·굵게·기울임·밑줄·취소선·색상, Ctrl+Z/Ctrl+Y. 외부 붙여넣기는 일반 텍스트, 내부 복사는 허용된 서식 유지.
- 학생용 흰색 화이트보드, 독립 배율, 접는 서식 도구, 직접 편집, 전체화면과 복귀, 긴 본문 스크롤.
- 최근 기록과 검색·주간·월간 필터, 날짜별 삭제, 휴지통·복원·영구 삭제. 같은 날짜 복원은 기존 문서를 휴지통으로 교환하며 보존.
- 별도 SQLite 저장소, 리비전 충돌 확인, 쓰기 직렬화, 재시도 식별자, 영구 삭제된 ID의 재생성 방지.
- 명시적 저장·삭제·복원 후 정상 백업. 손상 시 사용자 복구 동작으로 원본을 보존하고 백업 복구.
- 알림장과 명단의 보관 완료를 함께 기다리는 종료 조정 및 종료 취소.
- 일반 모드 좌측 작성 패널 상단의 회색 `@Powered by`와 아이콘·초록색 `Clanner`. 아이콘과 서비스명은 `https://www.clanner.kr/` 링크이며 네이티브에서는 외부 브라우저로 연다. 화이트보드에는 표시하지 않는다.
- 알림장은 툴킷 공용 화면을 거치지 않는 전용 진입 번들로 열고, 첫 화면에는 완성된 작성 화면과 본문 자리표시자를 바로 표시한다. 오류처럼 보이던 별도 로딩 문구는 제거했다.
- 문서 조회와 글꼴 설정 조회를 병렬화하고, 사용자 글꼴 파일은 화면 준비를 막지 않도록 백그라운드에서 동시에 불러온다. SQLite 연결은 알림장 단일 창의 수명 동안 재사용한다.

## 계획 대비 구현 선택

- 편집 엔진은 ProseMirror 사용. 기존 메모 편집기는 변경하지 않는다.
- 네이티브 자료는 SQLite, 브라우저 미리보기 자료는 전용 localStorage에 저장하며 실제 사용자 DB와 분리한다.
- 보기 설정은 본문과 분리한 localStorage에 저장한다. 보기 설정 오류가 문서 열기를 막지 않는다.
- 기록은 요약을 읽어 프런트에서 필터하고 50개 단위로 표시한다. 서버 커서 페이지 방식은 사용하지 않았다.
- 날짜별 저장본과 임시본 각각 최신 한 개를 유지하며 문서 공통 수정 시각을 사용한다.
- 백업은 매 입력이 아니라 명시적 저장·휴지통 변경 이후 생성한다. 영구 삭제 전에 이전 백업을 제거하여 복구로 삭제 자료가 되살아나지 않게 한다.

## 남은 수동 검증

실제 Windows 앱에서 한글 IME 조합과 단축키, 전체화면 진입/ESC 후 위치 복구, 여러 모니터와 배율, 트레이 종료와 명단 동시 보관, 외부 링크 열기, 실기기 강제 종료 및 재실행을 확인해야 한다. 브라우저 자동화와 Rust 테스트가 이 검증을 대신하지 않는다. 실행 중인 사용자 앱은 종료하거나 재시작하지 않았다. macOS와 실제 교실 디스플레이 검증은 하지 않았다.
