# 뽑기 결과 팝업 · 긴장감 연출 QA (2026-09-21)

변경:
- 인형 뽑기와 풍선 다트 완료 시 화면 대부분을 채우는 모달 표시. 이름·번호·안내 문구 분리.
- 확인, 닫기, Esc로 닫으면 하단 카드에 동일한 결과 유지. 팝업이 열린 동안 추가 뽑기 단축키 차단.
- 안내 문구는 단어 중간 줄바꿈 없이 표시. 긴 항목 이름은 별도 줄바꿈 처리.
- 후보 3~5곳을 둘러보는 경로, 정지 시간, 집게의 얕은 내려가기 동작을 매번 샘플링. 이어 같은 당첨 대상으로 이동.
- 제외 대상은 경유 후보에서 제거. 당첨 확률과 결과는 기존 추첨 엔진 유지.
- 타이머·소리·완료 시점을 추가 연출 시간과 동기화. 동작 감소 모드는 추가 연출 생략.

검증:
- production build 성공.
- picker 테스트 13개 통과 (경로 다양성, 제외 후보, 종료 위치, 마지막 한 명 포함).
- 브라우저에서 인형/풍선의 경유 동작, 결과 팝업, 동일 당첨자 및 1회 기록, 확인/닫기/Esc, 감소 모드 검증.
- 640px 창과 긴 이름의 팝업·하단 카드 가로 넘침 없음.
- 전체 svelte-check 기존 오류는 남아 있으며 이번 수정 파일의 오류는 해소.
- Windows 패키지 실행은 검증하지 않음.
