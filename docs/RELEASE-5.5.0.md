# Tidy Task 5.5.0 · Tidy 툴킷 출시

## 출시 공지와 화면 구성

**Hello, Tidy toolkit.**
수업에 필요한 순간, 가볍게 꺼내세요.
시간, 집중, 그리고 우리 반의 즐거운 순간. 선생님의 하루를 넓혀줄 새로운 도구함.

흰 바탕과 보라색 포인트, 어두운 쇼케이스에 실제 도구 화면을 배치합니다.
툴킷의 실제 디자인은 그대로 촬영하고, 공지의 타이포그래피와 구성을 별도로 설계했습니다.

1. 첫 만남: 실제 툴바와 아날로그 타이머·뽑기 화면을 큰 이미지로 소개.
2. 시간과 집중: 전광판·아날로그·모래시계·스톱워치, 집중벨 4종.
3. 함께하는 교실: 학급 명단, 간단 뽑기, 토너먼트, 알림장.
4. 나만의 도구함: 6가지 테마, 다크 모드, 가로·세로, 크기 5단계, 도구 표시 설정.

11개 실제 화면과 뽑기 무대 상세 컷을 브라우저 미리보기에서 2배 해상도로 촬영했습니다.
예시 이름과 내용은 촬영용이며 사용자 데이터는 사용하지 않습니다.
이미지에는 실제 도구 화면임을 명시하고, 설명과 시작 경로를 함께 제공합니다.
촬영본은 `public/images/update-5.5/`, 재촬영 스크립트는 `scripts/capture-release-5.5.mjs`입니다.

## 노출과 보관

5.5.0에서 처음 한 번만 **처음 설정** 팝업을 먼저 표시합니다. 학교 등록 뒤 급식창 자동 실행 여부와 Tidy 툴킷 사용 여부를 2단계로 묻고, 선택이 끝난 뒤에만 해당 창들을 자동 실행합니다.
처음 설정 → 환영 안내 → 툴킷 출시 → 기존 5.1.2 공지 순으로 한 창씩 표시합니다.
앞 창이 실제로 닫히기 전에는 다음 창을 만들지 않습니다.
처음 설정 완료 여부는 앱 버전과 무관한 `initial-setup` 키에 `completionCount: 1`로 저장합니다. 완료 또는 명시적 건너뛰기 뒤에는 다음 버전에서도 다시 표시하지 않으며, 저장 실패·비정상 종료로 완료 기록이 남지 않은 경우에만 복구를 위해 다시 표시합니다.
같은 프로세스에서 시작 이벤트가 중복되어도 하나의 시작 Promise로 합쳐 팝업과 자동 실행이 두 번 발생하지 않게 합니다.
숨김 설정은 공지마다 별도 키를 사용합니다. 기존 공지 내용·버전·숨김 이력은 유지합니다.
오늘 그만보기는 다음 로컬 자정까지, 더 이상 보지 않기는 해당 출시 공지에 한해 적용합니다.
일반 닫기는 숨김 설정을 바꾸지 않습니다. 저장 실패 시 안내를 남기고 재시도를 제공합니다.

## 스마트 가이드

툴킷 시작, 시간·집중, 학급·참여, 알림장, 맞춤 설정 패널을 추가합니다.
기존 노트·리마인더·급식·보관함 설명을 유지하고, 상단 목차로 빠르게 이동합니다.
기존의 무제한 노트·전체 기록 TXT 백업 표현을 실제 범위에 맞게 정정합니다.
