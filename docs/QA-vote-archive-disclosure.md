# 기록함 결과 공개 범위 선택 (2026-09-27)

## 동작

- 모든 기록은 원래 발표 설정과 관계없이 `모두 공개`로 열립니다. 다른 기록을 선택하거나 기록함을 다시 열어도 기본값은 동일합니다.
- 후보 투표: 모두 공개 / 순위만 공개 / 당선자만 공개.
- 의견 투표: 모두 공개 / 순위만 공개 / 선택된 항목만 공개.
- 찬반 투표: 모두 공개 / 결과만 공개.
- 같은 드롭다운이 투표 결과 탭과 결과 이미지 탭에 적용됩니다. 탭을 바꿀 때 선택을 유지합니다.
- 모두 공개에서는 개별 득표·득표율과 유효표·기권을 확인합니다. 여러 찬반 안건의 합산 수치는 합계로 표시합니다.
- PNG 미리보기의 Blob을 저장·복사에도 사용합니다. 공개 범위를 바꾸는 동안 이전 모델의 이미지는 보여 주거나 내보내지 않으며, 늦게 완료된 이전 생성 작업은 폐기합니다.
- PNG 파일명에 공개 범위를 포함합니다. 저장된 투표 설정·표·결선 기록은 변경하지 않습니다. 실제 발표와 다시 개표는 기존 발표 설정을 따릅니다.
