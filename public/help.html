시간과 집중 TOOLKIT

남은 시간은 보여 주고,
활동의 끝은 소리로 알려요.

활동에 맞게 시간을 정한 뒤 시작하세요. 진행 중에는 일시정지하고 다시 이어갈 수 있어요.

전광판 타이머큼직한 숫자로 남은 시간을 확인합니다. 시간 설정을 마친 뒤 시작하고, 필요하면 일시정지하거나 다시 설정하세요.
아날로그 타이머시계판의 색으로 남은 시간을 표현합니다. 설정에서 한 바퀴 기준을 30분 또는 60분으로 선택할 수 있어요.
모래시계모래가 줄어드는 모습으로 시간을 보여 줍니다. 설정에서 남은 시간 표시를 켜거나 끌 수 있어요.
스톱워치시작한 뒤 경과한 시간을 측정합니다. 일시정지·재개와 초기화를 사용하고, 설정에서 진행음을 바꿀 수 있어요.
소리와 단축키카운트다운 도구에서는 진행음, 종료 전 알림, 종료음을 각각 설정합니다. 종료 전 알림의 시점과 길이도 조절할 수 있어요. 입력란에 커서가 없을 때 Space로 시작·일시정지합니다.
집중벨벨·사이렌·폭탄·방구 네 가지 소리를 골라 재생합니다. 음량과 음소거를 확인하고, 멈추려면 정지를 누르세요. 다른 소리를 선택하면 재생할 소리가 전환됩니다.

학급 명단 · 뽑기 · 토너먼트 TOOLKIT

우리 반의 이름으로
더 즐거운 참여를.

학급 명단을 먼저 등록하면 뽑기와 토너먼트에서 학생 명단을 불러올 수 있어요.

학급 만들기학급 명단에서 학급을 만들고 번호·이름·성별을 관리하세요. 여러 학급과 기본 학급을 관리하고, 검색·정렬로 학생을 찾아 편집합니다.
명단 가져오기PDF · XLSX · CSV · HWPX 파일 또는 이름·표 붙여넣기로 가져옵니다. 파일은 최대 20MB이며, 미리보기에서 번호·이름·성별 열과 가져올 내용을 확인한 뒤 적용하세요.
모둠 관리모둠을 만들고 학생을 배정하세요. 모둠 이름과 순서를 정리할 수 있습니다. 토너먼트에서 참가 단위를 모둠으로 선택해 불러올 수 있어요.
간단 뽑기 시작학급 명단 / 모둠 뽑기 / 직접 입력 중 대상을 정합니다. 모둠 뽑기와 직접 입력은 목록에 이름을 한 줄씩 넣어 준비하세요. 클래식·인형 뽑기·풍선 다트 중 디자인을 고르고 뽑기 시작 또는 Space를 누르세요.
뽑기 세부 설정한 번씩 골고루를 켜면 뽑힌 대상을 제외합니다. 대상 관리에서 제외할 대상을 확인하고, 직전 뽑기 취소·다시 시작을 사용할 수 있어요. 소리와 동작 감소 모드도 조절할 수 있습니다.
토너먼트 만들기4·8·16·32·64강 중 규모를 고르고 대진표를 만드세요. 이름을 직접 입력·붙여넣기하거나 학급 명단에서 불러옵니다. 빈 자리는 부전승으로 처리됩니다.
대진 준비와 진행준비 화면에서 대진을 섞거나 자리 번호 두 개를 선택해 맞바꾸세요. 경기를 시작한 뒤 승자를 눌러 진출시키고, 같은 승자를 다시 눌러 취소할 수 있어요. 전체·왼쪽·오른쪽·결승 보기와 확대·축소로 대진표를 살펴보세요. 저장된 대회는 목록에서 이어서 진행합니다.

우리 반 알림장 TOOLKIT

오늘의 안내를 기록하고,
큰 화면으로 함께 읽어요.

날짜별 안내와 준비물을 적어 두고 화이트 보드로 펼쳐 보세요.

날짜별 기록날짜 선택 또는 좌우 화살표로 날짜를 이동해 내용을 작성하세요. 기록 열기에서 이전 기록을 찾고 오늘로 돌아올 수 있어요.
본문 서식글꼴과 글자 크기, 굵게·색상 등 서식 도구로 중요한 안내를 강조합니다. 실행 취소·다시 실행으로 편집 내용을 되돌릴 수 있어요.
화이트 보드화이트 보드(전체화면)를 누르면 교실 화면에 크게 띄울 수 있어요. 화면을 넓게 활용하고 필요한 순간에 서식 도구를 펼쳐 사용하세요.
자료 보관작성 중인 내용은 초안으로 자동 보관됩니다. 저장을 누르면 저장본으로 확정하고, 수정 중에는 저장본으로 되돌릴 수 있어요. 최근 알림장에서 날짜·내용을 검색하고 휴지통에서 삭제한 기록을 확인하세요. Tidy Task의 메모 TXT 내보내기에는 알림장이 포함되지 않습니다.

나만의 툴킷 설정

방향과 크기툴바의 설정 버튼에서 가로·세로 방향과 매우 작게부터 매우 크게까지 5단계 크기를 선택하세요. 툴바의 접기 기능으로 공간을 줄일 수도 있어요.
테마와 다크 모드세이지·앰버·오션·로즈·라벤더·슬레이트 6가지 테마를 제공합니다. 다크 모드에서는 어두운 공통 화면을 사용하고, 다크 모드를 끄면 선택한 색상이 적용됩니다. Tidy Task 메모의 15가지 테마와는 별도 설정입니다.
보이는 도구자주 쓰는 도구만 툴바에 표시하세요. 표시를 끄는 것은 도구 버튼을 숨기는 설정이며 기록 삭제 기능이 아닙니다.
외부 툴롤린썬더와 클래너를 브라우저에서 열 수 있습니다. 외부 툴 사용 여부와 표시할 서비스를 설정할 수 있으며, 웹 서비스 이용에는 인터넷 연결이 필요합니다.
공지 표시 설정오늘 그만보기는 오늘 자정까지, 더 이상 보지 않기는 해당 공지에만 적용됩니다. 닫기는 숨김 설정을 바꾸지 않습니다. 환영 안내·툴킷 출시·기존 업데이트 공지는 앞 창을 닫은 뒤 순서대로 표시됩니다.

⌨️ Tidy Task 전체 단축키 사전

Enter 하단 입력창에서 타이핑 후 즉시 할 일을 생성합니다.
Ctrl + Z / Y 타임머신: 잘못 수정한 텍스트나 실수로 삭제한 항목을 이전/이후 단계로 되돌립니다.
Ctrl + S 수동 동기화: 입력 중인 데이터를 즉시 안전하게 저장합니다.
Ctrl + C / V 스마트 다중 생성: 편집 모드에서 여러 줄의 텍스트를 복사한 뒤 앱에 붙여넣으면, 각 줄이 독립된 할 일 항목으로 한 번에 쪼개져 생성됩니다. (편집 모드 시 다중 항목 복사도 가능)
Alt + Shift + N / W 자간 조절: N(좁게), W(넓게) 키를 통해 텍스트 자간을 미세 조정합니다.
Ctrl + B / I / U 스타일 편집: 편집 모드에서 여러 항목을 선택한 후 누르면 각각 굵게(Bold), 기울임(Italic), 밑줄(Underline)이 일괄 적용됩니다.

🪟 다중 윈도우 & Tiny Note NEW

독립된 서브 노트 상단 바의 포스트잇 아이콘이나 시스템 트레이의 '새 Tiny Note'를 누르면, 조그마한 포스트잇 형태의 Tiny Note를 최대 10개까지 띄울 수 있습니다. (우클릭 메뉴의 '새 창 띄우기'는 일반 메모 창을 엽니다) 각 노트는 별도의 데이터를 가집니다.
Tiny Note 아카이빙 Tiny Note 화면 좌측 상단의 아카이빙 버튼(보관함 아이콘)을 누르면, 해당 서브 노트의 완료된 내용 전체가 메인 아카이브(중앙 보관함)로 일괄 전송됩니다.
전체화면 · 롤업 메인 및 Tiny Note의 타이틀바를 더블클릭하면 전체화면으로 전환되고, 다시 더블클릭하면 원래 크기와 위치로 돌아옵니다. Tiny Note는 상단의 화살표 버튼으로 롤업/펼치기를 사용할 수 있으며 상태가 그대로 보존됩니다.
영역 분할 스플리터 메인 화면 내 할 일 목록과 하단 텍스트 메모장 사이의 경계선을 드래그하여, 작업 공간의 높이 비율을 내 마음대로 분할할 수 있습니다.

🗄️ 아카이브 보관함 NEW

중앙 보관함 저장 메인 툴바의 아카이빙 아이콘이나 서브 노트의 전송 버튼을 통해 삭제하기 아까운 기록들을 중앙 보관함으로 영구 저장할 수 있습니다.
스마트 검색 & 복원 보관함 상단의 검색창을 통해 수개월 전의 기록도 즉시 찾을 수 있으며, 클릭 한 번에 다시 메인 노트로 꺼내올 수 있습니다.

일괄 스타일 & 삭제 항목을 여러 개 선택한 뒤 팝업되는 전용 툴바를 이용해 형광펜 색상을 칠하거나, 수십 개의 항목을 동시에 휴지통으로 지울 수 있습니다.
인라인 직접 편집 각 할 일의 글자를 마우스로 누르면 즉석에서 타이핑하여 내용을 수정할 수 있습니다.

🍲 오늘의 급식

학교 연결상단 도구 모음의 급식 아이콘을 누르고 학교 이름을 두 글자 이상 입력하세요. 주소를 확인한 뒤 학교를 등록하면 식단이 열립니다.
창 크기와 날짜크기에 따라 미니·컴팩트·기본·와이드·주간 보기로 바뀝니다. 좌우 화살표로 날짜를 바꾸고 T로 오늘로 돌아옵니다. 주간 보기에서는 한 주씩 이동합니다.
내게 맞게 보기급식 설정에서 표시할 끼니, 알레르기, 영양·원산지 정보, 테마, 글꼴과 글자 크기를 바꿀 수 있습니다. 선택한 알레르기는 메뉴 옆에 별도로 표시합니다.
복사와 오프라인메뉴 복사 버튼 또는 Ctrl+C로 현재 날짜의 메뉴를 복사합니다. 인터넷이 끊겨도 저장된 식단은 계속 볼 수 있습니다. 트레이 메뉴에서도 급식창을 다시 열 수 있습니다.

⚙️ 환경 설정 및 백업

상단 디자인과 테마설정에서 클래식·모던 상단 디자인을 고릅니다. 모던에서는 서식 도구를 필요할 때 펼칠 수 있어요. 메모의 15가지 색상 테마와 다크 모드, 글꼴·크기도 조절할 수 있습니다.
앱 업데이트설정에서 설치된 버전과 새 버전을 확인합니다. 업데이트 안내에서 내려받기를 진행하거나 내일 다시 알림·이 버전 건너뛰기를 선택할 수 있어요.
화면 밖의 창 찾기모니터를 바꾼 뒤 창이 보이지 않으면 작업 표시줄의 Tidy Task 아이콘을 우클릭해 좌표 초기화를 선택하세요.
사용자 커스텀 폰트 시스템 설정 창에서 PC 내의 .ttf 파일 등을 등록해 나만의 글꼴을 사용하세요. UI 전용 글꼴과 본문용 글꼴을 분리해 적용할 수 있습니다.
리마인더 마스터 토글 방해받고 싶지 않은 회의 시간이라면, 환경 설정에서 '리마인더 알림'을 완전히 꺼버릴 수 있습니다.
