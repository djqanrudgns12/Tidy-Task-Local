# 5.5.0 출시 공지 · 스마트 가이드 검수

## 반영

- 패키지·잠금 파일·Rust 앱 버전·설정 표시·가이드·배포 문서를 5.5.0으로 갱신.
- 기존 `UpdateNotice.svelte`와 5.1.2 공지 ID, 숨김 키 보존.
- 새 공지: 독립 진입점 `release-toolkit`, 4개 페이지, 툴킷 실행·가이드 연결.
- 11종 실제 컴포넌트 화면과 뽑기 무대 상세 컷을 2배 해상도로 촬영. 사용자 데이터 대신 예시 이름 사용.
- 흰 바탕·보라색 포인트·어두운 제품 쇼케이스로 디자인 변경.
- 스마트 가이드: 13개 목차와 기능별 패널, 실제 화면, 툴킷 전 기능 설명.
- 시작 안내는 이전 창이 닫힌 뒤 다음 창을 열고 모니터 배율과 작업영역에 맞춰 크기를 제한.
- 병행 작업의 처음 설정 흐름과 연결된 기존 시작 절차를 보존.

## 검증 결과

- `npm test`: 246개 통과. 새 공지의 독립 숨김 키, 창 순서, 실패 시 중단, 고배율 화면 크기 포함.
- `npm run build`: 통과.
- `cargo check --manifest-path src-tauri/Cargo.toml --locked`: 통과.
- `scripts/verify-release-5.5.mjs`: 740×820, 390×720, 320×460에서 공지 4개 페이지 검증.
- 모든 이미지 디코딩 성공, 가로 넘침 없음, 닫기·오늘 그만보기·더 이상 보지 않기·Escape 검증.
- 저장 실패를 주입해 팝업이 유지되고 오류 안내 후 닫을 수 있는지 확인.
- 가이드 960·600·390px에서 가로 넘침 없음, 목차 13개 링크와 이미지 확인.
- `npm run check`: 프로젝트 기존 타입·접근성 진단으로 전체 실패. 새 공지 컴포넌트·창 순서 모듈·새 테스트 파일의 진단은 해소.

## 확인 범위

촬영·UI 검증은 실제 프런트엔드 컴포넌트의 브라우저 미리보기에서 수행했습니다.
설치판의 네이티브 창 연속 표시와 다중 모니터 실기 테스트, 설치 파일 배포는 수행하지 않았습니다.
공지별 숨김은 브라우저 테스트에서 격리된 로컬 저장소, 설치판에서 기존 Tauri 설정 저장소를 사용합니다.
