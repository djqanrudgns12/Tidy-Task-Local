# 간단 뽑기: 무대 확대 및 대상 표시 (2026-09-21)

- 기본 창 1440×920. 모니터 작업 영역이 작으면 기존 크기 제한 로직으로 맞춤.
- 무대 높이는 창 높이에 따라 증가. 상단 선택 영역과 버튼 정리.
- 무대에 대상 이름 표시. 30명 이하는 슬롯을 유지하고 뽑힌 대상만 제거하여 빈자리가 남음.
- 대상이 30명보다 많아도 전체 후보에서 추첨하며 실제 당첨자를 표시 슬롯에 연결.
- 결과를 무대 하단 띠로 표시하여 남은 대상 확인 가능.
- 동작 감소 모드는 기본 OFF, 명시적인 저장 토글. OS 설정이 자동 활성화하지 않음.
- 뽑기, 토너먼트, 공용 툴킷 글꼴 덮어쓰기를 제거하여 앱 UI 글꼴 사용.

검증:
- npm run build 통과.
- cargo check 통과.
- picker 단위 테스트 11개 통과.
- large-stage-check.mjs: OS 동작 감소 상태에서 기본 OFF, 인형/풍선 이름 표시, 실제 당첨자 제거, 나머지 슬롯 유지, 취소 복원, 반복 허용, 감소 모드, 640/960/1440/1680 너비 확인.
- large-edge-check.mjs: 45명 후보의 표시 이름과 당첨자 일치, 동작 감소 ON/OFF 재진입 유지, 툴킷 글꼴 상속 확인.
- 전체 svelte-check는 기존 범위의 873개 오류/14개 경고로 실패. 이번 수정의 picker/toolkit/tournament 파일에는 진단 없음.
- 실제 패키징된 Windows 앱 실행 검증은 수행하지 않음. 브라우저 화면 및 Rust 컴파일 검증 완료.
