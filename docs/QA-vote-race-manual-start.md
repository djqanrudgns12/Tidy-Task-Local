# 실시간 레이스와 개표 시작 방식 검수 — 2026-09-27

## 동작

- 모든 개표 방식은 대기 상태에서 시작합니다. 투표 종류와 공개 범위, 다시 보기, 저장된 개표 위치 복원에 동일하게 적용됩니다.
- 자동 재생 버튼을 눌러야 연속 개표가 시작됩니다. 다음 버튼은 한 걸음만 진행합니다.
- 바로 결과는 결과 공개 버튼을 눌러야 공개합니다. 빈 투표나 이미 개표가 끝난 저장 상태도 명시적으로 결과를 공개합니다.
- 선생님 전용 창에도 결과 공개 버튼과 상태를 연결했습니다.

## 레이스 디자인

- 짙은 청록색 경기장 안에 후보별 레인을 연결하고 출발선, 체커보드, 중앙 점선, 트랙 가장자리 패턴을 배치했습니다.
- 득표에 따라 캐릭터가 전진하고 후보 색 궤적이 이어집니다. 미공개 득표를 이용하지 않고 기존 raceGoal의 축척을 사용합니다.
- 출발 대기, 진행 중, 잠시 멈춤, 완료를 구분합니다. 공개된 용지 수와 선두/공동 선두를 표시합니다.
- 후보가 많으면 득표와 판세를 가로로 배치합니다. 이름과 득표 영역의 줄 높이를 제한해 레인 밖으로 넘치지 않게 했습니다.
- 움직임 줄이기 설정에서는 위치 전환과 점프 애니메이션을 제거합니다.
