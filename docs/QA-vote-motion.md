# 개표 가독성과 당선 축하 연출 (2026-09-27)

## 구현

- 용지의 scaleY 접기 효과를 제거했습니다. 12px 이동으로 240ms 동안 안착하며 글자 비율·용지 높이는 유지합니다.
- 도장은 180ms 뒤 등장, 집계 획은 300ms부터 표시합니다. 같은 후보가 연속으로 나와도 획 연출을 다시 재생합니다.
- 자동 개표 간격은 느리게 2800ms / 보통 2000ms / 빠르게 1400ms입니다. 빠르게에서도 핵심 연출 뒤 약 1초의 읽는 시간을 확보합니다.
- 확정된 후보 당선자는 별도 축하 장면에서 동시에 공개합니다. 650ms 준비 → 이름·그림·월계수·당선 리본 → 3차 색종이 → 결과판 순서입니다.
- 색종이는 144개, 중앙 이름을 피하는 양옆 경로로 재생하며 종료·화면 이동 시 정리합니다. 여러 명일 때 이름과 그림을 입자보다 위에 표시합니다.
- 기본 6.5초 뒤 결과로 이동하며 여러 당선자는 읽는 시간을 더 줍니다. 결과 보기/Esc로 즉시 넘길 수 있고 버튼에서 넘긴 경우 결과판으로 키보드 초점을 복구합니다.
- 동점만 있거나 전부 기권이면 당선 축하가 나오지 않습니다. 일부 당선+동점이면 확정된 당선자만 축하하고 남은 자리가 동점임을 명시합니다.
- 움직임 줄이기에서는 움직이는 입자 없이 정적인 축하 장면을 제공합니다. PNG의 공유용 결과 렌더러는 기존 내용을 유지합니다.
- 결과 이미지 준비 실패 시에도 텍스트 대체 화면으로 진행합니다.

## 검증

- 투표/결과 이미지 테스트 57개 통과. 프로덕션 빌드 통과.
- Svelte 진단: 이번 변경 파일 오류·경고 없음. 전체 검사는 기존 자리 배치 테스트 파일 3곳의 오류 18개로 실패합니다.
- 브라우저 빠른 개표 표본에서 용지 높이 481.609375px 유지, 변환 행렬의 가로·세로 배율 모두 1 확인.
- 실제 다시 개표→결과 흐름: 축하 입자 144개, 종료 후 0개. 동점은 축하 장면 0개. 움직임 줄이기는 움직이는 입자 0개·정적 장식 1개. 런타임 오류 없음.
- 별도 컴포넌트 화면에서 1366/1024px 폭, 당선자 1~4명, 긴 이름, 좁은 650px 폭의 2명 결과를 검수했습니다.
- 검수 스크립트·이미지·수치는 `output/vote-motion/`에 있습니다. 브라우저 검증이며 실제 Tauri/전자칠판의 DPI·효과음 청취는 수행하지 않았습니다.
