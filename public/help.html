📖 Tidy Task 스마트 가이드 v5.0.0

Tiny Note와 아카이브 등 새롭게 추가된 핵심 기능을 카테고리별로 안내합니다.

⌨️ Tidy Task 전체 단축키 사전
Enter / Tab 하단 입력창에서 타이핑 후 즉시 할 일을 생성합니다.
Ctrl + Z / Y 타임머신: 잘못 수정한 텍스트나 실수로 삭제한 항목을 이전/이후 단계로 되돌립니다.
Ctrl + S 수동 동기화: 입력 중인 데이터를 즉시 안전하게 저장합니다.
Ctrl + C / V 스마트 다중 생성: 여러 줄의 텍스트를 복사한 뒤 앱에 붙여넣으면, 각 줄이 독립된 할 일 항목으로 한 번에 쪼개져 생성됩니다. (편집 모드 시 다중 항목 복사도 가능)
Alt + Shift + N / W 자간 조절: N(좁게), W(넓게) 키를 통해 텍스트 자간을 미세 조정합니다.
Ctrl + B / I / U 스타일 편집: 편집 모드에서 여러 항목을 선택한 후 누르면 각각 굵게(Bold), 기울임(Italic), 밑줄(Underline)이 일괄 적용됩니다.
🪟 다중 윈도우 & Tiny Note NEW
무제한 서브 노트 메인 노트 바깥에서 바탕화면을 우클릭하여 '새 창 띄우기'를 선택하면, 조그마한 포스트잇 형태의 Tiny Note를 여러 개 띄울 수 있습니다. 각 노트는 별도의 데이터를 가집니다.
Tiny Note 아카이빙 Tiny Note 화면 좌측 상단의 아카이빙 버튼(보관함 아이콘)을 누르면, 해당 서브 노트의 완료된 내용 전체가 메인 아카이브(중앙 보관함)로 일괄 전송됩니다.
전체화면 · 롤업 메인 및 Tiny Note의 타이틀바를 더블클릭하면 전체화면으로 전환되고, 다시 더블클릭하면 원래 크기와 위치로 돌아옵니다. Tiny Note는 상단의 화살표 버튼으로 롤업/펼치기를 사용할 수 있으며 상태가 그대로 보존됩니다.
영역 분할 스플리터 메인 화면 내 할 일 목록과 하단 텍스트 메모장 사이의 경계선을 드래그하여, 작업 공간의 높이 비율을 내 마음대로 분할할 수 있습니다.
🗄️ 아카이브 보관함 NEW
중앙 보관함 저장 메인 툴바의 아카이빙 아이콘이나 서브 노트의 전송 버튼을 통해 삭제하기 아까운 기록들을 중앙 보관함으로 영구 저장할 수 있습니다.
스마트 검색 & 복원 보관함 상단의 검색창을 통해 수개월 전의 기록도 즉시 찾을 수 있으며, 클릭 한 번에 다시 메인 노트로 꺼내올 수 있습니다.
🔔 스마트 리마인더 시스템 NEW
마감일 뱃지 할 일 좌측의 날짜 뱃지를 눌러 마감일을 지정하세요. 잔여 일수에 따라 뱃지가 D-3 (빨강), D-7 (초록) 등으로 자동 변환됩니다.
투명도 조절 기능 리마인더 팝업창 상단의 눈알 아이콘을 드래그하여 알림창의 투명도를 내가 원하는 대로 세밀하게 조절할 수 있습니다.
알림 지연 타이머 리마인더 팝업 하단의 '시간 지정' 🕒 버튼을 누르면, 내가 원하는 정확한 시간과 분 단위로 알람을 조용히 연기(Snooze)시킬 수 있습니다.
✏️ 다중 편집 모드 & 일괄 디자인
편집 모드 전환 하단의 펜 아이콘(편집 모드) 버튼을 누르거나 우클릭 메뉴를 통해 항목 다중 선택 상태로 전환합니다.
일괄 스타일 & 삭제 항목을 여러 개 선택한 뒤 팝업되는 전용 툴바를 이용해 형광펜 색상을 칠하거나, 수십 개의 항목을 동시에 휴지통으로 지울 수 있습니다.
인라인 직접 편집 각 할 일의 글자를 마우스로 누르면 즉석에서 타이핑하여 내용을 수정할 수 있습니다.
⚙️ 환경 설정 및 백업
사용자 커스텀 폰트 시스템 설정 창에서 PC 내의 .ttf 파일 등을 등록해 나만의 글꼴을 사용하세요. UI 전용 글꼴과 본문용 글꼴을 분리해 적용할 수 있습니다.
리마인더 마스터 토글 방해받고 싶지 않은 회의 시간이라면, 환경 설정에서 '리마인더 알림'을 완전히 꺼버릴 수 있습니다.
데이터 안전 내보내기 시스템 트레이 혹은 우클릭 메뉴의 '텍스트로 내보내기'를 통해 지금까지 쓴 모든 기록을 .txt 로 안전하게 로컬 백업합니다.
