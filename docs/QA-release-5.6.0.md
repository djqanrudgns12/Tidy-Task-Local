# 5.6.0 새 소식과 처음 설정

## 시작 흐름

- 메인 데이터 초기화 전에 기존 데이터 및 시작 프로필을 확인한다.
- 신규 사용자는 처음 설정을 마친 후 5.6.0 공지 하나를 본다. 설정 중 강제 종료해도 신규 프로필을 유지한다.
- 기존 사용자는 과거 처음 설정 완료 값이 없어도 처음 설정을 다시 보지 않는다.
- 개발자의 말, 5.1.2, 5.5.0 개별 공지는 시작 큐에서 제외한다.
- 닫기/X/Escape는 이번 창만 닫는다. 오늘 그만보기는 다음 날 자정까지, 이 공지 그만보기는 해당 공지 ID에 영구 적용한다.
- 설정의 새로운 소식 버튼은 숨김 여부와 관계없이 다시 연다. 연속 클릭은 같은 창을 사용한다.

## 구성

- 기본 창 600×1040 세로형, 공지를 여는 창이 있는 모니터의 작업 영역과 배율에 맞춰 축소. 최대화 비활성화.
- 화면 높이가 부족하면 폭도 같은 비율로 축소하고, 읽을 수 있는 최소 폭은 유지한다. 4K 작업 영역 3840×2040, 150% 배율에서는 600×1040 논리 크기를 유지한다.
- 제목은 내장 MaplestoryB 글꼴로 강조한다. 도구 카드와 전체 도구 분류는 제목·패널·태그 색을 연결하고, 선택 탭은 진한 초록 바탕으로 구분한다.
- 네 탭: 5.6.0 새 소식 / 툴킷 전체 / 지난 업데이트 / 롤링 썬더.
- 툴킷 전체는 실제 등록된 12가지 도구를 네 용도로 묶어 모두 소개한다. 타이머 4종·점수판 3종은 12가지 도구에 포함되며, 외부 서비스·설정은 별도로 소개한다.
- 지난 업데이트: 5.5.3 앱 업데이트·날짜 선택·사용성, 5.5.0 툴킷, 5.1 급식창·상단 디자인·테마.
- 실제 구성요소를 브라우저에서 예시 자료로 촬영한 WebP 12개를 사용한다. 촬영 정보는 `public/images/update-5.6/captures.json`, 재촬영은 `scripts/capture-release-5.6.mjs`.
- 원본 고해상도 이미지는 확대 보기에서 제공하고, 닫은 뒤 원래 버튼으로 초점을 돌려준다.
