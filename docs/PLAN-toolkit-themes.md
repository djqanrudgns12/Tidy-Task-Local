# 툴킷 공통 테마 구현 계획

## 목표
툴킷 설정의 툴바 방향 위에서 6가지 색상과 독립적인 다크 모드를 선택한다. 열린 모든 툴킷 창과 포털 메뉴에 즉시 적용하고 재실행 후에도 유지한다.

## 팔레트
- 세이지 그린: 차분한 녹색, 기본 테마
- 오션 블루: 선명한 파랑
- 라벤더: 부드러운 보라
- 로즈: 따뜻한 분홍
- 앰버: 편안한 호박색
- 슬레이트: 절제된 청회색
6개 밝은 테마와 1개 공통 다크 모드의 배경, 패널, 강조 면, 본문, 보조 글자, 테두리, 액션 색을 공통 토큰으로 정의한다. 본문·보조 글자는 일반 텍스트 대비 4.5:1 이상을 검증한다. 강조 버튼은 흰 글자와 대비되는 별도 진한 색을 쓴다.

다크는 Tidy Task #23272e/#2b3039, Tiny Note #334155의 차콜/슬레이트를 참조한다. 다크 토글을 끄면 저장된 컬러 테마가 복원된다.

## 구현 순서
1. 테마 정의 및 저장 필드를 JS/Rust에 함께 추가. 기존 설정은 기본 그린/라이트로 안전하게 정규화.
2. 공통 appearance 구독을 툴킷 설정 저장/이벤트에 연결. 메인 앱 글꼴 구독은 유지. 초기 읽기와 이벤트 경쟁 및 해제 처리.
3. 설정 패널: 색상 견본과 드롭다운, 설명, 독립 다크 토글. 기존 공통 Select와 Switch 사용.
4. 툴바, 메뉴, 타이머, 알림장, 뽑기, 학급 명단, 집중벨, 토너먼트의 UI 색을 공통 토큰에 연결. 그림/사용자 문서 서식/무대 팔레트는 의미를 보존.
5. 대비 및 설정 단위 테스트, Svelte 검사, 빌드, Rust 검사. 브라우저에서 6개 밝은 테마 + 동일한 다크 모드, 열린 창 동기화, 포털 메뉴, 재로드 유지와 좁은 설정창을 검증.
