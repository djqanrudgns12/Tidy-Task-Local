# Tidy Task — 선생님의 업무와 수업을 함께 돕는 데스크톱 도구

> TPICKS 프로그램 등록용 제품 설명 자료
> 작성일: 2026년 10월 1일 · 기능 확인 기준: Tidy Task 5.6.5 · 제작: 찰떡쌤

## 1. 등록용 기본 정보

- **도구 이름:** Tidy Task
- **한 줄 소개:** 할 일과 메모부터 타이머·뽑기·알림장·투표·자리 배치·급식까지, 선생님의 업무와 수업을 한 프로그램에서 관리하세요.
- **분야:** 교사 업무 관리, 학급 운영, 수업 보조, 시간 관리, 학생 참여, 학급 자치
- **주요 사용자:** 초등·중등·고등 교사, 담임교사, 교과교사, 학급 활동 진행자
- **학생 이용 방식:** 교사가 PC에서 실행하고 전자칠판·TV·프로젝터로 화면을 보여 주거나, 학생이 해당 PC의 키보드로 투표에 참여합니다.
- **학교급·학년:** 특정 학년 전용이 아닙니다. 초등 1~6학년과 중·고등학교에서 활동 내용과 화면 설정을 바꾸어 활용할 수 있습니다.
- **과목:** 전 교과 수업 운영, 창의적 체험활동, 학급 자치, 국어, 수학, 사회, 도덕, 체육 등
- **형태:** Windows PC에 설치하는 데스크톱 프로그램
- **설치 파일·버전별 안내:** [Tidy Task 다운로드 페이지](https://github.com/djqanrudgns12/Tidy-Task-Local/releases)

## 2. 프로그램 소개

Tidy Task는 선생님의 할 일, 기억해 둘 내용, 다시 꺼내 쓸 기록과 교실 활동 도구를 한곳에 모은 프로그램입니다. 바탕화면에 작은 메모 창을 띄워 업무를 정리하고, 수업 중에는 Tidy 툴킷에서 필요한 도구를 별도 창으로 꺼내 사용할 수 있습니다.

기본 메모와 할 일 관리에 더해 12개 교실 도구를 제공합니다. 타이머, 시계, 간단 뽑기, 알림장, 토너먼트, 집중벨, 주사위, 점수판, 학급 온도계, 학급 투표, 자리 배치, 학급 명단이 포함됩니다. 학교를 등록해 사용하는 독립 급식창도 있습니다. 타이머는 4종, 점수판은 3종을 선택할 수 있습니다.

교실에서 자주 하는 일을 짧은 조작으로 처리하는 데 초점을 맞췄습니다. 발표자 뽑기, 활동 시간 안내, 준비물 공지, 학급 회장 선거, 모둠 활동 점수 기록, 학급 공동 목표 관리, 자리 바꾸기 등을 여러 웹페이지로 이동하지 않고 진행할 수 있습니다.

## 3. 사용 환경과 준비물

- Windows PC와 설치 파일이 필요합니다. 배포 설치 파일은 `.exe` 형식입니다.
- 학생에게 화면을 보여 주려면 전자칠판·TV·프로젝터 또는 외부 모니터를 연결합니다.
- 소리 안내와 집중벨을 사용하려면 스피커가 필요합니다. 학급 투표에는 숫자키가 있는 키보드가 필요합니다.
- Tidy Task 자체의 계정 가입 없이 로컬 자료를 작성하고 사용할 수 있습니다.
- 메모와 대부분의 교실 도구는 인터넷 없이 사용할 수 있습니다. 학교 검색·새 급식 조회, 앱 업데이트, 시계 표준시 보정, 외부 웹 서비스 연결은 인터넷이 필요합니다.
- 투표의 기본 안내 음성은 내장되어 있습니다. 선택 기능인 제목·이름·안건 읽기는 처음 음성 모델을 준비할 때 약 380MB를 내려받으며, 이후 해당 PC에서 음성을 만듭니다.
- 교사 PC에 자료가 저장되는 방식입니다. 학생 각자의 기기에서 접속하는 온라인 수업방이나 투표 링크를 만드는 기능은 아닙니다.

## 4. 처음 사용하는 순서

1. 다운로드 페이지에서 Windows 설치 파일을 내려받아 설치하고 실행합니다.
2. 처음 설정에서 학교 등록, 급식창 자동 열기, Tidy 툴킷 사용 여부를 정합니다. 필요에 따라 건너뛰고 나중에 설정할 수 있습니다.
3. 메모 창에 오늘 할 일을 입력하고, 아래 메모 공간에 기억할 내용을 적습니다.
4. 메모 창의 **설정 → 동작 → Tidy 툴킷**을 켜면 교실 도구 모음이 나타납니다. 모던 상단 디자인에서는 메뉴에서도 켤 수 있습니다.
5. **학급 명단**에서 학급과 학생을 등록하면 뽑기·개인 점수판·자리 배치 등에서 명단을 활용할 수 있습니다.
6. 툴킷에서 도구를 눌러 별도 창으로 열고, 수업 화면으로 옮겨 사용합니다. 필요한 경우 전체화면이나 항상 위 기능을 사용합니다.
7. 처음 보이는 툴바에 없는 도구는 **툴킷 설정**에서 활성화합니다. 기본 표시 도구는 타이머·간단 뽑기·알림장·학급 투표·자리 배치·학급 명단입니다.

## 5. 할 일과 메모 관리

### 5.1. Tidy Task 노트

- 할 일을 한 줄씩 입력하고 Enter로 추가합니다. 각 항목의 내용과 마감일을 수정할 수 있습니다.
- 완료한 항목은 같은 창의 **마감된 일**로 이동합니다. 완료를 취소하여 할 일 목록으로 돌릴 수 있습니다.
- 손잡이를 위아래로 끌어 할 일 순서를 바꿉니다. 키보드로도 순서를 조정할 수 있습니다.
- **여러 항목 선택**으로 여러 할 일을 함께 선택하여 서식을 바꾸거나 일괄 완료·삭제할 수 있습니다.
- 여러 항목 선택 상태에서 글자를 편집하고 있지 않을 때 여러 줄을 붙여넣으면 한 줄씩 할 일로 추가됩니다. 한 번에 최대 10줄입니다.
- 아래의 **중요한 일 메모**에는 회의 내용, 업무 절차, 자주 확인할 정보를 길게 적습니다.
- 할 일과 메모 사이의 경계선을 끌어 영역 크기를 조절하고, 마감된 일·메모 영역의 표시 여부를 설정합니다.
- 글꼴·크기·굵게·기울임·밑줄·글자색·형광펜·자간·기호·링크 등으로 내용을 꾸밉니다.
- 입력 내용은 자동 저장되며 Ctrl+S로 바로 저장할 수 있습니다. 실행 취소·다시 실행도 지원합니다.
- 여러 노트 창을 띄워 업무, 학급, 회의 등 용도별로 나눌 수 있습니다. 메인 창 외에 일반 노트 창은 최대 10개입니다.
- 창 제목, 위치와 크기, 불투명도, 항상 위 상태 등을 조절하여 바탕화면에서 사용합니다.

### 5.2. Tiny Note

- 짧은 메모를 적는 작은 스티커형 독립 창입니다. 최대 10개까지 열 수 있습니다.
- 제목과 본문을 적고, 색상과 서식을 바꾸며, 필요한 위치에 놓습니다.
- 본문을 접어 제목줄만 남기거나 다시 펼칠 수 있습니다. 항상 위 설정도 가능합니다.
- 보관함 버튼을 누르면 **제목과 메모 내용**이 아카이브에 저장되고 해당 Tiny Note가 비워집니다.
- 전화 메모, 임시 안내, 수업 중 떠오른 아이디어, 다음 시간 준비사항을 짧게 남기기에 적합합니다.

### 5.3. 아카이브

- 보관한 Tiny Note를 별도 창에서 다시 확인하는 기록함입니다. 완료된 할 일 목록과는 구분됩니다.
- 제목·본문 검색, 북마크, 포스트잇 보기·목록 보기, 드래그 순서 변경을 지원합니다.
- 기록의 제목·본문·테마 색을 고치거나, 아카이브에서 새 기록을 만들 수 있습니다.
- 내용을 복사하거나 **꺼내기**로 다시 Tiny Note 창에 가져옵니다. 여러 기록을 선택하여 정리할 수도 있습니다.
- 반복해서 쓰는 안내문, 상담 후 정리한 참고사항, 회의 메모, 업무 문구 등을 모아 두는 데 활용합니다.

### 5.4. 마감일과 통합 리마인더

- 할 일마다 달력에서 마감일을 정합니다. 새 할 일을 입력할 때도 날짜를 미리 지정할 수 있습니다.
- 여러 메모 창의 마감 임박 항목을 모아 보여 줍니다. 기본 대상은 마감 3일 전부터이며 마감이 지난 미완료 항목도 포함합니다.
- 알림창에서 항목을 완료 처리하거나, **1시간 후**, **시간 지정**으로 다시 알릴 시간을 정합니다.
- **오늘 끄기**로 당일 알림을 쉬거나 통합 리마인더를 설정에서 켜고 끕니다.
- 알림창의 불투명도를 조절할 수 있습니다. 앱이 실행 중일 때 점검하는 알림이므로 앱을 종료한 상태의 원격 알림 기능과는 다릅니다.

## 6. Tidy 툴킷의 교실 도구

### 6.1. 타이머 4종

| 종류 | 보여 주는 방식 | 활용 예 |
| --- | --- | --- |
| 전광판 타이머 | 남은 시간을 큰 숫자로 표시 | 문제 풀이, 발표 준비, 평가 시간 |
| 아날로그 타이머 | 시계판의 색과 바늘로 남은 시간을 표시 | 저학년 활동, 모둠 토의, 정리 시간 |
| 모래시계 | 줄어드는 모래로 진행을 표시 | 독서, 조용한 개인 활동, 쉬는 시간 |
| 스톱워치 | 시작 후 경과 시간과 중간 기록을 표시 | 체육, 실험, 수행 시간 비교 |

- 카운트다운 타이머는 최대 60분까지 설정합니다. 30초~40분의 빠른 설정과 분·초 직접 입력을 제공합니다.
- 시작·일시정지·계속하기·다시 시작을 지원하고, 1·5·10분 단위로 시간을 더하거나 뺍니다.
- 활동 제목과 설명을 적어 학생에게 과제와 준비물을 함께 보여 줄 수 있습니다.
- 아날로그 타이머는 30분·60분 눈금을 선택하고 바늘로 시간을 조정합니다. 모래시계는 남은 시간 숫자를 켜고 끕니다.
- 스톱워치는 누적 시간과 구간 기록을 남기고 기록 타임라인을 확인합니다.
- 진행음·종료 경고음·종료음을 각각 선택하거나 끄고, 미리 들어 볼 수 있습니다. 경고 시작 시점과 길이도 조절합니다.
- 별도 타이머 창을 여러 개 열 수 있으며, 전체화면과 항상 위 기능을 지원합니다.
- 소리 등 설정은 저장하지만 진행 중 측정값과 스톱워치 기록은 창을 닫은 뒤 다시 이어지는 영구 기록이 아닙니다.

### 6.2. 시계

- 디지털·아날로그 시계를 골라 현재 한국 시각을 크게 보여 줍니다.
- 초 표시, 12·24시간 표시, 활동 제목, 아날로그 보조 표시 등을 설정합니다.
- 전체화면에서 잠시 조작하지 않으면 도구가 숨고 시계 중심의 화면이 됩니다.
- 인터넷이 연결되면 시간 서버를 이용해 표시 시각을 보정합니다. Windows 자체의 시각 설정을 바꾸지는 않습니다.
- 연결에 실패하면 PC 시각으로 계속 표시하며, 표준시·PC 시각 표시로 현재 기준을 확인합니다.

### 6.3. 간단 뽑기

- 학급 명단의 전체 학생·남학생·여학생, 직접 입력한 이름이나 활동, 직접 입력한 모둠 이름을 대상으로 뽑습니다.
- **클래식·인형 뽑기·풍선 다트** 중 연출을 고릅니다.
- **한 번씩 골고루**로 이미 뽑힌 대상을 제외하거나, 대상 관리에서 특정 대상을 직접 제외합니다.
- **바로 결과 보기**로 연출 없이 즉시 결과를 확인할 수 있습니다. 이 선택은 창을 열 때마다 꺼진 상태로 시작합니다.
- 직전 뽑기 취소, 기록 초기화, 직접 입력 목록 저장·불러오기, 효과음·동작 감소 설정을 지원합니다.
- 직접 입력 목록은 최대 500개입니다. 모둠 뽑기는 학급 명단의 모둠을 자동으로 불러오지 않으며, 모둠 이름을 직접 입력하여 사용합니다.
- 뽑기 이력과 제외 상태는 해당 창의 사용 세션에 적용됩니다. 창을 닫으면 이력은 사라지고 저장한 목록·설정은 남습니다.
- 발표자 선정, 활동 순서, 놀이 과제, 역할 정하기 등에 활용합니다.

### 6.4. 알림장

- 날짜별로 준비물·과제·가정 안내를 적는 독립 알림장입니다.
- 날짜 선택, 앞뒤 날짜 이동, 오늘로 돌아가기, 글꼴·크기·굵게·기울임·밑줄·취소선·글자색을 지원합니다.
- 작성 중 내용은 초안으로 자동 보관합니다. **저장**은 저장본 확정이며, **저장본으로**는 이후 수정 내용을 취소하고 저장본으로 돌아갑니다.
- **화이트 보드** 전체화면에서 학생에게 보여 주고, 글자 배율을 조절하거나 그 화면에서 직접 편집할 수 있습니다.
- 날짜·내용 검색, 최근 기록, 주간·월간 필터, 휴지통·복원·영구 삭제를 지원합니다.
- 하교 전 준비물 안내, 하루 일정, 학급 약속, 내일 과제를 큰 화면으로 함께 확인할 때 활용합니다.

### 6.5. 토너먼트

- 4·8·16·32·64강 대진표를 만들고 참가자와 대회 이름을 정합니다. 빈자리는 부전승으로 처리합니다.
- 참가자를 직접 입력하거나 학급 명단의 **학생·모둠**을 불러옵니다.
- 명단에서 참가자를 선택하고 지정 자리에 배정하며, 정원만큼 랜덤 선택·번호순 배정·자리 교환·대진 섞기를 할 수 있습니다.
- 경기마다 승자를 누르면 다음 라운드로 진출합니다. 같은 승자를 다시 누르면 진출을 취소합니다.
- 전체·왼쪽·오른쪽·결승 보기, 확대·축소, 큰 글씨, 우승자 축하 화면을 제공합니다.
- 대회별 자동 저장과 저장된 대회 이어서 진행, 결과 초기화를 지원합니다.
- 체육 경기, 모둠 퀴즈 대회, 놀이 활동의 진행 상황을 한눈에 보여 줄 때 활용합니다.

### 6.6. 집중벨

- **벨·사이렌·폭탄·방구** 네 종류의 소리를 한 번씩 재생합니다.
- 같은 소리를 다시 누르면 처음부터 재생하고, 다른 소리를 누르면 그 소리로 전환합니다.
- 음량·음소거·정지·전체화면을 지원합니다. Esc로 소리를 멈출 수 있습니다.
- 활동 전환, 모둠 토의 마무리, 안내 시작 신호 등에 사용합니다.

### 6.7. 주사위

- 주사위를 1~3개 굴려 각 눈을 표시하고, 여러 개일 때는 덧셈식과 합계를 보여 줍니다.
- 두 개가 같으면 **더블**, 세 개가 모두 같으면 **트리플** 표시가 나타납니다.
- 마지막으로 고른 개수를 기억하며, 효과음과 동작 줄이기를 설정할 수 있습니다.
- 수학의 수·연산·확률 활동, 보드게임, 이동 칸 수나 놀이 규칙 정하기에 활용합니다.

### 6.8. 점수판 3종

| 종류 | 대상 준비 | 명단 연결 |
| --- | --- | --- |
| 개인 점수판 | 학급 명단의 학생을 불러옴 | 학생 추가·이름 수정이 반영됨 |
| 모둠 점수판 | 모둠 수를 정하고 이름을 수정 | 명단의 모둠과 별도 관리 |
| 커스텀 점수판 | 항목을 한 줄씩 직접 입력 | 명단과 별도 관리 |

- 1·2·5·10점 또는 직접 정한 단위로 점수를 더하거나 뺍니다. 음수도 사용할 수 있습니다.
- 점수를 두 번 눌러 직접 수정하고, 상위 순위 배지와 큰 화면으로 점수를 보여 줍니다.
- 개인 점수판에서는 여러 학생을 선택하거나 명단의 모둠 단위로 선택하여 함께 점수를 바꿉니다.
- 모둠·커스텀 점수판은 이름을 직접 고칩니다. 모둠 점수판은 2~12개 모둠을 지원합니다.
- 커스텀 점수판은 여러 판을 만들고 전환·복제·삭제할 수 있습니다. 최대 12개 판, 판별 최대 40개 항목입니다.
- 되돌리기, 점수 초기화, 전체화면, 효과음을 지원하고 점수는 로컬에 저장됩니다.
- 퀴즈, 모둠 협력 활동, 참여 기록, 운동회나 놀이의 점수 집계에 활용합니다.

### 6.9. 학급 온도계와 미니 온도계

- 반 전체가 함께 쌓는 공동 목표를 온도로 보여 줍니다. 학급 명단이 있으면 반별로 관리하고, 없어도 사용할 수 있습니다.
- 한 학급에 온도계를 최대 2개 사용합니다. **긍정 온도계**는 칭찬·목표 달성, **부정 온도계**는 경고·약속 지키기 상황에 맞춰 설정합니다.
- 최대 온도, 목표 보상, 기한, 중간 단계와 보상, 한 번에 움직이는 양을 정합니다.
- 올리기·내리기와 사유 칩으로 협동·발표 등 변화 이유를 함께 기록합니다.
- 주간 그래프와 변화 목록, 목표 달성 도장, 도장판 보상을 확인합니다. 경고 온도계는 기한까지 한계에 닿지 않았을 때 약속 지킴 도장을 받을 수 있습니다.
- 자동 식힘은 매일 0으로, 매일 일정량 감소, 매주 월요일 0으로 중에서 설정합니다. 기본은 꺼짐입니다.
- **미니 온도계**를 별도 창으로 띄워 현재 온도와 목표를 계속 볼 수 있습니다. 표시할 학급·온도계와 항상 위 등을 정합니다.
- 미니 창의 **Tidy Task와 함께 열기**를 직접 켜면 다음 실행에서도 위치·크기를 기억해 다시 엽니다.
- 학급 공동 약속, 협동 프로젝트, 긍정 행동 강화, 학급회의에서 목표 진행을 돌아보는 데 활용합니다.

### 6.10. 학급 투표

- **후보 투표·의견 투표·찬반 투표**를 만들고 학급 회장 선거, 체험학습 장소, 학급 규칙 결정 등에 사용합니다.
- 후보·의견은 2~9개, 참여 인원은 2~60명, 1인 표 수는 1~5표, 당선 인원은 최대 4명입니다. 찬반 투표는 안건을 최대 5개 설정합니다.
- 몰아주기·기권 허용, 당선 기준, 후보 기호 추첨, 캐릭터와 색상, 빠른 시작 틀을 설정합니다.
- 학생이 한 명씩 **같은 PC의 숫자키**로 투표합니다. 기권은 0이며 마우스·터치 투표는 지원하지 않습니다.
- 투표 완료 후 잠시 기다리면 다음 학생의 화면으로 자동 전환합니다. 다음 차례마다 Enter를 누를 필요가 없습니다.
- 잘못 투표했을 때 다음 학생이 투표하기 전에 **다시 투표하기**로 직전 표를 취소하고 다시 고릅니다.
- 학생 화면에는 선택 번호가 드러나지 않고 선택·기권에 같은 완료 화면과 소리를 사용합니다. 표는 순서를 섞어 저장하고 개별 투표 시각을 기록하지 않습니다. 선생님도 개표 전에 득표를 보지 못하도록 구성되어 있습니다.
- 개표는 **바로 결과·한 장씩 펼치기·실시간 레이스·개표 방송·반전 공개·골라 공개**를 제공합니다. 찬반의 레이스는 줄다리기 방식이며, 투표 종류와 결과 공개 범위에 따라 선택 가능한 개표 방식이 달라집니다.
- 결과를 모두 공개·순위만·당선자만 등으로 설정하고, 다음 단계·자동 재생·속도 변경·결과로 건너뛰기를 사용할 수 있습니다.
- 기본 안내 음성의 남성·여성 목소리와 속도를 선택합니다. 제목·이름·안건 읽기를 선택해 PC에서 음성을 준비하고 발음을 별도로 수정할 수도 있습니다.
- 안내·투표·개표에 배경 음악과 효과음을 사용하며, 필요에 따라 끄거나 음량을 조절합니다.
- 선생님 메뉴 또는 별도 **선생님 창**에서 참여 인원, 직전 표 취소, 투표 마감과 개표를 조작합니다. 다른 모니터에서 학생 화면을 유지하며 진행할 수 있습니다.
- 동점 후보의 결선 투표, 결과 PNG 저장·이미지 복사, 최근 30개 기록의 결과 재열기·다시 개표·같은 설정으로 새 투표를 지원합니다.
- 진행 중 투표는 저장되어 창을 다시 열면 이어서 받을 수 있습니다. 학생 이름과 표를 연결하는 온라인 인증이나 개인별 중복 투표 차단 기능은 아니므로 참여 순서는 교사가 진행합니다.

### 6.11. 자리 배치

- 학급 명단으로 학생을 불러오고 **둘씩 앉기·혼자 앉기·모둠으로 앉기** 중 교실 모양을 고릅니다.
- 가로·세로 책상 수를 조절하고 자리 재배치로 새 배치를 계산합니다. 완성된 기존 배치에서는 책상 대형과 빈칸 위치를 유지하며 학생을 재배정합니다.
- 선생님 설정에서 **떨어져 앉기·함께 앉기·앞쪽 앉기·뒤쪽 앉기**, 특정 자리 사전 지정, 현재 자리 고정을 설정합니다.
- 성별과 무관하게, 짝의 성별 같게·다르게, 모둠에 고르게 등 성별 배치 옵션을 제공합니다. 성별 미입력 학생도 참여합니다.
- 지난 짝꿍·모둠 친구·같은 위치 반복을 줄이는 옵션과 비교할 이전 배치 선택을 지원합니다. 실제로 만족 가능한 조건인지 확인하며 충돌을 안내합니다.
- 두 학생을 차례로 누르거나 끌어 자리를 교환하고, 학생을 빈자리로 이동합니다. 되돌리기·다시 하기도 가능합니다.
- **효과 없음·가림막·순차적 공개·1개씩 클릭**으로 새 자리를 보여 줍니다. 3·2·1 연출과 효과음은 별도로 켜고 끕니다.
- 학생·교사 기준 방향, 확대·축소·교실에 맞추기, 간단한 이름 중심 보기를 제공합니다.
- 현재 배치를 저장하고 지난 자리 기록을 열어 확인·이름 수정·불러오기를 합니다. 이전 학생 배치 전체 또는 책상 배치만 가져올 수 있습니다.
- **PNG 저장**에서 학생·교사 방향, 번호만 표시, 간단한 배치도를 선택합니다. 자리 배치의 선생님 설정 창과 표시 창을 나누어 사용할 수 있습니다.
- 월별 자리 바꾸기, 학생 관계와 수업 참여를 고려한 배치, 모둠 학습 대형 준비에 활용합니다.

### 6.12. 학급 명단과 모둠 관리

- 여러 학급을 만들고 번호·이름·성별을 등록·수정합니다. 성별은 선택 정보이며 결번과 동명이인을 다룰 수 있습니다.
- 학생 검색, 번호순·이름순 정렬, 필터, 기본 학급 선택을 지원합니다.
- **PDF·XLSX·CSV·HWPX** 명렬표 또는 이름·표 붙여넣기로 가져옵니다. 파일은 최대 20MB입니다.
- 반영 전 미리보기에서 읽힌 번호·이름·성별, 학생 수, 기존 학생 연결과 등록 여부를 확인·수정합니다. 자동 인식이 어려우면 열과 시작 행을 직접 지정합니다.
- 필요한 번호·이름·성별을 가져오며 원본 파일 사본을 보관하지 않습니다. 전화번호·생년월일 등을 학생 정보로 가져오는 기능은 아닙니다.
- 모둠을 만들고 학생을 선택 또는 드래그하여 배정합니다. 학생은 한 모둠에 속하며 미배정으로 돌릴 수 있습니다. 모둠을 삭제해도 학생 명단은 남습니다.
- 실행 취소, 학급 자료 JSON 내보내기·백업 복원을 지원합니다.
- 등록 명단은 간단 뽑기, 토너먼트, 개인 점수판, 학급 투표 후보 선택, 자리 배치 등에서 활용합니다. 학급 온도계도 학급별 목표 관리에 연결됩니다.

## 7. 학교 급식창

- 메모 창의 **급식** 버튼으로 여는 독립 창입니다. 나이스(NEIS) 공개 정보를 이용합니다.
- 학교 이름을 두 글자 이상 입력하여 검색하고, 학교와 주소를 확인해 등록합니다.
- 조식·중식·석식 표시 여부를 선택하고 이전·다음 날짜로 이동합니다. 창을 넓히면 주간 보기로 바뀝니다.
- 오늘로 돌아오기, 다음 급식 찾기, 메뉴 새로고침, 메뉴 클립보드 복사를 지원합니다.
- 알레르기 정보를 번호·식품 이름으로 표시하고 주의할 식품을 골라 메뉴 옆에 표시할 수 있습니다.
- 등록된 칼로리·탄수화물/단백질/지방 비율·영양 성분·원산지·급식 인원과 학교 홈페이지 연결을 확인합니다.
- 메모 창의 테마·글꼴을 따르거나 급식창의 모양·크기·불투명도를 별도로 설정합니다. 항상 위와 앱 시작 시 자동 열기도 선택합니다.
- 이미 조회해 저장한 식단은 인터넷 없이 볼 수 있습니다. 학교 검색과 새 식단 조회는 인터넷이 필요하며, 표시 정보는 학교가 나이스에 등록한 자료 범위에 따릅니다.

## 8. 화면과 동작을 내게 맞추기

- 메모 창은 **15가지 색상 테마**, 다크 모드, 클래식·모던 상단 디자인을 제공합니다. Tiny Note는 자체 지원 테마를 사용합니다.
- 메모 글자와 버튼·메뉴에 쓰는 화면 글자의 글꼴·크기를 따로 설정합니다. 내장 글꼴 외에 PC의 글꼴 파일을 추가할 수 있습니다.
- 메모 창과 도구 창을 옮기고 크기를 조절하여 여러 모니터에 나누어 놓습니다. 저장된 창은 마지막 위치·크기를 복원합니다.
- 툴킷은 **세이지·앰버·오션·로즈·라벤더·슬레이트** 6가지 테마와 다크 모드, 별도 UI 글꼴을 사용합니다.
- 툴바 가로·세로, 크기 5단계, 접기·펼치기, 항상 위, 표시할 도구 선택과 드래그 순서 변경을 지원합니다.
- 외부 툴 메뉴에서 **롤린썬더·클래너**를 브라우저로 엽니다. 이 항목은 외부 웹 서비스 바로가기이며 각각의 이용 환경을 따릅니다.
- **컴퓨터를 켜면 자동 실행**은 기본 켜짐이며 설정에서 끌 수 있습니다. 앱 자동 실행과 미니 온도계 자동 열기는 별도 선택입니다.
- 전체 무음, 리마인더, 툴킷 사용 여부, 업데이트 확인을 설정합니다.
- 작업표시줄의 Tidy Task 트레이 메뉴에서 앱·툴킷을 다시 열거나 새 노트를 만듭니다. 창이 화면 밖으로 나간 경우 **좌표 초기화**로 화면 안에 모을 수 있습니다.
- 앱의 **기능 설명**에는 검색 가능한 사용 가이드가 있습니다. 가이드 글자 크기도 조절합니다.
- **설정 초기화**와 **데이터 초기화**는 구분됩니다. 전자는 설정을 되돌리고, 후자는 모든 메모·툴킷 자료 등을 삭제하므로 필요한 자료를 먼저 보관해야 합니다.

## 10. 저장, 백업과 개인정보 안내

- 메모·학급 명단·알림장·점수·자리 배치·투표 자료 등은 해당 PC의 로컬 저장소에 보관합니다. 여러 PC·휴대전화 간 클라우드 자동 동기화 기능은 제공하지 않습니다.
- 메모와 주요 도구의 저장·복구 안전장치가 있지만, 같은 PC의 자동 사본이 다른 장치에 보관하는 별도 백업을 대신하지는 않습니다.
- **메모장으로 내보내기**는 현재 노트 창의 할 일·마감된 일·메모를 TXT로 저장합니다. 다른 노트 창, 아카이브 전체, 명단, 알림장 등 모든 자료를 묶는 전체 백업이 아닙니다.
- 메모 TXT 가져오기는 현재 창의 내용을 가져온 내용으로 대체합니다. TXT는 글자 중심이라 원래 서식을 그대로 보존하는 형식이 아닙니다.
- 학급 명단은 자체 JSON 내보내기를 사용합니다. **백업 복원**은 현재 학급 자료를 대체하므로 내용을 확인한 뒤 진행합니다.
- 투표 결과와 자리 배치도는 PNG로 남길 수 있습니다. 나머지 자료는 각 도구의 보관·복사·저장 범위를 확인합니다.
- 앱 개선을 위해 설치별 무작위 ID, 앱 버전·운영체제, 기능 사용과 오류 종류 등 사용 통계를 PostHog로 자동 전송합니다.
- 사용 통계에는 메모·할 일 본문, 학생 이름, 투표 내용·결과, 학교명·학교 코드, 창 제목, 파일 경로, 실제 입력 문장을 보내지 않습니다. 화면 녹화는 사용하지 않습니다.
- 급식 조회에는 나이스에 대한 학교·날짜 조회 요청이 필요합니다. 외부 서비스 연결, 업데이트 확인, 표준시 보정, 선택형 음성 모델 다운로드는 각 기능의 네트워크 통신입니다.
- 학생 이름을 표시한 투표 결과나 배치도를 외부에 공유할 때는 필요한 공개 범위를 선택합니다. 자리 배치도는 번호만 표시하여 저장할 수 있습니다.

## 11. 실제 사용 범위와 알아둘 점

- 투표는 같은 PC에서 순서대로 참여하는 교실용 도구입니다. 학생별 온라인 접속, 투표 링크·QR 코드, 학부모 원격 참여 기능은 없습니다.
- 모둠 이름 자동 연동은 도구마다 다릅니다. 토너먼트는 명단의 모둠을 불러오지만 간단 뽑기는 직접 모둠 이름을 입력하고, 모둠 점수판은 자체 모둠을 관리합니다.
- 자리 배치에서 모든 조건을 동시에 만족할 수 없으면 조건과 자리 수를 조정해야 합니다. 지난 짝·모둠·위치 반복 줄이기는 항상 완전히 새로운 배치를 보장하는 약속이 아닙니다.
- 명렬표 가져오기는 형식과 양식에 따라 확인이 필요합니다. 구형 HWP·XLS, 이미지뿐인 PDF의 OCR, 암호 파일은 지원하지 않습니다. 필요한 경우 지원 형식으로 저장하거나 이름·표를 붙여넣습니다.
- 알림장 자동 초안과 확정 저장, 아카이브 보관과 별도 파일 백업, 설정 초기화와 전체 데이터 삭제는 각각 다른 동작입니다.
- 앱 업데이트는 설정에서 확인하고 앱 안에서 설치하거나 새 설치 파일을 내려받습니다. 설치 전에 저장 여부를 확인하며 업데이트 직전 사본을 준비하는 절차가 구현되어 있습니다.
- 이 문서는 5.6.5 프로젝트의 실제 코드·도구 목록·도움말·검수 자료를 대조하여 작성했습니다. 이후 버전의 화면이나 기능은 달라질 수 있습니다.
