# 미니 온도계 위젯 검증 · 2026-09-27

## 변경

- 미니 전용 화면을 테두리 없는 단일 표면과 옅은 색의 두 카드로 정리.
- 두 온도계는 최소 창 280×220부터 항상 같은 행에 표시. 작은 높이에서는 부가 정보만 줄임.
- 관 위·아래의 증감 버튼은 기존 증감 단위, 범위, 일일 기록, 목표 및 도장 규칙을 공유.
- 상단 항상 위 핀: 기본 켜짐, 해제 상태 저장, 네이티브 설정 저장 실패 시 이전 상태 복원.
- ‘가까운 목표’ 및 ‘가까운 경고’, 목표 수치·이름·남은 양, 다음 단계·오늘의 변화·도장 표시.
- 긴 숫자 크기 조정, 다크 모드 대비, 키보드 초점, 동작 줄이기 지원.
- 병행 작업의 이름 편집 기능을 유지하며 아이콘/자료형 이름 충돌만 해소.

## 통과

- `node --test src/lib/thermometer/*.test.js src/lib/scores/section.test.js`: 36개 통과.
- `npx.cmd svelte-check --threshold warning`: 오류 0, 경고 0.
- `npm.cmd run build -- --outDir dist-mini-widget-check`: 성공.
- 브라우저: 280×220, 320×240, 400×560, 520×380, 820×600, 1200×300. 두 카드 및 네 조작 버튼이 창 안에 위치하며 카드 내용의 수직 넘침 없음.
- 연속 증감, 재열기 후 값·핀 해제 유지, 설정 열기/Escape 닫기, 두 탭의 변경 동기화 확인.
- 최대 1000 및 −1000, 긴 제목·목표, 다크 모드 확인. 숫자 가로 넘침 없음.
- 최종 브라우저 검사에서 pageerror 없음.

스크린샷과 최종 빌드/검사 로그: `output/mini-thermometer-qa/`.

## 남은 네이티브 검증

실행 중인 Windows 관리 창을 확인했으나 사용자/병행 작업의 입력 감지로 미니 창 진입 검증을 중단함. 실제 앱 간 앞뒤 전환, 창 드래그·크기 변경, 서로 다른 모니터 배율은 통과로 간주하지 않음. 실제 사용자 온도 자료는 테스트로 변경하지 않음.

병행 편집 중 발생했던 목표 패널 export 및 이름 충돌은 최종 검사 시 해소된 상태. 다른 작업의 변경을 되돌리거나 커밋하지 않음.
