## 검증 중 발견해 고친 것

- **투표판이 멈춤**: 판 크기를 재기 전(폭 0 · 가려진 창) 카드 배치 계산(`boothGrid`)이 빈 값을 돌려줘 화면 갱신 전체가 멈췄음 → 항상 배치를 돌려주도록 고치고 0×0 · 1×1 · 40×30 회귀 테스트 추가.
- **공개 전 결과가 DOM에 있음**: 반전 공개 · 골라 공개에서 아직 뒤집지 않은 카드 뒷면에 순위가 미리 들어 있었음(뒷면 숨김이 그래픽 환경에서 깨지면 비칠 수 있음) → 연 카드에만 결과 글자를 넣음.
- 결선 제안 팝업이 순위 목록을 가림 → 목록 아래 흐름 안의 띠로.
- 1280×720에서 당선 카드가 아래 버튼 줄과 겹침 → 결과 영역을 재서 카드 · 이름 · 키캡 크기를 정함(왕관 자리 40px 포함). 동점 후보는 금색 점선 카드 + "N명 자리를 두고 M명이 동점" 안내로.
- 찬반 결과 머리글에 안건들의 기권을 더한 값이 보임 → 후보 · 의견 투표에만 표시.
