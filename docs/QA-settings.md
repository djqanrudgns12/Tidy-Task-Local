# 설정창 개편 검수 — 2026-09-30

기존 미완성 작업을 이어서 설정창과 초기화·자동 실행 경로를 완성했다. 버전은 `package.json` 기준 5.6.3이며 배포·커밋·푸시는 하지 않았다. 실제 사용자 데이터·기존 검수 결과는 변경하지 않았다.

## 최종 동작

- **모양**: 15개 테마 방울과 다크 모드를 같은 카드에 배치하고, 상단 디자인·보이는 영역을 묶었다.
- **글자**: 메모 글꼴·크기, 화면 글꼴·크기를 각각 한 카드에 배치했다. 글꼴 추가는 한 줄로 정리했다.
- **동작**: 컴퓨터 시작 시 자동 실행(기본 켜짐), 알림·무음, Tidy 툴킷을 배치했다. 기존 창 위치·크기 복원을 사용한다. 사용자가 끈 자동 실행 선택은 기존 `thermometer.display.windowsStart`에 보존한다. 미니 온도계는 Windows 시작 등록을 변경하지 않는다.
- **관리**: 업데이트와 설정·데이터 초기화를 묶었다. 설정 초기화는 내용·등록 글꼴을 보존한다. 자동 실행을 기본값으로 되돌리는 데 실패하면 다른 설정도 먼저 초기화하지 않는다.
- 데이터 초기화는 경고 두 번과 마지막 버튼의 3초 잠금을 거쳐 요청한다. 표식을 남기고 재시작한 뒤 앱 데이터와 별도 웹뷰 캐시를 비운다. 앱 식별자와 다른 폴더·링크는 거부한다. 앱 시작의 기본 창 생성을 미뤄 초기화·백업 복구보다 먼저 저장소가 열리지 않도록 했다.
- 알림·무음을 모든 열린 데이터 창이 함께 받아 다른 창의 다음 저장·매니저 승계 때 이전 선택으로 돌아가는 문제를 막았다. 창별 모양·글자는 요청한 창에만 적용한다.
