# 급식창 구현과 검수

2026-09-18. 제공된 [PRD](https://claude.ai/code/artifact/917d874f-3ae9-4796-ac75-bd7d21300863)와 [시안](https://claude.ai/artifact/Uhd4NQxccTChPSDpqKnp5i)을 읽고 구현했다. 이 문서는 실제 수행한 검증과 아직 수행하지 않은 네이티브 검증을 구분한다.

## 화면과 동작

- Tidy Task/Tiny Note의 공통 15종 테마와 기존 글꼴을 공유한다. 메뉴는 왼쪽 정렬, 알레르기 번호는 오른쪽 보조 정보로 배치하고 긴 이름은 줄바꿈한다. 선택한 알레르기는 색상과 경고 아이콘을 함께 사용한다.
- 대표 아이콘은 김이 올라오는 그릇으로 직접 만들었다. 기본 창은 320×460, 최소 180×120이다. 글자 크기 5단계를 고려해 미니·컴팩트·기본·와이드·주간 보기로 바뀐다. 경계에는 6px 여유를 둔다.
- 메뉴·칼로리를 우선 표시하고 영양·원산지·인원은 자세히 보기에 둔다. 넓은 창에서는 오른쪽 정보 열로 펼친다. 작은 창은 부가 정보를 줄이고 메뉴를 우선한다.
- 학교 검색은 2글자 이상, 300ms 지연과 요청 버전 검사, 지역 필터, 주소 확인 후 명시적 등록을 지원한다. 방향키로 선택하고 Enter로 등록한다.
- 날짜 이동, 오늘로 돌아가기(T), 메뉴 복사(Ctrl+C), 학교 홈페이지, 항상 위, 시작 시 열기, 오후 2시 이후 다음 급식 표시를 제공한다. 주간 보기의 화살표는 주 단위로 이동한다.
- 메인/일반 메모 툴바에 급식 버튼, 트레이에 급식창 열기를 추가했다. 작은 툴바는 제목 영역을 줄이고 공간이 부족하면 투명도 컨트롤을 접는다.

## 저장·요청 경계

- `meal`, `meal-search`, `meal-settings`는 독립 진입점이다. 메모 App/appState의 초기화·저장·매니저 효과를 실행하지 않는다. 급식 관련 창만 남아도 프로세스를 유지한다.
- 학교/설정/월별 캐시/창 위치는 `tidy-task-meal.json`에 저장한다. 설정을 필드별 키로 저장해 여러 웹뷰의 변경이 서로 덮어쓰이지 않게 한다. 메인 설정·커스텀 글꼴은 읽기만 한다.
- 현재 월 6시간, 다음 월 24시간, 과거 월은 자동 만료 없이 저장한다. 학교별 최근 저장 3개월을 유지한다. 20일부터 다음 월을 미리 받는다. 학사일정은 조회 중인 월 범위에서 7일마다 갱신한다. 원안의 연간 학사일정 조회는 월별 조회로 좁혔다.
- 캐시를 먼저 보여 주고 갱신한다. 동일 요청을 합치고 60초 재요청 제한을 둔다. 실패 시 기존 캐시를 보존하며 인증/한도 오류는 당일 반복 요청을 멈춘다. 학교 변경/캐시 삭제 도중 끝난 요청이 지운 캐시를 다시 저장하지 않게 검사한다.
- API 응답을 HTML로 삽입하지 않는다. 숫자 괄호와 명확한 끝 번호 목록만 알레르기로 분리하고 `3.1절`, `배추(무)김치`, `사과(1/2)` 같은 메뉴 이름을 보존한다. 알 수 없는 알레르기 번호도 버리지 않는다.
- 3대 영양소 비율은 탄수화물·단백질·지방의 4/4/9 에너지 환산 후 합계 100%가 되도록 계산한다. 실제 열량 값과는 별도 정보다.

## 인증키와 빌드

`src-tauri/.env`의 `NEIS_API_KEY` 또는 빌드 프로세스 환경변수를 사용한다. 환경변수가 우선이다. `VITE_` 변수로 키를 전달하지 않는다. `.env`를 커밋하지 않는다.

키 없는 개발 빌드는 나이스 샘플 모드이며 화면에 그 한계를 표시한다. 키 없는 release 빌드는 중단한다. 의도적으로 샘플 배포를 만들 때만 `NEIS_ALLOW_NO_KEY=1`을 지정한다.

Rust 바이너리에 랜덤 마스크로 난독화한 바이트를 넣는다. 이는 단순 문자열 노출을 줄이는 방법이며, 데스크톱 바이너리에서 키를 완전히 비밀로 보관하는 수단은 아니다. 요청 오류에 인증키가 든 URL을 반환하지 않는다.

```powershell
npm.cmd test
npm.cmd run build
cargo test --manifest-path src-tauri/Cargo.toml --lib
cargo test --manifest-path src-tauri/Cargo.toml --lib live_school_and_meals -- --ignored --nocapture
npm.cmd run tauri -- build --no-bundle
```

실제 API 테스트는 명시적으로 실행하는 ignored 테스트다. 일반 테스트에서 외부 서비스를 요청하지 않는다.

## 실제 데스크톱에서 남은 확인

- 네이티브 3개 창의 열기/닫기, 트레이, 핀, 학교 등록부터 식단 표시까지의 전체 경로
- 메인 종료 후 급식창 단독 유지, 앱 완전 재시작 시 자동 열기와 위치/크기 복원
- 서로 다른 DPI의 듀얼 모니터에서 이동/최소화/모니터 분리 후 복원
- 실제 네트워크 단절·복귀, 날짜 변경, 14시 전환, 알림/종료 타이밍이 겹치는 장시간 동작
- Windows 설치 패키지 생성·업데이트 배포. 버전은 기존 5.0.5를 유지했으며 커밋/푸시/설치는 수행하지 않았다.

## 디자인 미리보기

`npm.cmd run dev` 후 `http://localhost:5173/?meal-design`을 연다. 테마·밝기·크기·글자 배율과 화면 종류를 바꿀 수 있다. 실제 앱과 동일한 컴포넌트를 사용하지만 식단은 디자인 검수용 예시이며, 검색/API 조회는 데스크톱에서 동작한다. `?meal-matrix`는 개발 모드 전용 크기 검수 화면이다.
