# 찬반 투표 안건·개표·결과 가독성 개선 (2026-09-27)

## 변경

- 안건이 `normalizeConfig`에서 40자로 잘리던 한도를 120자로 늘렸습니다. 입력란도 같은 `LIMITS.agendaMax`를 사용합니다. 이미 문장 끝이 삭제된 저장 데이터는 원문을 다시 입력해야 합니다.
- 모든 찬반 개표에서 단일 안건도 ‘현재 안건’ 번호와 큰 제목이 있는 전용 패널에 표시합니다. 말줄임을 제거하고, 어절을 우선 유지하며 필요한 경우 패널 안에서 줄바꿈합니다.
- 한 장씩 펼치기의 집계를 파란 찬성·빨간 반대 구획과 하단 기권 구획으로 정리했습니다. 선택지·집계 획·큰 숫자를 각 구획에 모으고 두 선택지의 숫자 높이를 맞췄습니다.
- 결과의 안건 행 오른쪽에 연결된 두 득표 구획을 배치했습니다. 찬성은 파랑, 반대는 빨강이며 득표율과 표 수를 분리했습니다.
- 더 많은 표를 받은 구획에만 ‘최다 득표’ 도장을 표시합니다. 동률·전원 기권에는 도장이 없습니다. 통과·부결은 기준에 따른 판정으로 별도 표시합니다.
- 찬반 패널은 숫자와 도장에 필요한 폭을 글꼴로 실측해 확보하고 나머지 가로 공간을 안건 제목에 줍니다. 같은 결과판의 열 경계는 모든 행에서 일치합니다.
- 결과 제목은 한 줄을 우선합니다. 글자 크기를 최대 10% 조절하면 한 줄로 읽을 수 있을 때는 줄바꿈하지 않습니다. 정말 긴 제목은 가용 폭을 끝까지 쓰며 어절을 우선해 줄바꿈하고, 칸 높이에 맞는 크기를 계산합니다. 긴 어절도 표시하며 문장을 생략하지 않습니다. 앞서 적용했던 줄 길이 균형 조절은 제거했습니다.
- 화면과 3200×1800 PNG는 동일한 결과 렌더러를 사용합니다. 결과만 공개에서는 득표수·비율·최다 득표·동률 정보를 표시하지 않습니다. 보조 기술용 결과 목록도 같은 정보를 제공합니다.
- 120자 지원에 맞춰 준비·투표·안내 화면의 안건 문장도 칸 안에서 줄바꿈하도록 보완했습니다.

## 검증

- 투표·결과 이미지·개발 점검 집중 테스트: **65/65 통과**.
- 별도 경로의 프로덕션 빌드: 통과 (`output/vote-yesno-build`).
- 전체 Svelte 검사: 변경한 투표 파일 진단 **0건**. 기존 자리 배치 테스트 3개 파일의 오류 18건이 남아 있습니다.
- 브라우저 검사: 1440×900, 1366×768, 1024×720의 긴 제목·5개 안건, 1·2·3개 안건, 전원 찬성·반대·동률·기권·결과만 공개를 포함합니다.
- 안건 제목·패널의 스크롤 크기와 실제 글꼴의 글자 경계를 측정했습니다. 일반 및 최대 길이 검사에서 패널 넘침·텍스트 겹침·이미지 경계 이탈·런타임 오류가 없었습니다.
- 공백 없는 120자와 어절이 있는 120자를 각각 검사했고, 120자 안건 5개 결과 및 개표 화면의 전체 문장 표시를 확인했습니다.
- 실제 ‘PNG로 저장’ 버튼에서 생성한 결과 이미지를 시각적으로 확인했습니다.
- 사용자가 지적한 긴 안건 예시는 5개 모두 33px 한 줄로 표시됩니다. 실제 글자 경계와 찬반 패널 사이에 여유가 있으며 제목을 강제로 두 줄로 나누지 않습니다.
