# 학급 투표 한국어 음성·재투표 PRD

작성·개정: 2026-09-26 · 버전 2.0 · 상태: 구현 및 자동 검증 진행 / 청취·실제 교실 승인 전

이 문서는 유료 클라우드 서비스를 전제로 했던 1.0을 대체합니다. 사용자의 무료 구현 요청과 시간 제한 없는 재투표 요청을 반영했습니다. 적용 범위는 학급 투표뿐입니다. [조사 근거](RESEARCH-classroom-vote-speech.md), [검증 기록](QA-vote-speech.md)을 함께 확인합니다.

## 1. 목표와 완료 조건

번호·수량·찬반·기권·조작을 정확한 한국어로 안내하고, 남성·여성 목소리를 선택할 수 있어야 합니다. Windows 설치 음성이나 유료 계정 없이 기본 안내를 제공해야 합니다. 학생은 현재 투표를 시간 제한 없이 취소하고 다시 고를 수 있어야 합니다.

자동 검증 통과와 청취 승인, 실제 교실 검증은 별개입니다. 임의의 모든 이름·외래어 발음, 모든 스피커에서의 가청성을 무조건 보장하지 않습니다. 검증하지 않은 항목을 완료로 표시하지 않습니다.

## 2. 학생 흐름과 데이터 계약

1. 숫자키로 선택합니다. 후보·의견은 설정한 표 수까지, 찬반은 안건별로 선택합니다.
2. 저장 확인 중에는 중복 입력과 다음 차례 넘기기를 막습니다. 실패하면 재시도하며 성공으로 표시하지 않습니다.
3. 저장 성공 후 완료 화면이 유지됩니다. 시간이 지나도 현재 표를 확정하거나 다음 투표판을 열지 않습니다.
4. Backspace 또는 **다시 투표하기**로 현재 학생의 표 한 장 전체를 삭제합니다. 삭제 확인 후 처음 선택 화면으로 돌아갑니다. 여러 표·찬반 여러 안건도 현재 학생의 묶음 전체를 취소합니다.
5. 삭제 실패 시 완료 화면에서 다시 시도할 수 있습니다. 표가 남았는데 새 투표를 받지 않습니다.
6. **다음 친구 투표** 또는 Enter/NumpadEnter로 확정합니다. 취소용 표 ID를 메모리에서 지운 후 1.4초 동안 입력을 막고 다음 투표판을 엽니다. 이 시간은 연타 방지 전환이며 재투표 제한이 아닙니다.
7. 마지막 학생에게는 **투표 마치기**를 표시합니다. 마지막 학생도 이를 누르기 전까지 재투표할 수 있습니다.
8. 차례를 넘긴 뒤 Backspace로 이전 학생의 표를 취소할 수 없습니다. 현재 선택 중에는 마지막 선택 한 칸만 지웁니다.
9. 교사 마감·투표 교체·앱 종료는 학생의 현재 취소 권한을 끝냅니다. 재시작 후에는 저장된 표를 유지하며 학생 취소 ID를 복원하지 않습니다. 이는 이전 학생의 표를 다른 학생이 취소하지 못하도록 하는 경계입니다.
10. 완료 화면·소리에는 선택 후보, 선택 수, 기권 여부를 노출하지 않습니다. 표 순서 무작위 저장과 기존 집계를 유지합니다.

구버전 `undoSeconds`, `lastUndoSeconds`는 읽기 정규화에서 버립니다. 표 데이터는 변경하지 않습니다. 저장·삭제의 비동기 결과는 해당 세션에서만 반영합니다. 교사가 현재 표를 지우면 학생 부스도 선택 화면으로 돌아갑니다.

| 실패 대안 | 제목·소개 전체가 준비되지 않으면 이름 일부만 읽지 않고 해당 묶음 전체를 기본 안내로 대체합니다. 투표 기능은 모델 다운로드·합성 실패와 무관하게 유지합니다. |

| 라이선스 | helper MIT, 모델 OpenRAIL-M 원문 및 출처를 포함합니다. 저장소가 보관 상태이므로 버전을 고정하고 업데이트를 자동 반영하지 않습니다. |

유료 API, 비공식 Edge 서비스, 서버 인증·과금·외부 이름 전송은 이번 구현에 필요하지 않습니다. 무료라는 이유로 검수 기준을 낮추지 않습니다.

## 4. 한국어 발화 규칙

- 기호 번호는 `기호 일 번`, `기호 이 번`으로 제작합니다. 횟수 `한 번`, `두 번`과 구별합니다.
- 인원은 `스무 명`, `스물한 명`, `스물여덟 명`, 표는 `한 표`, `두 표`, 안건 수는 `세 개`처럼 단위를 포함합니다.
- 키 입력은 `숫자 영`, `백스페이스`, `엔터`로 읽습니다. 화면 표시는 0·Backspace·Enter를 유지합니다.
- 후보·의견의 여러 표에서 0은 남은 표 전체 기권입니다. 찬반의 0은 현재 안건만 기권입니다. 서로 다른 대본을 사용합니다.
- 기호 번호와 이름은 문장으로 합성하며 숫자·음절 조각을 이어붙이지 않습니다.
- 임의 문장에 있는 숫자·영문을 무조건 치환하지 않습니다. 교사가 발음 별칭으로 읽을 문장을 지정합니다. 별칭은 화면 원문을 바꾸지 않습니다.
- 제어 문자와 마크업 구분 문자를 정리하고 별칭은 80자 이내입니다. 삭제된 후보·안건의 별칭도 정리합니다.
- 안내 대본에는 2초 제한이나 완료 후 자동 확정 지시가 없어야 합니다. 마지막 학생의 실제 버튼 명칭은 화면에서 명확히 제시합니다.

## 5. UI와 재생 상태

준비 화면의 **안내 음성** 펼침 영역에 남녀 선택, 안내 켜기, 목소리 들어 보기, 제목·이름·안건 읽기, 발음 별칭, 준비·취소·소개 들어 보기·삭제를 제공합니다. 처음 다운로드 용량과 PC 내 처리 사실을 알립니다. 기본 안내/동적 준비 완료를 구분합니다. 별도 선생님 창은 설정만 공유하며 자체 음성을 재생하지 않습니다.

소리 확인 카드의 체크는 교사가 **잘 들려요**로 확인합니다. `ended`를 수신했다는 사실을 실제 가청성 확인으로 사용하지 않습니다.

재생기는 `completed`, `cancelled`, `muted`, `blocked`, `missing`, `decode-error`, `timeout`, `disposed`를 구분합니다. 취소는 종료 이벤트를 기다리지 않고 Promise·소스·타이머를 정리합니다. 오래된 로딩·디코딩 결과는 재생하지 않습니다. 기본 로딩 상한 3초, 문장 길이 상한 35초이며 실제 음원 길이 기반 watchdog을 둡니다.

효과음과 안내는 같은 master 음량·음소거를 따릅니다. 안내 중 효과음만 감쇠합니다. 재생 실패 시 자동 넘김을 멈추고 **다시 듣기 / 음성 없이 계속**을 제공합니다. 마지막 안내 장은 자동으로 투표를 시작하지 않습니다.

## 8. 출시 판정

개발 빌드는 검수자가 확인할 수 있도록 동작합니다. `node scripts/vote-speech/verify.mjs --release`는 청취 미승인 음원이 있으면 실패합니다. 자동 시험 통과만으로 `reviewStatus`를 approved로 바꾸지 않습니다. 배포 전 실제 기기 확인과 음질 반려 수정을 완료해야 합니다. 이번 작업은 앱 수정과 검증이며 별도 배포·커밋·푸시를 수행하지 않습니다.
