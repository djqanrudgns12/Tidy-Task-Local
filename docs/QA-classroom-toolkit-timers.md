# 학급 툴킷 · 타이머 구현 검수

검수일: 2026-09-19. 사용자 실제 앱과 분리한 `com.tidy.task.toolkitqa`로 Windows 실행 검수. 기존 사용자 설정과 `public/sample`은 변경하지 않았다.

## 구현

- 독립 항상 위 툴킷, 전체 버튼 영역 드래그, 클릭 접기, 가로/세로, 도구 노출 설정, 메인 설정/모던 메뉴 ON/OFF.
- 네 가지 고유 타이머 창, 창별 핀 OFF 기본, 크기 조절, 시작/정지/재개/초기화/증감.
- 아날로그 30/60 눈금과 부채꼴·바늘, 경계/취소/키보드 조작. 모래시계 면적 기반 진행과 숫자 토글. 스톱워치 누적/구간 타임라인.
- 설정만 별도 로컬 파일에 저장. 종류별 변경 필드 병합, 새 창에 최신 설정 적용. 측정·제목·기록은 저장 경로가 없다.
- 투명 생성 아이콘과 실제 CC0 시계음/경고음/종료음. BGM 없음.

`output/qa/toolkit`에 각 명령 로그, 재실행 가능한 Playwright 스크립트, 화면 PNG가 있다. Playwright는 머신에 번들된 런타임 경로를 사용하므로 다른 PC에서는 import 경로를 조정한다. 제품 의존성에는 테스트 도구를 추가하지 않았다.

## 아직 수행하지 않은 실기기 검사

- 실제 절전/복귀, 모니터 분리, 혼합 DPI 경계 횡단, 100/125/150% 배율별 드래그.
- native 8창 장시간 부하·20회 생성/종료 후 메모리 계측, OS 작업표시줄/트레이의 모든 종료 조합.
- 교실 스피커에서의 청감·적정 음량. 파일 신호/재생 코드는 검사했지만 실제 스피커로 듣고 평가했다고 주장하지 않는다.
- 기존 메모·급식 등 실제 사용자 자료로 수행하는 전체 수동 회귀. 기존 자동 테스트/빌드는 통과했다.

## 에셋 및 의존성

출처와 편집 값: [에셋 README](../artwork/toolkit/README.md). 원본 다운로드 팩은 보존했다. Bits UI는 2.19.2 고정. 의존성 감사에서 기존 `dompurify`, Svelte 하위 `devalue` 항목이 남아 있으며 이번 Bits UI 추가분의 새 경고는 없었다. 기존 패키지의 일괄 업데이트는 수행하지 않았다.


## 프런트엔드 개정 검수

`redesign-check.mjs`: 곡선 모래의 0/1/25/50/75/99/100% 캡처(시간 가속 fixture 사용), dark 입력에서도 밝은 배경 유지, 기본 960×680의 아날로그 전체 설정 패널이 스크롤 없이 들어오는지 실제 DOM 크기로 확인. `analog-380-new.png`에서 최소 창의 시간/주요 조작을 함께 확인했다. 기본 타이머 4종의 PNG도 새 화면으로 갱신했다.

개정 후에도 시간 계산·소리·저장·기록 경로의 기존 검사를 다시 실행했다. 스피커 청감/절전/혼합 DPI의 미검증 범위는 위와 같다.

새 디자인의 Windows 재검수: 세로형 툴킷 → 독립 메뉴 → 아날로그 창을 다시 실행했다. 핀 버튼으로 실제 최상단 전환, 시작 후 05:00→04:48 감소와 설정 패널 접힘, 일시정지 전환을 확인했다.
