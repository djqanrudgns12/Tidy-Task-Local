# 뽑기 UI·연출 개편 검증

2026-09-21. 기존 `QA-classroom-picker.md` 이후의 화면 개편에 대한 기록이다.

## 목표와 변경

처음 쓰는 교사가 명단 준비 → 방식 선택 → 뽑기 → 다시 시작을 설명 없이 찾도록 구성했다. 학급·모둠·직접 입력은 펼쳐진 선택 카드, 성별은 세 개의 버튼으로 바꿨다. 학급 선택만 일반 선택 상자로 유지한다. 대상 관리·설정·다시 시작을 상단의 테두리가 있는 큰 버튼으로 배치했다. 명단 관리와 설정은 포커스가 제한되는 네이티브 dialog로 열리고 Escape로 닫힌다.

읽기 쉬운 시스템 고딕체, 15–20px 중심의 주요 조작, 큰 결과 이름, 대비가 있는 선택/꺼짐 상태를 적용했다. 960×720에서 주요 관리 기능과 추첨 버튼이 첫 화면에 들어온다. 작은 창은 세로 흐름으로 전환되며 무대 아래 추첨 버튼이 스크롤 중에도 접근 가능한 위치를 유지한다.

클래식은 2초간 이름 카드가 섞인다. 인형뽑기는 4.7초 동안 집게 이동, 하강, 잡기, 들어 올리기, 출구 이동, 인형 낙하와 결과 공개를 진행한다. 풍선 다트는 3.3초 동안 조준, 곡선 비행, 풍선 파열과 조각, 결과 공개를 진행한다. 효과음 권한을 기다리느라 시각 연출 시간이 소진되지 않도록 분리했다. 추첨 결과는 시작 시 한 번 확정되고 종료 시 한 번만 기록된다.

기존에는 컴퓨터의 동작 줄이기 또는 저장된 연출 줄이기가 적용되면 곧바로 결과를 확정하는 경로가 있었다. 이제 적용 이유를 표시하고 0.9초간 정적인 준비 화면 후 결과를 보여준다. 사용자가 ‘전체 연출 보기’를 누르거나 설정에서 연출 줄이기를 끄면 이 창에서는 컴퓨터 설정과 관계없이 전체 연출을 사용한다. 이 명시적 컴퓨터 설정 재정의는 창을 다시 열면 초기화되며, 저장된 연출 줄이기 설정 자체는 유지된다.

모드 전환 시 직전 모드의 결과가 새 무대를 덮지 않는다. 모든 후보를 뽑으면 주요 버튼이 다시 시작으로 바뀌고, 전원을 일시 제외한 경우 대상 관리로 바로 연결한다. 초기화는 일시 제외 상태를 보존한다.

## 확인 결과

- 프로덕션 빌드 성공.
- 뽑기 단위 테스트 11개 통과.
- Edge 실제 브라우저 기본 흐름 33개 확인 통과, 브라우저 예외 0개.
- 밀집 명단·긴 이름·예외 경로 25개 확인 통과, 브라우저 예외 0개.
- 390 / 640 / 800 / 960 / 1440px 화면의 가로 넘침 없음.
- 인형과 풍선 각 30개를 640 / 960 / 1440px에서 표시하고 캡처.
- 실제 추첨 중 집게 좌표가 변하고 인형을 붙잡은 요소가 존재하며, 전달 이전에는 기록되지 않음을 확인. 다트 좌표 이동, 목표 풍선 하나의 파열, 중복 기록 방지도 확인.
- 대상 검색·일시 제외·제외 해제·취소·초기화·저장 후 재열기, 모달 Escape, 키 반복/검색창 Space 오발 방지 확인.
- 긴 이름이 390 / 640 / 960px에서 결과 카드 안에 들어오는지 경계 좌표로 확인.
- 컴퓨터 동작 줄이기 적용과 사용자의 전체 연출 선택을 각각 확인.
- 인형 이미지 로딩 실패 시 추첨 차단과 클래식으로의 복구 확인.

전체 프로젝트 정적 검사는 마지막 확인 시 873 errors / 14 warnings / 36 files로 실패했다. 뽑기 컴포넌트·모듈 경로의 진단은 없었다. 병행 수정 중인 다른 기능의 오류를 이 작업에서 변경하거나 전체 검사가 통과한 것으로 표기하지 않는다.

## 재현 및 증거

`node output/qa/picker/serve.mjs`로 5193 포트에 전용 개발 서버를 실행한다. `node output/qa/picker/redesign-check.mjs`, `node output/qa/picker/redesign-edge-check.mjs`로 검증한다. 스크립트는 번들 Playwright 및 설치된 Edge를 사용한다. 별도 브라우저 컨텍스트에만 검증용 이름을 만들며 사용자의 실제 학급 명단을 변경하지 않는다.

검증 결과는 `output/qa/picker/redesign-report.json`, `redesign-edge-report.json`에, 단계별 화면은 같은 폴더의 `redesign-*.png`에 있다. 대표 화면은 `redesign-ready-960.png`, `redesign-claw-ready-960.png`, `redesign-claw-lift.png`, `redesign-claw-result.png`, `redesign-balloon-flight.png`, `redesign-balloon-burst.png`이다.

이번 검증은 브라우저 렌더링과 프런트엔드 빌드 범위다. 설치 프로그램 재생성·설치본 교체, 실제 교실 프로젝터·스피커, Windows 배율별 네이티브 창 검수는 수행하지 않았다.
