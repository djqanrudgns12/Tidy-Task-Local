## 1. 만들려는 경험

**학급 명단을 다시 입력하지 않고, 내 교실에 맞게 책상을 놓고, 학생에게 필요한 조건과 지난 자리를 살펴 다음 자리를 정한다.**

도구 이름은 **자리 배치**로 한다. ‘스마트’, ‘AI’, ‘프로’ 같은 수식어를 버튼과 기능명에 반복하지 않는다. 복잡한 기능은 교사가 하는 행동으로 설명한다. 처음에는 `교실 모양 확인 → 자리 재배치 → 필요한 학생만 손으로 조정` 흐름을 이해하면 된다. 완성된 마지막 배치는 별도 확정 버튼 없이 자동 기록된다.

주 사용자는 시니어 초등교사와 디지털 도구가 익숙하지 않은 교사다. 담임의 한 교실, 교담의 여러 학급, 전자칠판 공개, 종이 출력까지 하나의 흐름으로 연결한다. 서비스 가입·프롬프트 작성·학생 정보의 외부 전송 없이 로컬에서 작동한다.

### 확정 요구와 제안의 구분

| 구분 | 내용 |
| --- | --- |
| 사용자 확정 | 학급 명단 자동 연결, 기본 학급 변경 반영, 숫자로 위치 안내, 지난 배치를 활용한 짝꿍 회피와 분리 조건, 성별을 반영한 위에서 본 학생 그림, 독창적인 Tidy 디자인, 쉬운 사용법 |
| 이번 산출물 | PRD와 세부 개발계획, 첫 에셋 스타일 시트. 실제 기능과 개별 배포용 에셋은 다음 구현 단계 |
| 추가 사용자 확정 | 학급별 교실·초안 보존과 자동 전환, 최근 확정 기록 3개 기본 참고, 필수 조건 자동 완화 금지, 학생에게 쉽게 보이지 않는 선생님 전용 모달/팝업에서 조건 편집 |
| 위임받은 설계 | 학생·교실 그림 세부 방향과 생성, 성별 미입력 중립 그림, 음향·순차 공개 기본 끔 |

첨부 7장은 기능 참고 자료다. 자료 안의 안내·추천·PRO 표시는 사용자 지시나 제품 정책으로 채택하지 않는다. 화면 구성, 색, 버튼, 일러스트, 문구, 학생 이름을 복제하지 않는다.

## 3. 출시 범위

**첫 정식 출시에서 아래 핵심 묶음을 모두 완성한다.** 개발 순서는 기능을 줄이기 위한 MVP 구분이 아니다.

| 묶음 | 포함 |
| --- | --- |
| 학급 | 기본 학급 자동 추종, 이 학급 유지, 학급별 초안·확정 배치, 추가/수정/삭제 반영 |
| 교실 | 시작 모양, 반듯한 숫자 격자, 가로·세로 자리 수 조절, 앞쪽 방향, 빈 칸 이동, 숫자 안내 |
| 학생 | 끌기·두 번 선택으로 교환, 아직 자리 없는 학생, 명단 성별에 맞춘 기본 모습 |
| 조건 | 떨어져 앉기, 짝 지정, 앞/뒤/구역, 최근 짝꿍·같은 모둠·같은 위치 회피, 성별 섞기, 기존 모둠 활용 |
| 제안 | 필수/선호 구분, 앞자리부터 채운 차이가 큰 3개 후보, 3·2·1 연출, 선택형 가림막, 실행 취소/다시 실행 |
| 기록 | 완성된 마지막 배치 자동 기록, 같은 작업의 반복 재배치 한 건 갱신, 기간·개수 선택, 교실 모양 재사용, 기록 삭제 |
| 공유 | 학생에게 보여 주는 전용 화면, PNG, 인쇄/PDF 저장 경로, 학생 쪽/선생님 쪽 보기 |
| 품질 | 로컬 저장·복구·백업, 큰 글씨, 키보드·클릭 대안, 학생 그림과 교실 에셋, 다크 모드 |

후속 확장: 같은 교실을 여러 학급이 실시간 공동 참조하는 교실 관리, 시간표 기반 자동 학급 전환, 학기 전체 순환 계획, 학생의 자리 선호 조사. 첫 출시에서는 교실 모양 복사로 교담 요구를 지원한다. 서버 동기화·사진 얼굴 재현·성적 기반 학생 분류는 이번 범위에 넣지 않는다.

## 4. 첫 사용과 반복 사용

1. 툴킷의 `자리 배치`를 열면 기본 학급 이름·학생 수가 보인다. 명단이 없으면 `학급 명단 등록하기` 하나를 중심으로 안내한다. 기본 학급만 없으면 학급을 직접 고르거나 명단에서 기본 학급을 지정한다. 첫 학급으로 임의 이동하지 않는다.
2. 첫 교실은 `둘씩 앉기 / 혼자 앉기 / 모둠으로 앉기 / 마주 보기 / 둥글게 앉기 / 직접 놓기` 중 작은 교실 미리보기를 선택한다. 모양은 출발점이며 언제든 책상을 움직일 수 있다.
3. 학생 수보다 조금 넉넉한 격자를 만들 수 있다. 비어 있는 칸은 시각적으로 공란이며, 마우스를 올리거나 키보드로 초점을 둔 경우에만 이동 대상임을 드러낸다.
4. `자리 재배치`를 누르면 앞자리부터 채운 `배치 1 / 배치 2 / 배치 3`을 만든다. 각 배치는 필수 조건을 모두 지키고, 가능한 범위에서 서로 여러 학생이 다르게 앉는다.
5. 이름을 눌러 두 자리를 교환하거나 학생을 빈 칸으로 직접 이동한다. 변경이 잠잠해지면 완성된 마지막 상태를 자동 기록한다. 같은 앱 작업 중 여러 번 재배치하면 해당 작업의 기록 한 건을 마지막 결과로 갱신한다.
6. 다음 실행은 마지막 편집 상태와 현재 자동 기록을 복구한다.

## 5. 정보 구조와 명칭

### 기본 화면

상단에는 `자리 배치`, 학급 선택, `기본 학급 따라가기`, `교실 모양`, `선생님 설정`, 저장 상태를 둔다. 중앙은 교실이고 교실 아래에서 되돌리기·크기·학생 쪽/선생님 쪽을 다룬다. `선생님 설정`은 별도 창에서 `배치 조건 / 지난 자리`를 다룬다. 하단의 강조된 주 행동은 `자리 재배치` 하나다.

항상 보이는 제어는 제한하고 선택한 학생·책상에 필요한 동작만 붙인다. 조건 설정을 연속 모달로 겹치지 않는다. 선생님 창은 독립적으로 이동할 수 있고, 최초에는 학생 공개 화면과 다른 모니터의 사용 가능한 영역을 우선 제안한다. 모니터가 하나면 공개 화면을 가린 뒤 설정하도록 안내한다. 별도 창 자체가 화면 전체 공유에서 비공개를 보장하지는 않는다.

| 의미 | 제품 문구 |
| --- | --- |
| 자동 배정 실행 | 자리 재배치 |
| 선택한 학생만 재배정 | 선택한 학생만 다시 배치 |
| 학생 고정 | 이 자리 유지 |
| 책상 이동 방지 | 책상 위치 잠그기 |
| 분리 규칙 | 떨어져 앉기 |
| 이전 파트너 회피 | 지난 짝꿍 피하기 |
| 저장된 확정 배치 | 지난 자리 |
| 교실만 가져오기 | 교실 모양만 가져오기 |
| 학생 제외 | 이번에는 자리 비워 두기 |
| 공개용 화면 | 학생에게 보여 주기 |
| 저장 | 마지막 결과 자동 저장 |

위쪽과 왼쪽에는 **1, 2, 3… 숫자만** 표시한다. 제품 UI·도움말·접근성 설명에서 좌표를 부를 때 `행`, `열`을 사용하지 않는다. 선택 설명은 `위쪽 3 · 왼쪽 2`, 스크린리더 이름은 `김하늘, 위쪽 3, 왼쪽 2, 자리 유지`처럼 쓴다. 문서 내부 데이터명 x/y와 화면 번호를 구분한다.

## 6. 학급 자동 연동 — S01

- 기본 연결은 `기본 학급 따라가기`. 명단 창에서 단순히 다른 학급을 열어 본 것은 전환 신호가 아니다. `기본 학급으로`가 실제 변경된 때 따라간다.
- 학급별로 교실, 조건, 학생 모습 선택, 확정 배치, 작성 중인 초안, 화면 확대를 별도 보존한다.
- 사용자가 자리 배치에서 직접 학급을 고르면 `이 학급 유지`로 바뀐다. 공통 기본 학급까지 바꾸지는 않는다. `기본 학급 따라가기`를 누르면 다시 합류한다.
- 자동 전환 시 이전 초안 저장 성공을 확인한 뒤 새 학급을 연다. 교실 중앙과 상단에 `5학년 2반으로 바뀌었어요`를 잠깐 보여 준다. 빈 교실이나 다른 반 학생을 순간 노출하지 않는다.
- 드래그·이름 선택 교환 중이면 미확정 조작을 취소하고 전환한다. 조건 입력이 유효하면 저장하고 전환, 미완성이면 해당 학급의 로컬 초안에 보존한다. 저장 실패면 기존 반에 머무르고 전환 대기 이유와 재시도를 표시한다.
- 계산·공개 연출 중 변경되면 이전 작업을 취소하고 결과를 폐기한다. 이전 반 결과가 새 반에 들어가지 않도록 작업 세대와 학급 ID를 함께 검사한다.
- 이름/번호 변경은 같은 학생 ID의 현재 표시만 갱신한다. 신규 학생은 `아직 자리 없는 학생`에 추가한다. 이미 정한 배치를 자동으로 전부 섞지 않는다.
- 전출/삭제 학생은 현재 배치와 조건에서 제거하고 자리를 비운다. 학급 삭제·기본 학급 해제 시 명확한 빈 상태로 전환한다. 동명이인, 번호 재사용으로 과거 학생을 연결하지 않는다.
- 명단의 모둠을 배치에 이용할 수 있지만 책상 모둠을 편집한 결과를 명단 모둠에 자동 기록하지 않는다.

## 7. 교실 편집과 숫자 안내 — S02

### 두 가지 조작 방식

`학생 옮기기`에서는 학생만 이동한다. 학생 → 학생은 교환, 학생 → 빈 책상은 이동이다. `책상 놓기`에서는 책상과 앉아 있는 학생을 함께 옮긴다. 두 방식 모두 끌기뿐 아니라 대상 선택 → 목적지 선택으로 가능하다. 선택 상태에서 Escape로 취소한다.

학생의 `이 자리 유지`와 책상의 `위치 잠그기`는 서로 다른 상태다. 학생 고정은 자동 배치·수동 교환 모두에서 보존한다. 고정 학생을 옮기려면 먼저 고정을 해제한다. 책상 이동은 그 책상에 대한 학생 고정을 유지하되 앞쪽 구역 등 다른 조건을 다시 검사한다.

### 자유 이동과 맞춤 정렬

- 모든 책상은 영속 seatId와 교실 내 x/y·방향을 가진다. 화면에서의 몇 번째 위치를 학생이나 기록의 식별자로 쓰지 않는다.
- `맞춰 놓기` 기본 켬. 책상 경계·중심·옆 책상과의 간격에 가까워지면 안내선과 반투명 착지 모습을 보여 준다. 맞춤을 꺼 미세 배치할 수 있고 키보드로도 조금씩 이동한다.
- 책상을 바깥에 놓으면 교실 작업 영역과 숫자 안내가 확장된다. 다른 책상을 예고 없이 밀어 내거나 전체 교실을 재정렬하지 않는다. `간격 맞추기`와 `가지런히 놓기`는 선택한 책상에만 명시적으로 실행한다.
- 놓는 동안 숫자는 안정적으로 유지하고, 놓기가 끝나면 정렬된 중심선 묶음에 따라 숫자를 다시 산출한다. 한 번 이동한 결과와 숫자 변경은 한 번에 되돌릴 수 있다.
- 새 숫자 위치가 필요하면 착지 미리보기부터 해당 숫자를 보여 준다. 반대로 비어 있는 안내선은 다른 책상 위치를 옮기지 않고 정리한다.
- 겹친 책상·벽 밖 배치는 놓기 전 알림. 놓을 수 없는 경우 원래 위치를 유지한다. 학생을 놓는 모드에서 빈 공간에 놓아 학생을 삭제하는 동작은 없다.
- 여러 책상 선택, 묶어서 이동, 복제, 90도 회전, 간격 맞추기, 통로 넓히기, 빈 책상 추가·삭제를 지원한다. 회전해도 이름표는 똑바로 읽힌다.
- 사용 중인 책상 삭제는 해당 학생을 `아직 자리 없는 학생`으로 옮긴다고 미리 보여 준다. 다른 학생을 밀어내지 않는다.
- 축소 시 숫자·이름이 읽히지 않으면 확대 또는 목록 보기를 제공한다. 창 폭에 맞추기 때문에 모든 글자를 무조건 작게 만들지 않는다.

### 교실 의미

칠판·교탁·문·창문·사물함·책장·화분·게시판·교실 앞쪽 표시를 배치한다. 교실 앞쪽은 교사가 정하며 칠판 장식의 이동만으로 뜻이 바뀌지 않는다. 문·책장 등은 공간을 차지하는 물건, 창문·게시판은 벽 장식으로 구분한다. 통로 영역은 책상 배치를 막지만 학생 두 명의 거리 조건을 자동 면제하지 않는다.

자리 연결은 `짝으로 묶기`, `모둠으로 묶기`로 지정하고 선/선택 테두리로 확인한다. 시작 모양에서는 자동 생성하되 자유 이동으로 임의 재결합하지 않는다. 붙여 놓았다고 자동 짝꿍, 떨어뜨렸다고 자동 해제가 되지 않는다.

## 8. 배치 조건과 제안 — S03

선생님이 추가한 배치 조건은 모두 필수이며 자동으로 풀지 않는다. 기존에 `가능하면`으로 저장한 조건도 동일하게 지킨다. 서로 충돌하면 배치 결과를 적용하지 않는다. 지난 자리·성별·모둠 균형은 별도의 참고 옵션으로 점수를 비교한다. 일반 교실에는 분리 대상이나 조건 요약을 표시하지 않는다. 별도 `선생님 설정` 창의 `배치 조건`에서 입력·충돌 이유·제안 비교를 확인한다. 교실에서 규칙 때문에 이동할 수 없을 때는 `선생님 설정에서 확인해 주세요`만 표시한다.

| 조건 | 제안 기본값과 조정 |
| --- | --- |
| 이 자리 유지 | 학생과 seatId를 연결하는 필수 조건 |
| 떨어져 앉기 | 필수 조건. `짝이 되지 않기 / 주변 자리도 피하기 / 다른 모둠에 앉기 / 더 멀리` 선택, 해당 범위를 교실에 표시 |
| 함께 앉기 | 필수 조건. 짝 지정/같은 모둠 구분 |
| 앞쪽·뒤쪽·직접 고른 구역 | 필수 조건. 학생별 허용 구역 표시 |
| 지난 짝꿍 피하기 | 배치 조건과 별도의 참고 옵션. 최근 확정 3개를 기본으로 반복을 줄이며 최근 1/3/5개·기간·직접 기록 선택 가능 |
| 지난 모둠 친구 피하기 | 별도 선택. 짝꿍과 모둠을 혼동하지 않음 |
| 같은 위치 반복 줄이기 | 교실 앞쪽 기준 앞/중간/뒤·왼쪽/중간/오른쪽 비율 영역을 우선 비교 |
| 성별 배치 | 배치 조건과 별도의 참고 옵션. 기본 성별 무관. `짝의 성별 다르게 / 짝의 성별 같게 / 모둠에 고르게` 선택 |
| 학급 명단 모둠 | 같은 모둠끼리 앉기 또는 골고루 섞기. 원본 모둠은 수정하지 않음 |
| 일부 학생만 다시 배치 | 나머지 학생은 해당 계산 동안 고정. 배치 대상과 빈자리 범위를 먼저 표시 |

‘주변 자리’는 자동 계산한 좌석 간 가까운 범위다. 화면 숫자로 인접성을 추론하지 않고 실제 교실 좌표와 책상 크기로 계산한다. 기본은 책상 중심 간 가로·세로 각각 한 책상 간격 이내인 이웃(대각선 포함)이며, 구현 전 표준 책상 크기와 간격 단위로 고정하고 범위를 눈으로 확인하게 한다. 회전 교실에서도 교실 좌표 기준으로 계산한다. 통로 건너도 범위 안이면 이웃이다. 자유 모양에서 교사가 제외/추가한 관계는 명시적 예외로 저장한다.

‘지난 짝꿍’은 과거 확정 시 저장한 짝 연결로 판단한다. 모둠 기록은 같은 모둠 관계다. 방향·교실 모양이 바뀌어도 학생 ID 쌍은 유지된다. 한 책상을 여러 짝에 연결할 수 없고 모둠과 짝은 동시에 존재할 수 있다. 홀수 모둠의 짝 없는 한 학생을 오류로 보지 않는다.

### 계산과 설명

1. 버튼을 누른 순간 명단 revision, 교실, 조건, 참고 기록을 동결한다.
2. 자리 부족·중복 고정·허용 구역 부족·상충하는 짝 지정부터 검사한다.
3. 필수 조건을 만족하는 후보를 찾고, 선호 조건을 우선순위대로 개선한다. 수학적 최적 배치를 보장한다고 표현하지 않는다.
4. 가능하면 서로 다른 후보 최대 3개를 제공한다. `지난 짝꿍 0쌍 / 같은 위치 2명 / 선호 조건 1개 확인`처럼 구체적으로 비교한다. 하나만 가능하면 같은 결과를 세 장으로 복제하지 않는다.
5. 순차 공개·효과음은 결과가 정해진 다음 표현에만 사용한다. 기본은 즉시, 무음. 연출 중 취소해도 다른 결과를 새로 뽑지 않는다.
6. 완료 후 명단이나 조건이 바뀌면 후보를 오래된 결과로 표시하고 확정을 막는다. 후보를 몰래 최신 명단에 맞춰 바꾸지 않는다.

불가능이 확인된 경우 `빈자리가 2개 부족해요`처럼 원인과 `책상 2개 추가` 등 직접 해결 행동을 제안한다. 제한 시간에 답을 찾지 못한 경우는 `이 조건으로 아직 배치를 찾지 못했어요`라고 구분한다. 증명하지 않은 불가능을 단정하지 않는다. 선호 조건을 충족하지 못했으면 어떤 조건인지 교사에게만 알려 주고 선택하도록 한다.

수동 이동도 같은 조건 검사기를 거친다. 충돌하는 배치를 초안으로 살펴볼 수는 있지만, 필수 조건을 수정하거나 위반을 해소하기 전 확정할 수 없다. 조작 한 번을 이유로 분리 조건을 일시 해제하지 않는다.

## 9. 지난 자리와 사용 기록 — S04

- 완성된 배치는 850ms 동안 추가 조작이 없으면 현재 기록으로 자동 저장한다. 모든 학생이 앉지 않았거나 필수 조건이 충족되지 않은 중간 상태는 현재 기록으로 승격하지 않는다.
- 기록에는 학급 ID, 날짜, 제목, 확정 당시 명단 표시값, 학생 ID, 교실과 배정, 짝/모둠 관계, 조건 요약, 사용 여부를 저장한다. 그 이후 개명은 과거 이름을 덮어쓰지 않는다.
- 한 앱 작업에는 안정적인 sessionId를 사용한다. 같은 작업에서 재배치·후보 변경·손수 교환을 반복하면 기존 기록을 마지막 결과로 교체하고, 새 앱 작업에서 완성된 배치를 바꾸면 새 기록을 만든다.
- `지난 자리`는 날짜순 교실 썸네일과 제목을 보여 준다. `두 자리 비교`에서 바뀐 학생·반복 짝꿍·위치 이동을 확인한다. 학생 한 명을 선택하면 날짜별 짝꿍과 자리 흐름을 볼 수 있다.
- `교실 모양만 가져오기`는 이름·배정·개인 조건 없이 모양만 복사한다. `이 배치로 다시 시작`은 사본을 만들고 현재 명단과 비교한다. 없는 학생은 빈자리, 새 학생은 대기 영역이다.
- 기존 모양을 수정해도 과거 썸네일과 관계는 그대로다. 다른 학급의 기록은 자동 비교하지 않는다. 학년이 바뀌어 학생을 새 ID로 등록한 경우 이름으로 이력을 추정 연결하지 않는다.
- 기록은 자동 삭제하지 않는다. 개별·기간별 삭제, 전체 백업을 제공한다. 삭제될 개수와 되돌릴 수 없는 범위를 확인한다. 외부에 이미 저장한 이미지/PDF는 앱 삭제와 연동되지 않는다.

## 10. 독창적인 시각 방향 — S05

디자인 방향은 **정돈된 책상 위에서 작은 교실을 직접 꾸미는 느낌**이다. 중앙 교실이 넓고 명확하며, Tidy 공통 색과 글꼴을 사용한다. 참고 사진의 전체 화면을 베이지 카드나 노란 좌석으로 다시 칠하는 방식은 채택하지 않는다.

### 화면 위계

- 도구의 테두리·패널은 얇고 단정하게, 입체감은 실제 교실 물건에 집중한다. 손잡이는 조작할 때 나타나고 평소에는 이름과 교실이 중심이다.
- 학생 이름표는 카드 본문처럼 따로 떠다니지 않고 책상의 앞면에 붙은 명패처럼 연결한다. 번호는 보조, 이름은 가장 선명하게. 긴 이름은 기본 두 줄과 선택 시 전체 표시로 처리한다.
- 교실 앞쪽은 넓은 칠판으로 즉시 인식된다. 문·창문·교실 물건은 배치 판단을 방해하므로 사용하지 않고, 안정적인 마루 배경과 옅은 숫자 격자로 교실 감각을 만든다.
- Tidy 강조색은 선택·다음 행동에 쓴다. 성별을 파랑/분홍 배경으로 전체 분류하지 않는다. 그림·표시·문구를 병행하고 색만으로 의미를 전하지 않는다.
- 과한 유리 효과, 큰 그라데이션 CTA, 모든 영역의 둥근 카드화, 별/반짝이 장식, 계속 움직이는 캐릭터는 사용하지 않는다.

### 학생·교실 에셋 제작 지침

현대 대한민국 초등교실의 단정한 일상복과 자연스러운 검정·갈색 머리, 위에서 내려다본 머리·어깨·팔·의자를 표현한다. ‘동양풍’을 한복·전통 건물·과장된 얼굴 특징으로 해석하지 않는다. 귀여움은 비례·작은 손·책과 필통에서 만들고 이름 가독성을 희생하지 않는다.

| 에셋 | 제작 계획 |
| --- | --- |
| 학생 기본 | 남학생 기본 4종, 여학생 기본 4종, 성별 미입력 기본 4종: 동일 시점·광원·크기. 이름/성별 추론 없이 명단 값을 이용 |
| 모습 선택 | 학생별 별도 설정을 두지 않고 학급 명단 성별의 기본 모습을 안정적으로 사용 |
| 책상·의자 | 학생이 앉은 자리에서만 위에서 본 학생·책상 그림을 표시. 빈 칸은 공란 |
| 교실 | 넓은 칠판, 마루 배경, 옅은 숫자 격자 |

학생은 명단 성별에 맞는 기본 그림을 사용하고 재배치할 때 그림이 랜덤으로 바뀌지 않는다. 성별 미입력도 동일한 품질의 중립 그림을 쓴다. 성별 글자는 이름 옆에 반복하지 않으며, 이름은 한 줄 가운데 정렬하고 파랑·보라·중립색으로 구분한다. 장애·성격·문제 행동을 외형으로 표현하지 않는다.

제작은 소형 스타일 시트 → 실제 크기 좌석 6개 → 30명 교실 전체 → 전체 에셋 순서다. 처음부터 대량 생성하지 않는다. 생성 그림에는 텍스트를 넣지 않고 이름·번호는 HTML로 렌더링한다. 레이어별 투명 배경, 정렬 기준점, 방향, 축소 가독성, 다크 모드 외곽선, 그림 로딩 실패 시 대체 표시를 검수한다. 실제 학생 자료를 생성 도구에 보내지 않는다.

## 11. 시니어 사용성과 접근성 — S06

- 본문·주 버튼 18px 기본, 보조 정보 16px, 이름 18~22px를 목표로 한다. `글씨 크게` 20/22px를 제공하고 사용자 글꼴을 상속한다. 클릭 영역은 최소 44×44px, 주 행동은 48px 이상이다.
- 작업 시작마다 긴 설명을 띄우지 않는다. 처음 한 번 `학생을 누른 다음, 옮길 자리를 눌러 주세요`를 해당 자리 가까이에 표시한다. `사용 방법`에서 다시 볼 수 있다.
- 모든 끌기 동작에 클릭·키보드 대안이 있다. 여러 책상 선택도 체크 방식 제공. 방향키 이동, Enter 선택, Escape 취소, 화면의 되돌리기 버튼을 지원한다.
- 확대/축소·교실에 맞추기·글씨 크게는 별도다. 좌석 확대 때문에 버튼 글자가 작아지지 않는다. 작은 화면에서는 교실만 이동하며 창 전체 이중 스크롤을 피한다.
- 버튼에 글자 이름을 기본 제공한다. 작은 아이콘과 툴팁만으로 핵심 기능을 설명하지 않는다. 오류에는 이유와 다음 행동을 같이 쓴다.
- 감소된 동작 설정에서 이동·공개 효과를 줄인다. 플래시·빠른 흔들기 금지. 드래그 중 화면 자동 이동은 가장자리에서 제한 속도로만 작동한다.
- 스크린리더용 학생·자리 목록과 현재 선택 상태를 제공한다. 그림은 장식이며 중복 낭독하지 않는다. 조작 후 초점은 해당 자리 또는 대기 학생에 남는다.

## 12. 공개 화면·출력 — S07

`학생에게 보여 주기`는 자동 기록된 마지막 완성 결과만 전용 화면으로 보낸다. 큰 교실, 이름·번호, 선택한 공개 연출만 포함한다. 편집 중 상태·분리 조건·고정 이유·성별 필드·학생별 이력·내부 ID는 전달하지 않는다. 교사용 창을 프로젝터로 직접 공유하면 그 창의 내용은 보인다는 점을 사용 방법에서 짧게 설명한다.

학생 쪽/선생님 쪽 보기는 교실을 180도 돌려 보여 주되 이름은 정방향이다. 저장 좌표·앞쪽 영역·조건은 바뀌지 않는다. 숫자는 현재 보는 방향 기준이며 방향 표식을 항상 보인다. 내부 좌표로 조작을 정확히 역변환한다.

PNG와 인쇄는 공개용 데이터만 사용하는 별도 렌더러로 만든다. 이름 표시/번호만 표시, 날짜·제목, 그림 포함/간단한 배치도를 선택한다. A4 가로·세로와 한 장 맞춤 미리보기, 글씨가 너무 작아질 때 나누어 출력 안내를 제공한다. 인쇄/PDF는 Tauri WebView2 실제 환경에서 경로를 검증한 뒤 제공하며 웹 브라우저 성공만으로 완료 처리하지 않는다.

## 13. 저장·복구·개인정보 — S08

명단과의 삭제·복원을 원자적으로 다루기 위해 자리 배치 영속 데이터는 기존 classroom SQLite에 새 테이블로 추가하는 설계를 우선한다. 점수판 JSON 저장소에 학생 데이터를 임의 추가하지 않는다. 확정 기록과 초안을 분리하고 schema migration을 갖춘다.

- 수정 완료 후 500ms 이내 자동 저장 요청, 종료·학급 전환 전 대기 쓰기 완료. 저장 성공을 받기 전 `저장됨` 표시 금지. 실패해도 초안은 남기고 재시도를 제공한다.
- 저장 명령은 operationId로 중복 방지하고 expectedRevision을 검사한다. 초안·명단·선택 학급의 revision을 구분한다. 다른 학급 수정만으로 현재 후보가 무조건 무효화되지 않게 한다.
- 학급 삭제는 배치·조건·기록까지 같은 트랜잭션에서 삭제하고 기존 명단 삭제 안내에 영향 개수를 포함한다.
- 학생 삭제는 현재 배정·개인 조건·외형을 제거한다. 과거 기록의 해당 이름·번호·성별·외형·학생 ID 연결도 제거하고 익명 빈자리로 남기는 것이 제안 정책이다. 남은 학생의 과거 위치는 유지한다. 기록이 평소 불변이라는 원칙에 대한 명시적 삭제 예외다.
- 명단 삭제 실행 취소는 관련 자리 배치의 삭제 전 상태까지 함께 복구해야 한다. 다른 편집과 충돌하면 부분 복구하지 않는다. 이를 구현하지 않은 채 기존 실행 취소로 학생만 부활시키지 않는다.
- 백업 v2에 학급·배치·기록·조건·외형 선택을 포함한다. v1 복원은 기존 배치도 대체된다는 영향을 안내하고 빈 자리 배치 상태로 복원한다. v2 손상·상위 버전은 기존 데이터에 손대지 않는다.
- 기록·학생 이름·분리 조건을 로그·분석 이벤트·오류 breadcrumb로 전송하지 않는다. 분리 사유의 자유서술 필드는 첫 출시에서 제공하지 않는다.
- 자동 저장된 작업은 재시작 시 복구한다. 마지막 저장 성공 이후 강제 종료로 유실될 수 있는 범위는 별도로 검증·기록한다. 무제한 이력이나 전원 차단 무손실을 약속하지 않는다.

## 15. 인터뷰 결정 기록

2026-09-25 사용자 답변을 반영했다.

1. “네, 학급별로 기억하고 자동 전환” → 학급별 독립 교실·초안, 기본 학급 추종을 확정.
2. 필수 조건과 최근 3번 참고 방향에 동의. “학생들에게 쉽게 보이지 않는 곳”, “선생님 전용 모달이나 팝업” → 별도 선생님 설정 창을 채택. 공개 화면에 조건을 CSS로 숨기기만 하는 구현은 금지.
3. “너가 스마트하게 판단해서 생성해.” → 에셋 방향과 생성은 위임. 현대 한국 초등교실, 정돈된 탑뷰, 성별 기본형·중립형·개별 외형 선택을 채택.

## 2026-09-25 교사 사용성 수정 — 이전 자유 편집 요구보다 우선
- 기본 화면에서 학생/책상 모드와 책상 편집 도구를 제거한다. 학생을 두 번 선택하거나 가까운 자리로 끌어 교환한다. 책상 좌표는 이 동작으로 변경하지 않는다.
- 작은 좌표 오차는 같은 줄로 정리한다. 겹치는 자리로 합쳐지는 경우 기존 위치를 보존한다.
- ‘교실 모양’은 학급 표시줄의 선생님 설정 옆 패널형 버튼으로 제공한다. 둘씩/혼자/모둠 형태 및 가로 자리 수로 변경하며, 기존 학생 배치는 순서대로 유지한다. 위치 지정 조건 재설정은 명시적으로 알린다.
- 제목/자리 검색 패널, 교실 물건 추가, 회전/복제/사용 전환/가지런히/모두 선택 등 직접 책상 편집 도구를 제거한다.
- 학생 쪽/선생님 쪽 전환은 교실에 맞추기 표시줄 오른쪽 끝에 둔다.
- 기본 확대율은 가로·세로를 모두 고려한다. 20~40명 일반 배치가 한 화면에 들어오도록 학생 그림과 간격을 조절한다.
- 이름은 한 줄과 가운데 정렬을 유지한다. 명단 성별에 따라 남학생은 파랑, 여학생은 보라, 미입력은 중립색을 사용하며 별도 성별 글자·기호는 표시하지 않는다.
