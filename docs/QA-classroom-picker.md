# 간단 뽑기 구현 검증 — 2026-09-21

## 구현

툴킷에서 여는 독립 ‘간단 뽑기’ 창. 클래식·인형 뽑기·풍선 다트, 5개 대상 유형, 학급 데이터 구독, 직접 목록 편집/저장/불러오기, 제외·취소·초기화, 디자인·팔레트·효과음·연출 줄이기를 연결했다. 원본 학급 명단은 수정하지 않는다.

동일 학급의 성별 필터/모드 사이에서 제외 기록을 공유하고 다른 학급 및 직접 목록은 분리한다. 결과는 추첨 시작 시 확정된 스냅샷이며 재추첨 없이 한 번만 완료된다. 창을 닫으면 기록이 사라진다. 저장 버튼으로 보관한 목록과 소리/연출 설정만 기기에 남는다.

## 인원에 따른 배치

최대 30명까지 남은 후보 수만큼 오브젝트를 표시한다. 1~4명은 한 줄, 5~8명은 4열, 9~15명은 5열, 16~24명은 7열, 25~30명은 8열로 배치한다. 마지막 줄은 가운데 정렬한다. 셀 폭/높이로 이미지 크기를 제한하고 집게도 비례 축소한다. 연출 시작 후에는 해당 배치를 고정해 집는 위치가 바뀌지 않는다.

15명이 넘는 풍선 무대는 이동 진폭을 4 SVG 단위로 낮춘다. 30명을 넘는 직접 목록은 렌더링만 제한하고 모든 후보를 추첨 엔진에 전달한다. 작은 창에서는 상단 높이를 압축하고 무대와 뽑기 버튼을 함께 표시하며 하단 설정·기록은 스크롤로 접근한다.

30개 풍선 idle 120프레임 표본: Chromium headless, 960×720, 이번 Windows 개발 환경에서 중앙값 16.7ms / p95 16.8ms. 장시간 메모리 누수 검사나 저사양 교실 장비 FPS 보장 자료는 아니다.

## 확인 범위의 한계

Windows DPI 125%/150%, 글자만 200%, 다중 모니터, 실제 스피커 음량, 패키징한 설치본 재시작과 저장 복구, 네이티브 전체화면·항상 위·리사이즈 전환의 전체 수동 검수는 완료하지 않았다. 브라우저 저장 재열기 및 Rust 저장 검증을 네이티브 설치본 검증으로 대체해 표기하지 않는다. 전체 프로젝트 정적 검사 실패는 별도 기존 작업이다.

## 실행

개발 서버가 5193번에서 실행되는 상태로 `node output/qa/picker/browser-check.mjs`, `node output/qa/picker/density-check.mjs`, `node output/qa/picker/edge-check.mjs`를 실행한다. `serve.mjs`는 QA 출력이 앱을 새로고침하지 않도록 HMR를 끈 전용 Vite 서버다. 브라우저 fixture는 각 격리 컨텍스트에서 실제 repository 명령을 호출한다.
