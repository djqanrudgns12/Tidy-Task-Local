## 청취 승인 및 남은 실기 확인

1. **한국어 청취 검수:** 2026-09-27 사용자가 직접 확인한 뒤 “확인했는데 괜찮더라. 승인으로 바꿔.”라고 요청했습니다. 이 사용자 승인에 근거해 기본 492파일의 manifest를 모두 approved로 바꾸고 승인 일시·범위·근거를 기록했습니다. 별도의 두 명 평가나 Windows 장치 시험을 완료했다고 기록하지 않습니다.
2. **실제 Windows 패키지:** 네이티브 WebView2 IndexedDB 저장 위치/수명, 두 창 동기화, 오프라인 재시작, DPI·다중 모니터·외부 스피커·출력 장치 변경을 이 브라우저 결과로 대신하지 않습니다.
3. **실제 가청 품질과 성능:** 교실 뒤쪽 음량, 음소거 시 실제 출력 녹음, 지연 P95, 저사양 PC 메모리·다운로드 중 디스크 부족 시험은 남아 있습니다.
4. **임의 이름:** 원문 숫자·영어의 완전 자동 발음은 보장하지 않습니다. 준비 후 들어 보고 별칭으로 수정하는 흐름을 제공합니다.

## 최초 검수 계획

아래는 2026-09-26의 계획입니다. 청취 승인은 2026-09-27 사용자의 직접 확인 및 승인 요청으로 반영했으며, 실제 기기 확인은 별도 항목입니다.

3. Windows 설치본에서 기본/동적 준비·재시작·네트워크 단절·음소거·교사 창·마지막 학생 재투표를 확인합니다.

## 추가 취소 경합 검사

캐시 해시·IndexedDB 조회 중 준비 취소가 들어온 경우, 조회 완료 후 worker가 새로 생성될 수 있는 경합을 수정했습니다. 조회 직후와 생성 음원 해시 계산 직후 요청 세대를 다시 확인합니다. 취소된 준비는 유휴 타이머도 새로 남기지 않습니다.

`/scripts/vote-speech/cancel-qa.html`에서 준비와 취소를 연속 실행한 결과 **PASS: 캐시 조회 중 취소 뒤 worker 생성 0회**를 확인했습니다. 모델 다운로드가 늦게 시작되거나 취소한 음원이 뒤늦게 저장되는 경로를 줄였습니다. 이 검사는 음질 청취 승인과 무관합니다.
