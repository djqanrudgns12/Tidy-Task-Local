## 2026-09-27 추가 — 사유 직접 입력 · 온도계 이름 바로 고치기

사용자 요청: "칩이 정해진 것만 떠서 불편하다 → 협동 · 배려 옆에서 직접 입력", "제목(온도계 이름)을 누르면 실시간으로 이름을 고치게, 미니 온도계에도".

- 사유 칩 줄 끝에 "직접 입력" 칸(`ThermoReasons.svelte`). Enter 또는 ✓로 붙임, Esc는 지우고 나옴. 칸에 초점이 있는 동안은 4초 뒤 사라지기를 멈추고(`holdChips`), 나오면 다시 4초. 칩을 모두 지워도 칸은 뜸. 좁은 칸에서는 옆으로 숨기지 않고 다음 줄로 내림.
- 기록 사유 길이: 칩(6자)과 따로 `LIMITS.reason` 12자. `tagReason`이 다듬고(앞뒤 빈칸 · 12자) 빈 글은 무시. 알림은 "“…” 사유를 붙였어요"(받침과 상관없이 맞는 조사).
- 이름 바로 고치기(`ThermoTitle.svelte`, 관리 창 제목 줄 · 미니 온도계 공용): 글자처럼 보이다 누르면 입력 칸, 치는 대로 저장(`renameThermometer`) → 같은 저장 구역을 지켜보는 다른 창에 곧바로 반영. 글자 위를 누르면 그 자리에 커서, 연필을 누르면 전체 선택. Enter · 바깥 누르기로 끝, Esc는 고치기 전 이름으로, 다 지운 채 끝내면 원래 이름 유지. 되돌리기(Ctrl+Z) 기록은 남기지 않음(설정 서랍의 제목 칸과 같음).
- 한글 조합 중 Enter · Esc는 건너뜀(`isComposing`). 툴킷 공용 초점 테두리(`.tk-root … :focus-visible`)는 두 칸에서 끄고 칸 자체 표시(밑줄 · 파란 테두리)를 씀.
