# 개표 판세 태그 — 2026-09-27

## 판단 계약

`src/lib/vote/outlook.js`가 모든 개표 화면의 판세를 계산합니다. 최종 결과를 미리 보고 맞히는 방식이 아니라 **현재 공개된 정보와 남은 투표용지**만 사용합니다. 유력은 방송사의 당선 확률 수치를 흉내 내지 않는 보수적인 흐름 표시입니다.

후보·의견 투표에서 각 후보의 현재 득표에 도달하려면 다른 후보에게 각각 몇 표가 필요한지 계산합니다. 선출 인원만큼의 경쟁자가 동점 이상이 되는 데 필요한 추가 표를 작은 순서로 선택하고, 다음 두 값 중 큰 값을 필요한 최소 투표용지 수 `D`로 사용합니다.

- 가장 많은 추가 표가 필요한 경쟁자의 표 수 ÷ 한 장이 같은 후보에게 줄 수 있는 최대 표 수(올림)
- 경쟁자들에게 필요한 추가 표의 합 ÷ 1인 표 수(올림)

같은 후보에 몰아주기를 허용하면 한 장의 최대치는 1인 표 수, 허용하지 않으면 1입니다. 경쟁자들이 남은 표를 동시에 전부 받을 수 있다고 가정하지 않고 총 표 예산도 검사합니다. 선출 경계에서 동점이 생기는 상황도 확실 판정을 막습니다. 0표는 선출하지 않습니다.

| 태그 | 기준 |
| --- | --- |
| 경합 | 현재 선출 경계 동점이거나, 남은 장수 `R`의 25% 이내(내림, 최소 한 장)로 선출 경계가 바뀔 수 있음. 경계 밖 후보도 그 장수 안에 현재 경계에 도달할 수 있고 유효 득표가 있으면 표시. |
| 우세 | 현재 선출 범위 안이고 경합 기준을 벗어나지만 유력·확실 기준에는 못 미침. |
| 유력 | 6장 이상 및 전체의 50% 이상 공개했고, 판세를 바꾸려면 최소 2장 및 남은 장수의 75% 이상이 추격에 유리하게 나와야 함. |
| 당선 확실 / 선정 확실 | `D > R`. 남은 표가 어떻게 나와도 선출 범위에서 벗어날 수 없음. |

경합·우세는 최소 3장(전체가 그보다 적으면 전체 장수)과 20% 이상 개표한 뒤 표시합니다. 수학적으로 입증되는 확실은 이 제한을 받지 않습니다. 등록 인원이 아니라 실제 투표한 용지 수를 사용합니다. 현재 최다 득표가 동률이면 단독 선두로 강조하지 않습니다.

예: 공개 득표 12 대 8, 20장 개표, 1명 선출일 때 남은 표가 20장이면 경합, 10장이면 우세, 5장이면 유력, 3장이면 확실입니다. 마지막 한 장으로 동점이 가능하면 유력으로 표시하지 않습니다. 태그 설명에는 남은 장수와 판세를 바꾸는 데 필요한 최소 장수를 제공합니다.

## 모든 모드·공개 범위

| 방식 | 처리 |
| --- | --- |
| 한 장씩 펼치기 | 기호 순 집계 행에서 이름·집계 획·태그·득표를 구분. 현재 용지에는 판세를 넣지 않음. |
| 실시간 레이스 | 득표 영역에 태그. 후보가 많으면 득표 옆에 가로 배치하고 모든 레인을 화면 안에 유지. |
| 줄다리기 | 각 선택지 이름 아래 경합·우세, 안건 제목 옆 통과·부결 유력/확실. |
| 개표 방송 | 후보별 독립 태그 칸과 판세 요약. 숫자·막대·이름과 겹치지 않음. 후보가 많으면 상단 보조 문구를 줄여 9개 행 확보. |
| 반전 공개·골라 공개 / 모두 공개 | 카드는 후보의 완성된 득표이므로 표본 기반 유력 추정을 하지 않음. 공개하지 않은 카드가 모두 앞서더라도 선출 범위 안일 때만 확실. |
| 반전 공개·골라 공개 / 순위만 | 숨긴 표 수·표 차이를 판정에 사용하지 않음. 이미 공개된 순위 관계가 양수 득표와 동점 범위를 입증할 때만 확실 또는 경합. 최종 카드의 기존 당선·선정·동점 표시를 우선. |
| 당선자만·결과만 공개 | 중간 예측으로 숨긴 정보를 노출하지 않음. 정해진 발표 시점에 기존 최종 결과 표시. |
| 바로 결과 | 중간 집계가 없으므로 기존 최종 결과로 연결. 예측 태그를 억지로 추가하지 않음. |

공통 계산은 현재 cursor·agenda·revealed에서 즉시 파생되므로 수동 진행·자동 진행·건너뛰기·재개표·저장 후 복원에서 이전 판세가 남지 않습니다. 최종 결과 및 PNG에는 중간 예측 태그를 저장하지 않습니다.

## 찬반

찬반 득표의 우세와 안건 통과 여부를 분리합니다. `yesOverNo`, 참여자 과반, 3분의 2, 판정 없음 모두 처리합니다. 기권은 설정된 기준의 분모에 반영합니다.

과반·3분의 2에서는 최종 참여 인원에 필요한 찬성 수를 정수로 계산하고, 남은 표 중 찬성이 몇 장 더 필요한지 및 반대·기권이 몇 장이면 부결되는지 비교합니다. 한 장으로 판정이 갈리면 유력 표시를 하지 않습니다. 판정 없음에서는 통과·부결 태그가 없습니다. 안건 변경 시 새 안건의 공개 표만 계산합니다.

## 표현

- 글자 15px, 높이 32px, 아이콘 14px. 경합은 황금색, 우세는 파랑, 유력은 보라, 확실은 진한 초록. 다크 모드는 별도 대비 색.
- 태그 칸을 확보하여 상태 변경 때 이름·득표 위치가 밀리지 않게 함.
- 초기 등장만 240ms의 작은 이동·크기 변화. 반복 점멸하지 않으며 움직임 줄이기 설정 준수.
- 태그에 읽을 수 있는 문구·아이콘·판단 근거를 함께 제공. 색만으로 상태를 전달하지 않음.
- 마지막 결과의 동점 후보에게 확실을 표시하지 않음. 레이스의 완료 강조도 실제 선출 대상 기준이며 동점자를 임의의 당선자로 축하하지 않음.
