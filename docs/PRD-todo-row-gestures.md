## 1. 배경

할 일 한 줄의 오른쪽에는 **이동 손잡이(18px) + 휴지통(약 19.66px) = 약 37.66px**와 그 앞 간격 4px가 늘 있습니다.
두 버튼은 `opacity: 0`으로 안 보이기만 할 뿐 **자리를 계속 차지**합니다(`.todo-actions`).
그래서 모든 줄이 오른쪽 약 42px 앞에서 줄바꿈되고, 목록 오른쪽에 세로로 긴 빈 띠가 생깁니다.
사용자 평가는 "비어 보이고 디자인을 지나치게 해친다"였습니다.

예전에 자리를 비워 둔 이유는 하나였습니다. 마우스를 올릴 때 폭이 바뀌면 **편집 중인 글의 줄바꿈이 흔들리기** 때문입니다.
그래서 해법은 **자리를 비워 두지 않으면서, 어떤 순간에도 레이아웃이 한 픽셀도 바뀌지 않는** 구조여야 합니다.

마감된 일 목록도 같은 문제가 있습니다. 휴지통이 투명한 채로 약 29px를 차지해서 글이 그만큼 일찍 잘립니다.
그리고 머리글의 **[전체 삭제]는 확인 없이 한 번에 모두 지웁니다**(`deleteAllArchivedTodos`). 지금은 Ctrl+Z를 아는 사람만 살릴 수 있습니다.

## 2. 목표와 비목표

### 목표
1. 쉬는 상태에서 오른쪽 빈 띠 0px. 글이 줄 안쪽 여백 끝까지 씁니다.
2. 순서 변경은 **완료 버튼·날짜 알약**을 위아래로 끌어서 합니다. 손잡이 아이콘은 화면에서 없앱니다.
3. **클릭과 끌기가 절대 섞이지 않습니다.**
4. 삭제는 마우스를 올리면 나타나는 **말랑 X 단추**로 합니다. 할 일 목록과 마감된 일 목록 모두입니다.
5. 지운 직후 **귀여운 되돌리기 알림**으로 바로 살릴 수 있습니다. 지운 **그 항목만** 정확히 제자리로 돌아옵니다.
6. 마우스를 올리고·끌고·놓고·지우고·되돌리는 어떤 순간에도 **줄의 폭·높이·줄바꿈이 변하지 않습니다**.
7. 키보드 순서 변경은 지금과 똑같이 남깁니다.

### 비목표
- 순서 변경 움직임(미끄러짐 180ms, 착지, 자동 스크롤, 저장 1회) 변경
- 편집 모드 [선택 삭제]: 이미 확인 창이 있어 지금 그대로 둡니다(되돌리기 알림 없음, 기존 D-Day 안내 유지)
- 보관함 창(`ArchiveWindow`)의 노트 삭제
- 새 통계 이벤트. 기존 `todo_deleted`는 그대로 나가고, 되돌리기 사용은 보내지 않습니다(§16)
- 할 일 여러 개를 한꺼번에 끌기

## 5. 끌기 상호작용 명세

### 5.1 끌기를 시작하는 곳

| 누른 곳 | 마우스·펜 | 터치 | 키보드 |
|---|---|---|---|
| 완료 버튼 | 세로 6px 초과 → 끌기 | 0.4초 길게 → 끌기 | 끌기 없음 (스페이스·Enter = 마감) |
| 날짜 알약 (날짜 있음/없음) | 세로 6px 초과 → 끌기 | 0.4초 길게 → 끌기 | 끌기 없음 (Enter = 달력) |
| 보이지 않는 손잡이 | — | — | 스페이스·Enter → 키보드 끌기 |
| 글 · 편집 모드 체크박스 · 깃발 · X · 빈 여백 | 끌기 없음 | 끌기 없음 | — |
| 오른쪽·가운데 버튼 | 끌기 없음 (오른쪽 = 기존 메뉴) | — | — |

판정은 **누른 지점의 조상 중 `data-sort-activator` 표시가 있는가**로만 합니다. 아이콘(SVG) 위를 눌러도 같습니다.

### 5.2 한 번의 누름이 거치는 상태

```
           pointerdown(잡기 버튼, 왼쪽 버튼)
  [쉼] ─────────────────────────────────────▶ [누름]
   ▲                                            │
   │  떼기(기준 못 넘음) → 평범한 클릭           │ 세로 6px 초과 (터치: 0.4초)
   │  (마감 / 달력 — 지금과 같음)                ▼
   │                                       [끌기] ── 클릭 가드 무장
   │                                         │   ├ 목록 안 편집 중 글 확정
   │                                         │   └ 떠 있는 달력 닫기(유예 없음)
   │                     놓기 / Esc / 초점 잃음 / 창 크기 변경 / 목록 변경
   │                                         ▼
   │                                    [끝남] (기존 착지·취소 그대로)
   └──── 클릭 가드 해제 ◀─────────────────────┘
          (클릭 1번을 버렸거나, 새 누름, 뗀 뒤 키 입력, 또는 뗀 뒤 1초)
```

- 기준을 못 넘고 떼면 아무것도 끼어들지 않습니다. 가로로만 움직였을 때도 끌기가 시작되지 않습니다. 버튼 밖에서 떼면 브라우저 기본대로 클릭이 생기지 않습니다.
- [끌기] 이후의 움직임·착지·취소는 기존 엔진 그대로입니다.

### 5.3 클릭 가드

창(window)의 **캡처 단계** 리스너라서 라이브러리(document 캡처)보다 먼저 봅니다.

| 무장 중에 일어난 일 | 처리 |
|---|---|
| `click` (어디서든) | `preventDefault` + `stopImmediatePropagation`, **해제** |
| 새 `pointerdown` (어느 버튼이든) | **해제** |
| `keydown` — 아직 누르고 있음 | **유지** (Esc로 취소한 뒤 버튼 위에서 떼는 경우) |
| `keydown` — 이미 뗌 | **해제** |
| 누름이 끝난 뒤(`pointerup`·`pointercancel`) 1초 | **해제** (클릭이 안 생긴 경우의 안전 장치) |

막는 사고: 끌다가 Esc·초점 잃음 → 버튼 위에서 뗌 → **마감 안 됨**. 알약을 끌어 놓음 → **달력 안 열림**.
막지 않는 것: 끌기 뒤 다른 버튼 누르기(새 누름이 해제). 오른쪽 클릭 메뉴 "마감일 수정"의 프로그램 클릭(오른쪽 누름이 먼저 해제).

### 5.4 끌기 시작 때 함께 하는 일
1. 목록(`.todo-rows`) 안에서 편집 중인 글이 있으면 `blur()`로 확정합니다(기존 `onSave → saveNow`). 새 할 일 입력칸은 목록 밖이라 그대로 둡니다.
   - 왜: 예전 손잡이는 누를 때 초점을 가져가 글이 자연히 확정됐습니다. 완료 버튼은 `mousedown`에서 초점 이동을 막으므로 명시적으로 확정합니다.
2. 달력이 떠 있으면 `datePicker.close('drag', { toggleGrace: false })`로 닫습니다.
   - 왜: 같은 알약의 달력이 떠 있을 때 그 알약을 끌면, 달력의 바깥 누름 처리기는 "같은 버튼"이라 닫지 않습니다. 유예(450ms)를 남기면 빨리 놓고 바로 누를 때 "다시 누름 = 닫기"로 오인합니다.
3. 클릭 가드 무장(포인터로 시작한 경우만).
4. 떠 있는 되돌리기 알림은 그대로 둡니다(끌기와 무관).

### 5.5 끄는 동안의 모양
잡힌 줄(`[data-dnd-dragging]`)·착지 중인 줄(`[data-dnd-dropping]`)에서:
- 완료 버튼의 올림 효과(초록 채움·체크·1.1배)와 누름 효과(0.9배)를 끕니다. 그대로면 "마감될 것처럼" 보입니다.
- 날짜 알약의 1.05배·0.95배 효과를 끕니다.
- X와 보이지 않는 손잡이를 숨깁니다.
- 잡힌 줄의 배경·그림자·폭 고정은 지금 그대로입니다.

### 5.6 키보드

### 5.7 터치·펜
- 터치: 0.4초 길게, 그동안 6px 넘게 움직이면 끌기를 포기하고 스크롤. 두 버튼에 `touch-action: none`을 주지 않습니다.

- 펜은 마우스와 같은 규칙입니다.

### 6.6 X 무장
- 목록마다 `pointerover` 위임 리스너 하나로, 포인터가 **다른 줄로 들어온 시각**을 그 줄에 적습니다(`hoverSince`).
- X를 누를 때(`pointerdown`) `지금 − hoverSince < 150ms`이면 이번 누름은 무장 안 됨입니다. 이어지는 `click`은 아무것도 하지 않습니다.
- 키보드(`click.detail === 0`)는 늘 무장 상태입니다.

### 7.8 되돌리기 엔진 (삭제 기록)

**지울 때** (`captureDeletion`): 지우기 **직전 상태**와 **직후 상태**로 기록을 만듭니다.
```js
{
  kind: 'todo' | 'archived',
  items: [{ todo, index, prevId, nextId }],  // 원래 목록의 객체 사본·번호·앞뒤 이웃 id
  ddayBefore: [ ... ],  // 이번 삭제로 사라지거나 바뀐 D-Day의 "전" 모습
  ddayAfter:  [ ... ],  // 같은 D-Day의 "후" 모습 (사라졌으면 null)
  ddayEffect: 'deleted' | 'kept' | null,
}
```

**되돌릴 때** (`restoreDeletions(state, records)`): 묶음의 기록을 **지운 순서의 반대로** 하나씩 적용합니다.
1. 항목마다, 같은 id가 할 일·마감된 일 어디에든 이미 있으면 **건너뜀**(중복 방지).
2. 넣을 자리는 `prevId`가 있으면 그 뒤, 없으면 `nextId` 앞, 둘 다 없으면 `min(index, 길이)`입니다. 한 기록 안의 항목은 원래 번호 오름차순으로 넣습니다.
   - 반대 순서로 적용하는 이유: A를 지우고 A의 앞 이웃 B를 지웠다면, B가 먼저 돌아와야 A가 B 뒤에 정확히 들어갑니다.
3. D-Day는 항목마다(`ddayActions.restoreDdaysForTodos`, 새로 export):
   - 지금 없음 + "후"도 없었음(할 일과 함께 지워짐) → "전" 모습으로 다시 넣음
   - 지금 없음 + "후"는 있었음(남겼는데 사용자가 나중에 지움) → 건너뜀
   - 지금 있음 + 지금 모습 = "후" 모습(그 뒤로 손대지 않음) → "전" 모습으로 바꿈(연결 복원)
   - 지금 있음 + 그 뒤로 바뀜(다른 할 일에 다시 연결 등) → 건너뜀(사용자 변경 우선)
   - 다시 넣은 D-Day가 있으면 진행 중 D-Day 순서를 원래 `order` 기준으로 다시 매깁니다(같으면 되돌린 것이 앞).
4. 결과를 한 번에 대입하고 `saveNow()`로 저장합니다(되돌리기 기록에도 한 칸 쌓임 → 그 뒤 Ctrl+Z는 "되돌림"을 취소).
5. 되돌린 할 일 id를 `recentlyRestoredIds`에 1초 동안 넣어 **그 줄을 반짝**이게 합니다(강조색 18% → 0, 900ms). 첫 줄이 화면 밖이면 `scrollIntoView({ block: 'nearest' })`로 보입니다.
6. 검색 중이라 되돌린 줄이 걸러져 안 보여도 되돌림은 그대로 합니다(문구 "되돌렸어요!").
7. 업데이트 잠금 중이면 아무것도 하지 않고 알림을 닫습니다(단추는 잠금 시작 때 이미 사라짐).

**지키는 것**
- 새 저장 경로가 없습니다. 삭제·되돌림 모두 기존 `saveNow()`를 탑니다. 업데이트 설치 절차(쓰기 정지)에서도 따로 챙길 것이 없습니다.
- 삭제 기록은 메모리에만 있습니다(저장소·되돌리기 스냅샷 필드에 넣지 않음). `WINDOW_FIELDS` 변경 없음.

## 8. 마감된 일 목록

- 줄 = [되돌리기(진행 중으로) 단추] + 말랑 X(겹침). 지금의 휴지통(`ml-2 p-1`, 투명하게 자리 차지)을 지웁니다. 글은 끝까지 쓰고, 넘치면 지금처럼 말줄임됩니다.
- X 위치·색·움직임·무장은 §6과 같고, 받침 색만 이 영역 배경 기준입니다.
- 줄에 `position: relative`를 둡니다. 줄 높이(약 26px)·간격은 그대로입니다. 배치 규칙의 줄 높이 측정(`syncRowMetrics`)에 영향이 없어야 합니다.
- 연타 보호는 **복원 단추와 X 모두**에 적용합니다. 복원도 줄을 없애므로 더블클릭 한 번에 두 개가 돌아가는 사고가 같습니다.
- 머리글 [전체 삭제]의 휴지통 아이콘은 그대로 둡니다(묶음 동작이라 단건 X와 구분). 대신 지운 뒤 되돌리기 알림이 뜹니다.
- 키보드: Tab → 복원 단추 → X.
- 끌기는 없습니다.

## 9. 연타 보호

- 시작: 포인터 클릭으로 **할 일 완료 버튼 · 할 일 X · 마감된 일 복원 단추 · 마감된 일 X**가 줄을 없앤 순간. 누른 화면 좌표를 기억합니다.
- 보호 중 (두 목록 모두):
  - 위 네 종류 단추는 클릭을 무시합니다.
  - X는 숨깁니다(포인터 밑으로 올라온 줄의 X가 바로 보이지 않게).
  - 날짜 알약·글·끌기·되돌리기 알림은 막지 않습니다.
- 해제: 기억한 좌표에서 **4px 넘게 움직임** 또는 **0.5초 지남** 중 먼저 오는 것.
- 키보드·오른쪽 클릭 메뉴로 없앤 경우에는 시작하지 않습니다.
- 위 줄부터 하나씩 0.5초 넘는 간격으로 같은 자리를 누르면 그대로 됩니다.


### 11.3 `verticalSort.js` 센서 옵션
```js
{ plugin: TodoPointerSensor, options: {
    // 줄 전체에서 받고 실제 시작 여부는 아래에서 거름.
    // 왜: 버튼 요소에 직접 묶으면 버튼이 다시 그려질 때 리스너가 빠짐.
    activatorElements: source => [source.element],
    preventActivation: (event, source) => !findSortActivator(event.target, source.element),
    activationConstraints: event => toConstraints(sortActivationFor(event.pointerType)),
} }
```
- `toConstraints`: `distance` → `new PointerActivationConstraints.Distance({ value: { y } })`(축별 거리는 `@dnd-kit/geometry`의 `exceedsDistance`가 지원, 확인함), `delay` → `new PointerActivationConstraints.Delay({ value: ms, tolerance })`.
- `handle`: `node.querySelector('.todo-kbd-handle')`. 키보드 센서 설정은 그대로입니다.
- `dragstart` 모니터: 기존 처리 뒤 `activatorEvent instanceof PointerEvent`이면 `clickGuard.arm()`과 `options.onpointerdragstart?.()`.

### 11.4 CSS 원칙
- 보이고 숨기는 것은 `opacity`·`transform`·`pointer-events`만 씁니다. 폭·높이·여백·`display`를 바꾸지 않습니다.
- X 숨김 묶음: `.todo-row:has(.todo-text:focus)`, `[data-dnd-dragging]`, `[data-dnd-dropping]`, 목록의 `.is-settling`(연타 보호).
- 끄는 동안 효과 끄기: `[data-dnd-dragging|dropping] .todo-done` → `transform: none`, 초록·체크 끔. 알약도 `transform: none`.
- `@media (hover: none)`: X 늘 보임 + 글 오른쪽 24px.
- `@media (prefers-reduced-motion: reduce)`: 투명도만.
- `light-dark()` 금지(배포 빌드에서 값이 사라진 전례). 다크는 `appState.isDarkMode`로 나눕니다.
- 높이를 CSS `min-height`·%·vh로 새로 정하지 않습니다(메모 창 세로 배치 규칙).

### 11.5 바꾸지 않는 것
- `verticalDrop`, `dragover` 순서 계산과 충돌 판정 잠시 끄기, `dragend` 저장, `preview`/`previewOrder`, `sync()` 취소 조건, blur·resize·visibility·포인터 캡처 상실·Esc 취소
- `order.js`, `applyTodoOrder`, `appState.reorderTodos`, 잡힌 줄 폭 고정·배경·그림자
- `toggleTodo`, `restoreTodo`, `deleteSelected`(편집 모드)

`CLAUDE.md`에 넣을 문구:
> **할 일 줄 조작**: 끌기는 잡기 버튼(완료·날짜 알약, `data-sort-activator`)에서만 시작하고, 끌기로 시작된 누름의 클릭은 `rowGestures.js` 클릭 가드가 버립니다. 줄 안 단추를 보이고 숨길 때 폭·높이를 바꾸지 않습니다(편집 중 줄바꿈이 흔들림). 단건 삭제는 `deletionUndo.js` 기록 + 되돌리기 알림을 거치고, 알림의 되돌리기는 전역 Ctrl+Z가 아니라 기록으로 그 항목만 복원합니다. 삭제 기록은 메모리 전용이라 저장 필드에 넣지 않습니다.
