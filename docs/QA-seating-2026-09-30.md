# 자리 대형 보존·사전 지정·저장 수정 검증 · 2026-09-30

## 문제와 수정

- 재배치가 매번 앞쪽 자리부터 다시 선택하면서 중간 빈칸이 이동했다. 학생 전원이 배치된 상태에서는 현재 학생이 앉은 자리 집합을 유지하고, 그 안에서 학생만 재배치한다. 최초 배치 또는 미완성 배치에서는 조건에 맞는 자리를 확보한 다음 빈자리를 채운다.
- 상태를 다시 읽을 때 교실을 새로 만들면서 자리 고유 ID·좌표·활성 상태·잠금·물건·제외 학생 설정이 초기화됐다. 기존 상태를 보존하고, 명단 변경으로 더 이상 유효하지 않은 참조만 정리한다. 비활성 자리의 사전 지정은 유지하여 충돌을 안내한다.
- 가로·세로 변경이 배열 순서를 기준으로 학생을 이동시켰다. 실제 행·열과 자리 ID를 기준으로 확장하며 기존 좌표와 배치를 보존한다. 축소로 제거되는 자리의 학생은 가까운 가능한 자리로 옮기고, 사전 지정·자리 유지 또는 수용 인원 때문에 안전하게 줄일 수 없으면 변경하지 않는다.
- 저장된 교실 불러오기와 명단 증가 시 기존 대형을 보존하여 필요한 행만 추가한다. 과거 기록의 화면 복원에는 현재 명단 증가를 적용하지 않는다.
- 사전 지정끼리 이동하면 상대 지정이 사라지던 동작을 교환으로 수정했다. 고유 ID 또는 실제 행·열로 불러오며, 비활성 자리와 고정 학생을 보호한다.
- 여러 사전 지정과 개인 조건은 가능한 자리의 교집합으로 검사한다. 겹치는 구역의 인원 초과를 매칭으로 판별하고, 실제 짝·모둠 관계와 앞·뒤 줄을 기준으로 조건을 확인한다. 앞·뒤 판정은 JavaScript와 Rust에서 일치시킨다.
- 완성된 대형 밖 빈칸을 새로 사전 지정하면 대형을 자동 변경하지 않고 충돌을 안내한다. 학생을 그 빈칸으로 직접 옮기면 새 대형이 된다. 여러 미충족 조건은 이미 지켜지는 조건을 깨뜨리지 않으면서 한 건씩 수동 수정할 수 있다.
- 계산 취소·학급 전환·닫기 과정에서 늦게 도착한 계산 결과와 저장 예약이 다른 학급에 반영되지 않도록 처리했다. 저장은 기존 순차 저장 큐와 revision 계약을 사용한다.
- 하단 버튼 순서를 **PNG 저장 → 자리 재배치 → 저장**으로 정리했다. 저장 버튼과 저장 패널에 색을 적용하고 재배치 버튼 폭을 줄였다. 작은 화면에서 자리 잠금 버튼이 학생 클릭을 가로채지 않도록 크기와 위치를 조정했다.
